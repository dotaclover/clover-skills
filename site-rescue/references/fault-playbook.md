# 故障对照与现场验证

先核对操作系统、服务管理器、云厂商/面板、站点目录、运行用户及授权；下列工具需按现场替换，不默认Ubuntu、腾讯云、宝塔或固定属主。只读诊断不等于修改授权。

| 现象 | 先查 | 常见根因与后续 |
|---|---|---|
| 打不开/超时 | DNS、路由、监听端口、安全组/主机防火墙、负载与磁盘 | 解析错误、域名失效、服务未起、OOM；改规则或启动服务先确认 |
| 白屏/500 | Web/PHP/应用日志、实际版本与扩展 | 语法/兼容问题、缺扩展、内存耗尽；副本重现再最小修复 |
| 502/504 | FPM socket或上游监听、进程状态、反向代理、超时与数据库 | 区分普通PHP fastcgi与Hyperf/Go/Python反代，不盲目加大超时 |
| 403 | 目录权限、入口、deny与安全策略 | 核对部署用户、运行用户及ACL，不默认chown整站 |
| 内页404 | 根目录、入口、rewrite、应用路由 | WordPress固定链接与规则不一致；保存/刷新规则需写授权 |
| 资源404/样式乱 | 资源URL状态及Content-Type、子目录base、缓存 | 漏文件、绝对路径、CDN旧版本；先比较发布清单 |
| 后台登录循环 | 站点URL、cookie、HTTPS转发、缓存 | 可信代理或域配置异常；不直接重置所有用户 |
| 证书警告 | 系统时间、域名集合、完整链、实际有效期 | 到期/域名不匹配/链缺失；优先支持界面/API处理并核实续期 |
| WordPress上传/升级失败 | 可写目录、运行用户、ACL、磁盘 | 仅修获批目录权限，不使用777 |
| 慢/时好时坏 | 负载、内存、IO、慢查询、cron、外部API | 先证据定位瓶颈，不盲目扩容或清缓存 |
| 陌生内容/账号/跳转 | 时间线、文件哈希、日志、可信基线 | 转`site-incident`，不先删文件或清日志 |
| 数据丢失 | 备份、binlog/快照、写入状态 | 先保护现场，副本验证恢复；不承诺救回 |

## 只读命令示例

目标从任务配置解析并确认；变量为空或仍为占位则停止。日志可能含个人数据或凭据，只采集必要片段并脱敏。

```bash
dig "$DOMAIN" +short
curl -I --max-time 20 "$BASE_URL"
ss -lntup
df -h && df -i
stat -c '%U:%G %a %n' "$SITE_DIR"
```

服务日志、FPM socket与配置路径现场发现，不硬编码版本。WordPress清单工具若存在，先读说明并审查只读行为，不读取或输出`wp-config.php`秘密，也不执行未知PHP。

## 修复边界

单点故障在批准范围内处理；迁移、批量升级、支付、数据覆盖、超预算或未知根因先暂停评估。停用插件、改主题、刷新规则、重签证书、重载服务均为写操作，先备份并确认；生产测试只清本任务创建且获准对象。

回滚包括文件、配置及切换后新增数据协调，不仅是改DNS或解压归档。输出证据、已证实根因、最小动作、复测和未完成项；报价与抵扣按当前合同，不内置档位。
