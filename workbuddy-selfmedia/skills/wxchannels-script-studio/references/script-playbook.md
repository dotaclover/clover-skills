# 时间轴脚本与口播稿

## 通用硬规则

| 项 | 规则 |
|---|---|
| 时间轴 | 至少 **4 段**：钩子 → 展开 → 主体 → 结尾 |
| 语速 | 约 **4–5 字/秒**（视频号偏稳，不要按抖音的快节奏写） |
| 口播稿 | 可直接念，短句为主，不用书面语 |
| 语感 | **熟人语感**——像跟认识的人讲话，不喊麦 |
| 思考间隙 | 知识点之间留停顿标记 `（停）`，给观众消化时间 |
| 收藏设计 | A / D 型必须有可存下来的东西 |

> 视频号第一指标是**收藏率**。快节奏刺激能拉完播，但拉不动收藏——这不是抖音。

## 五套时间轴骨架

### A 知识科普（60–120s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–5s | 抛结论或反常识判断 |
| ② 为什么值得听 | 5–15s | 说清看完能解决什么 |
| ③ 主体 | 15s–{N-20}s | 2–3 个要点，每点后有停顿 |
| ④ 可存下来的总结 | {N-20}s–{N-5}s | 结论清单 / 对照表（**收藏率来源**） |
| ⑤ CTA | 最后 5s | 引导收藏 |

### B 故事共鸣（60–90s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–5s | 进具体情境，画面感开场 |
| ② 背景 | 5–20s | 时间 + 处境 |
| ③ 推进 | 20s–{N-20}s | 按时间推进，情绪渐强 |
| ④ 转折 / 升华 | {N-20}s–{N-8}s | 从个案推到普遍感受（**转发率来源**） |
| ⑤ CTA | 最后 8s | 引导转发给某类人 |

### C 观点洞察（45–90s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–4s | 抛反常识结论 |
| ② 普遍看法 | 4–15s | 先说大家都怎么想 |
| ③ 理由 | 15s–{N-15}s | 2–3 条，每条后停顿 |
| ④ 让步 | {N-15}s–{N-8}s | 承认对方成立的部分 |
| ⑤ 站队钩子 + CTA | 最后 8s | 你怎么看？ |

### D 教程实操（90–180s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–5s | 抛结果（做完能怎样） |
| ② 准备 | 5–20s | 需要什么，说清前提 |
| ③ 步骤主体 | 20s–{N-25}s | 每一步一段，步骤编号要说出来 |
| ④ 常见错误 | {N-25}s–{N-10}s | 1–2 个坑 |
| ⑤ 总结 + CTA | 最后 10s | 步骤回顾（**复访率来源**），引导收藏 |

### E 热点解读（30–60s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 事件 + 你的判断 |
| ② 事实 | 3–15s | 只写已确认的，不确定的说"据【X】报道" |
| ③ 增量 | 15s–{N-8}s | 意味着什么、对观众的影响（**E 型命门**） |
| ④ CTA | 最后 8s | 引导评论 |

## 时间轴输出格式（默认交付就是这个）

| 时间段 | 这一段干什么 | 关键信息 |
|---|---|---|
| 0–5s | 钩子：抛结论 | {具体说什么} |
| 5–15s | 说清价值 | {…} |
| … | … | … |

**不要在这一步写分镜。** 时间轴是方向，分镜是第二遍。

## 口播稿规范

### 字数换算

`目标秒数 × 4.5 ≈ 口播字数`（视频号语速偏稳）

| 时长 | 口播字数 |
|---|---|
| 45s | 约 200 字 |
| 60s | 约 270 字 |
| 90s | 约 400 字 |
| 120s | 约 540 字 |
| 180s | 约 800 字 |

### 写法

1. **短句**，一句不超过 20 字。
2. **口语**，写"那""其实""你看"，不写"因此""然而"。
3. 知识点之间标 `（停）`，提示停顿。
4. 数字要说具体，但真实值留【】。
5. 整篇口播稿**可一次念完**，不写导演提示。

### 格式

```
【口播稿】约 XXX 字 / 预估 XX 秒

{正文}

（停）  ← 停顿标记
```

## 字幕规范（展开分镜时才细写）

默认只给一句原则：**字幕是口播的补充，不是复述**。
- 关键数字、清单、结论上字幕。
- 不要每句话都上字幕。

展开分镜时按镜头逐条给。

## 联动公众号

视频号与公众号打通是独特优势：视频引流至公众号图文，公众号粉丝导流至视频。
若用户同时运营公众号，在结尾提示一句联动方式。

## 自检细项（按形态查，不必每次全列）

- **A**：有可存下来的总结？知识点之间有停顿？
- **B**：情绪有起伏？结尾从个案升华到普遍感受？
- **C**：有让步？结尾有站队钩子？
- **D**：步骤编号说出来了？有常见错误段？
- **E**：有增量而不是复述？事实与判断分开了？
