# 时间轴脚本与口播稿

## 通用硬规则

| 项 | 规则 |
|---|---|
| 时间轴 | 至少 **4 段**：钩子 → 展开 → 转折 → 结尾 |
| 语速 | 约 **5–6 字/秒**（比视频号快） |
| 爆点密度 | **每 12 字左右**出现一个数字、反差或金句 |
| 口播稿 | 可直接念，短句为主，全是口语 |
| 转折 | 中段**必须有一次转折**，否则中途流失 |
| 时长 | 宁短勿长，超过 60s 需说明理由 |

> 完播率是抖音的第一指标。所有设计围绕"让人看完"：短时长、高密度、中段转折。

## 五套时间轴骨架

### A 痛点开场（30–45s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 抛痛点，让目标人群对号入座 |
| ② 原因 | 3–12s | 为什么会这样 |
| ③ 解法 | 12–{N-8}s | 具体怎么做，2–3 步 |
| ④ 转折 | 中段某处 | 一个反直觉的提醒 |
| ⑤ CTA | 最后 8s | 引导评论 |

### B 反常识钩子（20–40s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 抛反常识结论，越颠覆越好 |
| ② 验证 | 3–{N-15}s | 为什么这是真的 |
| ③ 正确方法 | {N-15}s–{N-8}s | 那应该怎么做 |
| ④ 金句收尾 + CTA | 最后 8s | 一句可传播的判断 |

### C 数字列表（30–45s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | `{N}个方法，第{X}个 99% 的人没用过` |
| ② 逐条展开 | 3–{N-10}s | 每条 8–12 秒，条与条之间要换画面 |
| ③ 强调 | {N-10}s–{N-5}s | 回指最重要那一条 |
| ④ CTA | 最后 5s | 引导收藏或评论 |

### D 剧情反转（15–30s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 进冲突现场 |
| ② 铺垫 | 3–{N-8}s | 观众以为会怎样 |
| ③ **反转** | {N-8}s–{N-5}s | 结果相反（**必须发生在最后 5 秒之前**） |
| ④ CTA | 最后 5s | 引导评论 |

### E 热点跟拍（15–25s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–2s | 直接挂热点画面或话题 |
| ② 你的角度 | 2–{N-8}s | 一个别人没说的点 |
| ③ 落点 | {N-8}s–{N-5}s | 回到自己的垂类 |
| ④ CTA | 最后 5s | 引导评论 |

## 时间轴输出格式（默认交付就是这个）

| 时间段 | 这一段干什么 | 关键信息 |
|---|---|---|
| 0–3s | 钩子：抛痛点 | {具体说什么} |
| 3–12s | 原因分析 | {…} |
| … | … | … |

**不要在这一步写分镜。** 时间轴是方向，分镜是第二遍。

## 口播稿规范

### 字数换算

`目标秒数 × 5.5 ≈ 口播字数`

| 时长 | 口播字数 |
|---|---|
| 15s | 约 80 字 |
| 20s | 约 110 字 |
| 30s | 约 165 字 |
| 45s | 约 250 字 |
| 60s | 约 330 字 |

### 写法

1. **极短句**，一句不超过 15 字。
2. **口语**，写"那""其实""你看"，不写"因此""然而"。
3. **每 12 字左右埋一个爆点**：数字、反差、金句。
4. 数字要说具体，但真实值留【】。
5. 整篇口播稿**可一次念完**，不写导演提示。

### 格式

```
【口播稿】约 XXX 字 / 预估 XX 秒

{正文}
```

---

## 字幕规范（展开分镜时才细写）

默认只给一句原则：**字幕是爆点的放大器，不是口播的复述**。
- 每个爆点（数字、反差、金句）上字幕。
- 不要每句话都上字幕——会盖住画面。

---

## 节奏设计的三个检查点

写完口播稿后自查：

1. **第 3 秒**：观众知道这条视频跟他有关吗？
2. **中段**：有没有一次转折或新信息？（防止中途划走）
3. **最后 5 秒**：有没有让人想评论或再看一遍？

---

## 自检细项（按形态查，不必每次全列）

- **A**：痛点够具体？给了几步解法？中段有转折？
- **B**：结论够颠覆？有验证过程？有金句收尾？
- **C**：条数明确？每条换画面？回指了最重要一条？
- **D**：反转在最后 5 秒之前？铺垫够？
- **E**：挂上热点了吗？有自己的角度吗？
