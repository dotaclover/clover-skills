# 发布前违禁词体检

> ⚠️ 自检清单里的"无功效承诺、无极限词"是**软自审**，不能代替这一步。
> 一条视频拍得再好，卡在审核就是零。

---

## 六类高危

| 类别 | 典型命中 |
|---|---|
| **功效承诺** | 根治、治愈、7 天见效、瘦 X 斤、包过、一次搞定 |
| **医疗用语** | 消炎、杀菌、治疗、处方、症状、疗效 |
| **极限词** | 最、第一、100%、永久、唯一、顶级、全网最低 |
| **诱导互动**（抖音高频） | 点赞过 X 更新、评论区扣 1、关注才发、不关注看不到 |
| **收益承诺** | 稳赚、保本、月入 X 万、躺赚、零风险 |
| **导流信息** | 微信号、加 V、站外二维码、其他平台水印 |

> **诱导互动是抖音最高频的违规项**——完播与互动是指标核心，平台对"用利益换互动"判定很严。

---

## 替换对照表

| 违禁 | 安全改法 |
|---|---|
| 根治 / 治愈 | 缓解 / 我自己的情况改善了 |
| 7 天见效 | 我自己试到第【X】天开始有感觉 |
| 最 / 第一 | 我个人用下来最顺手的 / 少见的 |
| 100% 有效 | 大部分情况 / 我遇到的几次都 |
| 月入 X 万 | 收入结构我是这么搭的（不给具体数） |
| 点赞过 X 更新 | 想看下一期的话评论区告诉我 |
| 关注才发 / 不关注看不到 | 下一条讲 {X}，想看可以关注一下 |
| 加微信 / 私信领取 | 完整清单我放评论区置顶了 |
| 永久 / 终身 | 很长一段时间 / 至今 |

> 替换的原则是**改成体验描述**，不是换个同义词继续吹。

---

## 体检范围：四个地方全查

| 位置 | 常见遗漏 |
|---|---|
| **标题** | 极限词、夸张前缀 |
| **口播稿** | 功效承诺、收益承诺、诱导互动 |
| **字幕** | **最容易漏**——字幕里的极限词同样会被判定 |
| **封面文案** | 主文案里的极限词与功效词 |

只查口播稿是最大的漏：**字幕和封面文案一样会被判定。**

---

## 体检流程

1. 上面四个位置各过一遍六类高危。
2. 命中就**给替换建议**，并输出**仅替换违禁词后的安全版本**（不要让用户在原文里自己找）。
3. 标出命中位置：`标题` / `口播第 X 段` / `字幕镜 N` / `封面主文案`。
4. 没命中就明说"未命中六类高危"，不要含糊带过。

---

## 两条提醒

- **词库会更新。** 不确定某个词当前是否敏感 → 联网核实，不凭记忆判断。宁可改掉也不赌。
- **变体规避无效。** 谐音、拆字、符号替代（薇信 / +V / 瘦▲斤）都会被识别，而且被判定后性质更差。别写。

---

## 画面合规（视频特有）

除了文字，画面本身也会触发审核：

- 品牌 Logo、明星脸、他人作品入镜。
- 可识别的车牌、门牌、他人肖像。
- 血腥、密集恐惧、猎奇恶心、惊悚画面。
- 未获授权的音乐与素材。
- 诱导性质的二维码与联系方式露出。

展开分镜时一并检查。
