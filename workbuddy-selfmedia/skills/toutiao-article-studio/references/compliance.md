# 发布前违禁词体检

> ⚠️ 自检清单里的"无极限词、无导流"是**软自审**，不能代替这一步。
> 一篇内容写得再好，卡在审核就是零。

---

## 七类高危（头条特有的在最后两类）

| 类别 | 典型命中 |
|---|---|
| **功效承诺** | 根治、治愈、7 天见效、瘦 X 斤、包过 |
| **医疗用语** | 消炎、杀菌、治疗、处方、症状、疗效 |
| **极限词** | 最、第一、100%、永久、唯一、顶级、全网最低、震惊 |
| **诱导互动** | 点赞过 X 更新、不转不是、评论区扣 1、关注才发 |
| **收益承诺** | 稳赚、保本、月入 X 万、躺赚、零风险 |
| **导流信息** | 微信号、QQ、电话、二维码、站外链接、其他平台水印 |
| **资质越界** | 无新闻资质写时政、无健康资质写疾病治疗与用药、无财经资质荐股荐彩 |

> **导流是头条的红线**，且会落到配图上——图片带其他平台水印同样判定。

---

## 替换对照表

| 违禁 | 安全改法 |
|---|---|
| 根治 / 治愈 | 缓解 / 我自己的情况改善了 |
| 7 天见效 | 我自己试到第【X】天开始有感觉 |
| 最 / 第一 | 我个人用下来最顺手的 / 少见的 |
| 100% 有效 | 大部分情况 / 我遇到的几次都 |
| 月入 X 万 | 收入结构我是这么搭的（不给具体数） |
| 点赞过 X 更新 | 想看下一期的话评论区告诉我 |
| 加微信 / 私信领取 | 完整版我整理在后续文章里 |
| 永久 / 终身 | 很长一段时间 / 至今 |
| 震惊 / 千万人不知 | 直接写事实，去掉夸张前缀 |

> 替换的原则是**改成体验描述**，不是换个同义词继续吹。

---

## 体检范围：四个地方全查，不是只查正文

| 位置 | 常见遗漏 |
|---|---|
| **标题** | 极限词、"震惊"类夸张前缀、标题党判定（与正文不符） |
| **正文** | 功效承诺、诱导互动、资质越界 |
| **封面与配图** | 图片带其他平台水印、封面压字、可识别车牌门牌 |
| **话题标签** | 标签本身命中敏感词 |

只查正文是最大的漏。

---

## 额外一项：标题党自查

头条对标题党按**严重性扣分**，严重的单次扣 70 分。判定核心是**标题与正文是否匹配**。

检查三问：
1. 标题承诺的信息，正文真的给了吗？
2. 标题里的数字和结论，正文能一一对应吗？
3. 标题有没有制造正文补不上的缺口？

任一为否 → 改标题，不改正文硬凑。

---

## 体检流程

1. 上面四个位置各过一遍七类高危。
2. 命中就**给替换建议**，并输出**仅替换违禁词后的安全版本**（不要让用户在原文里自己找）。
3. 标出命中位置：`标题` / `正文第 X 段` / `封面` / `标签 N`。
4. 没命中就明说"未命中七类高危"，不要含糊带过。

---

## 两条提醒

- **词库会更新。** 不确定某个词当前是否敏感 → 联网核实，或使用专业检测工具比对词库，不凭记忆判断。宁可改掉也不赌。
- **变体规避无效。** 谐音、拆字、符号替代（薇信 / +V）都会被识别，而且被判定后性质更差。别写。

---

## AI 痕迹一项（头条特有）

平台对低质 AIGC 处置力度大。发布前提示用户：

1. 【】占位**必须填真实值**再发。
2. 补充个人真实经历细节（时间、地点、不完美的过程）。
3. 勾选原创声明前，确认没有大段摘抄（引用不超过全文 10%）。

> 这一项不做替换，只做提醒——它不属于违禁词，但直接影响推荐量。
