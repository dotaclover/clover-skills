# 标题与钩子方法论

标题管**点开**，前 3 秒管**留住**，结尾 CTA 管**互动与关注**。三件事分开设计，但必须互相呼应。

快手额外一条：**标题和钩子都要"说人话"**。观众是在关注页刷到一个熟悉的人，不是在信息流里被陌生内容冲击——腔调不对，老粉也不点。

---

## 第 -1 步：先搜同类爆款（动笔前必做）

差异化是比出来的，不是想出来的。不搜就写，出来的标题大概率和平台上已有的雷同。

### A. 避让（保下限）
统计该选题在快手已有的高频标题句式，**明确避开**。
- 记下出现 ≥3 次的句式与开头词。
- 记录格式：`高频句式：___（出现 N 次）→ 避开`。

### B. 借鉴（提上限）

| 借鉴什么 | 具体看 |
|---|---|
| **开场方式** | 前 3 秒是直接说话、直接干活还是先进场景 |
| **真实感来源** | 爆款里哪些细节让人觉得"这是真的" |
| **对话感** | 怎么跟老铁说话，在哪几个点互动 |
| **结尾话术** | 怎么引导关注与评论 |

输出一句：`借鉴点：___（来自哪类爆款）`。

**搜不到就跳过**，写"未搜到同类爆款，按机制出"。不要假装搜过。

---

## 七种标题机制

### 1. 激发好奇心 — 信息缺口
只给一半，缺口靠点开补。
- 快手版写法要**口语化**："你猜怎么着"好过"真相令人震惊"。

### 2. 借热点趋势 — 进搜索与推荐池
热点、季节、本地话题。快手的热点更偏生活化与本地化。

### 3. 增加互动性 — 诱发表达欲
反问、提问、直接问老铁。
- **这是快手最强的一档**：平台互动文化浓，直接发问的标题效果最好。

### 4. 数据利益法 — 数字 + 痛点 + 结果
`{数字} + {痛点} + {结果}`。
- 实用技能类最常用，数字要具体。

### 5. 制造紧张感 — 警示避坑
必须给出路，只制造焦虑不给方法会掉完播。

### 6. 引发共鸣 — 覆盖共同处境
打工、养家、种地、开店、带娃——**下沉市场的真实处境**。
- 共鸣型在快手的关注转化率最好。

### 7. 提供实用价值 — 直白点明收益
`{问题}咋解决，{N}步搞定`——复看率最高的一档。

## 前 3 秒钩子（3 条，与标题配套）

### 四种开场方式

| 方式 | 适用 | 写法 |
|---|---|---|
| **直接说话** | B / C 型 | 第一句就对着镜头说，像跟熟人开口 |
| **直接干活** | A 型 | 第一秒就在操作，不解释 |
| **抛结果** | A / C 型 | 先给做完的样子，再回溯过程 |
| **进冲突现场** | D / E 型 | 第一句进情境 |

### 禁止的开场

- ❌ 自我介绍 + 寒暄："大家好我是 XX，今天给大家…"
- ❌ 慢启动：前三秒还在切镜头、等 BGM
- ❌ 端着说话：官方腔、书面语
- ❌ 喊麦式："老铁们！三秒钟教会你！"——快手要真实，不要表演

### 格式

```
钩子 1（配标题 1）：{口播第一句} —— 留人机制：{为什么能留住}
```

## 结尾 CTA（关注与互动优先）

快手指标：**完播率 + 互动率**，且**关注转化与复看**权重高。

CTA 选一个主打：

| 目标 | 话术方向 |
|---|---|
| **关注**（首选） | "下一条讲 {X}，想看的点个关注" |
| **评论** | "你们那儿是怎么弄的？评论区说说" |
| **复看** | "第 {N} 步容易忘，存下来慢慢看" |
| **互动** | "有同款情况的扣个 1" → **改为**"有同款情况的评论区说说" |

**禁止**：点赞过 X 更新、评论区扣 1、关注才发、私信领取。

## 五维评分表

| 维度 | 看什么 | 分值 |
|---|---|---|
| **人群匹配** | 目标人群一眼认出"这说的就是我" | 20 |
| **信息缺口** | 有没有让人想点开的未补全信息 | 20 |
| **真实感** | 是否像本人说话，有没有端着（**快手核心**） | 20 |
| **结构合规** | 长度适合手机端、含数字或场景词、口语化 | 20 |
| **平台差异** | 是否避开已统计的高频句式 | 20 |

**等级**：≥85 优｜70–84 可用｜55–69 需改｜<55 重出。

**精简档输出**：每条只给「总分 + 最低维度」。推荐那条可展开五维明细。

---

## 差异化检查

1. **机制去重**：三条必须三种机制。凑不齐 = 采集信息不够，回去补，不许硬凑。
2. **句式去重**：不要都以同一个词开头。
3. **腔调检查**：三条都要说人话，任一端着就重出。

---

## 推荐规则

- **推荐 1 条**：说明为什么最配这个形态。
- **给一句选择建议**：`要完播率选 X，要关注转化选 Y`。

---

## 扩展模式

用户说「多给几个 / 出 10 条」才切：出 10 条，同机制最多 2 次，只给推荐与备选打分，表下方写机制分布。
