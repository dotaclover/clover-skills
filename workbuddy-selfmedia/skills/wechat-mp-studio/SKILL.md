# 公众号文章工坊

四个模块：**选题 → 标题 → 正文（+ 排版）→ 封面（+ 配图）**，发布前过**违禁词体检**。

**三条底线**
- **零预设**：不含任何预设垂类、人群、话术，全部由当次输入或用户画像推断填充。
- **零编造**：数据、案例、时间地点、个人经历一律留【】占位。见 `references/truthfulness.md`。
- **零刷量**：刷阅读、互阅群、利益诱导分享——检测到直接降权。

> 本 Skill 自洽独立，不依赖任何外部技能或平台能力，可单独分发使用。

---

## 公众号的三条平台铁律

| # | 规则 | 后果 |
|---|---|---|
| 1 | **完读率权重约 35%，分享转发率约 30%** | 二者合计决定推流，远高于标题打开率 |
| 2 | **订阅 + 算法双引擎** | 不勾原创、不开"允许被平台推荐"，就只有订阅流量 |
| 3 | **搜一搜是长期流量口** | 标题与首段不埋长尾关键词，就吃不到搜索流量 |

**第 1 条决定了：转发诱因必须提前设计**，不能指望读者自发分享——在文章 25% / 50% / 75% 位置埋设。

---

## 第 0 步：给预设场景卡，不问一串问题

**不要一次抛出 6 个问题。** 正确做法是：先拼出一段**完整的预设场景文本**给用户改。

推断来源，按优先级取：
1. **本次对话已给的信息**（最高优先级）
2. **用户画像与历史记忆**（赛道、人群、过往选题、表达偏好）
3. **该垂类的常识值** —— 取用时必须在文本里标 `（推断，可改）`

**只有「本篇内容」是必填项**。其余全部预设好。

模板与推断规则见 `references/input-brief.md`。

---

## 四条铁律

1. **先有人群，后有标题。** 同一机制填不同人群得出完全不同的标题。
2. **形态决定骨架。** 先定 A/B/C/D/E，再动笔。
3. **标题出 3 条，三条三种机制。** 凑不齐三种机制 = 采集信息不够，回去补，不许硬凑。
4. **每个观点配一句金句。** 金句是转发率的直接来源——人们转的是那句话，不是那篇文章。

## 形态路由

| 形态 | 适用 | 主攻 | 字数 | 标题主机制 | 小标题 | 配图 |
|---|---|---|---|---|---|---|
| **A 深度故事** | 个人经历、案例复盘、真实故事 | 完读+转发 | 1500–2000 | 共鸣 / 好奇心 | 要 | 4–6 |
| **B 清单干货** | {数字}个方法、教程、实操步骤 | 完读+收藏 | 1500–2000 | 实用价值 / 数字 | 要 | 4–6 |
| **C 测评对比** | 多方案横评、工具对比 | 完读+收藏 | 1500–2000 | 好奇心 / 数字 | 要 | 4–6 |
| **D 观点站队** | 反常识判断、行业立场 | 转发+留言 | 1200–1800 | 观点 / 反问 | 要 | 3–4 |
| **E 观察解读** | 趋势判断、行业观察、事件解析 | 转发 | 1500–2000 | 观点 / 热点 | 要 | 4–6 |

**判断**：发生过的事 → A｜能照着做 → B｜几个东西比一比 → C｜我认为 XX 是错的 → D｜在看一个趋势 → E。

**三条硬例外**
- **所有形态都用总分总**：开头抛核心观点 → 中间分点 → 结尾升华。公众号读者是"订阅后主动打开"，结构预期和小红书不同。
- **D 型态度必须鲜明**：观点类最忌两边都不得罪，那等于没观点。
- **结尾必须留互动口**：提问或引导留言，但不许用利益诱导。

## 分支：旧文诊断

用户给的是**已发布文章 + 数据差** → 走诊断，**不重新采集**。

| 层 | 看什么 | 常见病灶 |
|---|---|---|
| 1 标题 | 15–22 字、有无痛点或数字 | 太泛；或被手机端截断 |
| 2 开头 3 句 | 是否直击主题 | 寒暄铺垫，读完前 3 句还不知道在讲什么 |
| 3 结构 | 小标题、分段、层次 | 无小标题，一整片文字 |
| 4 转发设计 | 25%/50%/75% 位置有无诱因 | 通篇干货但没有一句可转发的金句 |
| 5 排版 | 字号行距、主色数量 | 花哨配色、大段不换行 |
| 6 合规 | 是否被限流 | 诱导分享、洗稿、敏感表述 |

输出：**先给诊断结论（哪 1–2 层是主因），再给改写版本**。

> 后台数据对应的改法：打开率低 → 改标题和封面；完读率低 → 改开头和结构；转发率低 → 补金句和实用价值；取关率升高 → 选题偏离粉丝需求。

## 交付规格（精简档）

| # | 项目 | 规格 |
|---|---|---|
| 1 | **标题 ×3** | 表格 `标题/机制/评分`，标 ⭐ 推荐 1 条，均 15–22 字 |
| 2 | **摘要** | 约 20 字，提炼核心价值 |
| 3 | **正文** | 可复制成稿，1500–2000 字，含小标题与金句 |
| 4 | **排版参数** | 字号 / 行距 / 字距 / 段间距 / 主色，可直接套用 |
| 5 | **封面与配图** | 封面文案策略 + 配图位置与内容建议 |
| 6 | **违禁词体检** | 命中项 + 替换后的安全版本 |
| 7 | **自检** | 勾选结果 |

不输出思路说明与过程分析。用户要"多给几个 / 出 10 条" → 切 `title-playbook.md` 扩展模式。

## 填写策略：先简后拆（不要一次填满）

| 产物 | 第一遍：简版（必出） | 第二遍：拆解展开（确认后 / 用户要求时） |
|---|---|---|
| **预设场景卡** | 1 行本篇内容 + 其余预设值 | 补全四类关键词 |
| **标题评分** | 每条：总分 + 最低维度 | 推荐那条展开五维明细 |
| **配图** | 张数 + 每张一句内容建议 | 每张展开构图与取材方式 |
| **排版** | 直接给完整参数（这项不用拆） | — |
| **自检** | 必检 8 项 | 按形态展开细项 |

**规则**
- 第一遍出**方向性内容**，等用户确认方向。
- 用户说「展开 / 继续 / 细化」才出第二遍。
- **用户没确认方向前，不要把重型模板全部填满。**

## 标准流程

1. **预设场景卡** — 拼一段完整场景文本给用户改，只等「本篇内容」
2. **搜同类爆款** — 标题避让 + 结构借鉴（见 title-playbook 第 -1 步）
3. **定形态** A/B/C/D/E，说明依据
4. **标题 ×3** — 三种机制，各附评分，均 15–22 字
5. **摘要** — 约 20 字
6. **正文** — 总分总骨架，真实细节留【】占位，埋转发诱因
7. **排版参数**
8. **封面与配图**
9. **违禁词体检** — 标题 + 正文 + 封面文案全过一遍
10. **自检**附末尾

---

## 输出格式约定

- 标题用**表格**，不用纯列表。
- 正文直接给成稿，不写"思路"。
- 占位符统一【】，正文上方声明"需要你填的 N 处"。
- 标题 **15–22 字**，超出会被手机端截断。
- 金句单独成行并加粗，方便读者截图转发。

---

## 自检清单（必检 8 项）

- [ ] **标题**：三条三种机制，均 15–22 字，评分均 ≥ 70
- [ ] **开头**：前 3 句直击主题，无寒暄铺垫
- [ ] **结构**：总分总，小标题清晰，字数 1500–2000
- [ ] **金句**：每个核心观点至少一句，已加粗可截图
- [ ] **转发诱因**：25% / 50% / 75% 位置至少埋了 2 处
- [ ] **排版**：参数齐全，主色 ≤ 2 种，未用纯黑
- [ ] **真实性**：【】占位全部列出，没有一处是我替他填的
- [ ] **合规**：标题 + 正文 + 封面文案全部过违禁词，无利益诱导分享

> ⚠️ 自检是**软自审**，不能代替违禁词体检。详见 `references/compliance.md`。

---

## 禁止事项

- **标题党**：标题与正文不符，完读率暴跌后算法停止推荐。
- **诱导分享**：不转不是、转发才能看、集赞解锁——直接违规。
- **刷量与互阅群**：异常设备访问判定无效流量，账号降权。
- **洗稿搬运**：轻度改写会被原创检测命中，降权。
- **极限词与绝对化**：最、第一、100%、永久、唯一、根治。
- **广告占比超 20%**：过度营销触发限流。
- **变体规避**：谐音、拆字、符号替代——同样会被识别。
- **编造细节**：把【】当真实内容发出，或替用户填"看起来合理"的值。
- **只戳痛点不给解法**。
