# 发布前违禁词体检

> ⚠️ 自检清单里的"无功效承诺、无绝对化用语"是**软自审**，不能代替这一步。
> 一篇内容写得再好，卡在审核就是零。

---

## 六类高危

| 类别 | 典型命中 |
|---|---|
| **功效承诺** | 瘦 X 斤、7 天见效、根治、治愈、美白淡斑、一次搞定 |
| **医疗用语** | 消炎、杀菌、治疗、处方、症状、疗效 |
| **极限词** | 最、第一、100%、永久、唯一、顶级、国家级、全网最低 |
| **诱导互动** | 点赞过 X 更新、不转不是、加微信、私信领取、评论区扣 1、关注才发 |
| **收益承诺** | 稳赚、保本、月入 X 万、躺赚、零风险 |
| **变体规避** | 谐音、拆字、符号替代（薇信 / +V / 瘦▲斤 / 最灬）——**同样会被识别** |

---

## 替换对照表

| 违禁 | 安全改法 |
|---|---|
| 瘦 X 斤 | 视觉上收紧了 / 穿起来利落了 |
| 7 天见效 | 我自己试到第【X】天开始有感觉 |
| 根治 / 治愈 | 缓解 / 我自己的情况改善了 |
| 最 / 第一 | 我个人用下来最顺手的 / 少见的 |
| 100% 有效 | 大部分情况 / 我遇到的几次都 |
| 加微信 / 私信领取 | 完整版我整理在收藏夹了 |
| 月入 X 万 | 收入结构我是这么搭的（不给具体数） |
| 点赞过 X 更新 | 想看下一期的话评论区告诉我 |
| 永久 / 终身 | 很长一段时间 / 至今 |
| 国家级 / 顶级 | 我见过里排前面的 |

> 替换的原则是**改成体验描述**，不是换个同义词继续吹。

---

## 体检范围：四个地方全查，不是只查正文

| 位置 | 常见遗漏 |
|---|---|
| **标题** | 极限词、"最"字开头的夸饰 |
| **正文** | 功效承诺、诱导互动 |
| **封面文案** | 主副文案里的极限词、功效词 |
| **话题标签** | 标签本身命中敏感词 |

只查正文是最大的漏——封面和标签一样会被判定。

---

## 体检流程

1. 上面四个位置各过一遍六类高危。
2. 命中就**给替换建议**，并输出**仅替换违禁词后的安全版本**（不要让用户在原文里自己找）。
3. 标出命中位置：`标题` / `正文第 X 段` / `封面主文案` / `标签 N`。
4. 没命中就明说"未命中六类高危"，不要含糊带过。

---

## 两条提醒

- **词库会更新。** 不确定某个词当前是否敏感 → 联网核实，不凭记忆判断。宁可改掉也不赌。
- **变体规避无效。** 谐音、拆字、符号替代都会被识别，而且被判定后性质更差。别写。
