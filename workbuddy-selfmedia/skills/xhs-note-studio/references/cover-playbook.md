# 封面设计

封面图和封面文案必须**基于本篇已定的标题与正文**生成，三层文案从标题和正文里提炼，不另起炉灶写新观点。

## 基础规范

| 项 | 值 |
|---|---|
| 画幅 | 3:4（1080×1440） |
| 安全区 | 顶部 15%、底部 20% 不放关键文字 |
| 主文案 | ≤ 12 字，字高 ≥ 画面高度 1/8 |
| 副文案 | ≤ 18 字｜角标 ≤ 8 字 |
| 缩略图测试 | 缩到 200×260px 仍能读出主文案 |

## 五大方法

| 方法 | 画面做法 | 文案方向 |
|---|---|---|
| **情绪化** | 真实表情，弱化摆拍，生活化场景 | `谁懂啊` / `终于不……了` |
| **价值外显化** | 把"能得到什么"直接印在封面上 | `{数字}招` / `{数字}套公式` |
| **痛点突出化** | 放大问题部位或错误示范，圈/箭头标注 | `别再……了` |
| **善用对比** | 左右或上下分屏，中间加分割线或 VS | `改一个细节` / `之前 vs 之后` |
| **借力打力** | 绑定当季趋势词、节日、平台热梗 | `今年最火的 {趋势词}` |

## 选方法的依据：形态 + 标题类型

| 形态 | 首选 | 备选 |
|---|---|---|
| A 单点放大 | **痛点突出化**（把"物证"做成主体：小票 / 账单 / 报错截图）+ 情绪化辅助 | 情绪化 |
| B 清单干货 | 价值外显化 | 对比 |
| C 测评对比 | 对比 | 价值外显化 |
| D 观点站队 | 情绪化（用表情传态度） | 借力打力 |

> A 型关键：**冲击力来自物证本身，不是人脸。** 那张小票比任何文案都更有说服力。

## 封面文案三层

```
主文案（≤12字，最大字号）：结论或最大利益
副文案（≤18字，中等字号）：补场景或补人群
角标（≤8字，小字色块）：痛点词或紧迫感
```
同时给**一条备选主文案**（情绪更强但损失数字冲击力的版本），让用户二选一。

## 中文生图提示词（九段）

**先填简版 3 段确认方向，再补全九段。** 一次填九段很容易整体跑偏——先让画面方向对，再补细节。

**简版（第一遍必出）**

```
【主体】{年龄}岁{面孔特征}，{与选题相关的外形特征}
【场景】{室内/街景/户外}，{背景描述}
【风格】{风格流派}，色调 {冷暖与饱和度}
```

**完整九段（确认后补全，按顺序拼装）**

```
【画幅】竖版 3:4 小红书封面摄影
【主体】{年龄}岁{面孔特征}，{与选题相关的外形特征}
【造型】{主体物描述}，{材质与颜色}
【姿态】{站/坐/走}，{具体动作}，表情 {情绪}
【构图】{分屏/居中/三分法}，{留白位置给文字}
【场景】{室内/街景/户外}，{背景描述}
【光线】{自然光/柔光/逆光}，{时间段与方向}
【风格】{风格流派}，色调 {冷暖与饱和度}
【画质】高清，真实质感，不过度磨皮，4K
```
非人物类选题：把【主体】【姿态】换成【产品主体】【摆放方式】，其余不变。

## 负面提示词

```
畸形手指，多余肢体，扭曲比例，过度磨皮，塑料质感，
水印，文字乱码，品牌 Logo，低分辨率，过曝，面部畸变，穿模
```
按选题补：人物类加"不自然身体比例"；街景加"清晰车牌号、可识别门牌"；票证类加"**票面文字乱码**"（必加）。

## 交付格式

1. **方法**：选了哪套，为什么配这条标题
2. **版式**：分屏 / 居中 / 上下，人物占哪，文字压在哪
3. **文案三层** + 备选主文案
4. **中文生图提示词**（整段可粘贴）
5. **负面提示词**
6. **备选方案**：1 个不同方法的简版

## 两条硬提醒

- 生图模型渲染**文字极不稳定** → **先生成无字画面，再用 Canva / 稿定 / 美图加字**。
- 不出现品牌 Logo、清晰车牌、可识别的他人面孔——侵权风险，不是审美问题。
