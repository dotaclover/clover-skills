# 小红书笔记工坊

四个模块：**选题 → 标题 → 正文 → 封面（+ 配图）**，发布前过**违禁词体检**。

**两条底线**
- **零预设**：不含任何预设垂类、人群、话术，全部由当次输入或用户画像推断填充。
- **零编造**：工具名、数据、金额、时长、地点、个人经历细节一律留【】占位。见 `references/truthfulness.md`。

> 本 Skill 自洽独立，不依赖任何外部技能或平台能力，可单独分发使用。

---

## 第 0 步：给预设场景卡，不问一串问题

**不要一次抛出 6 个问题。** 正确做法是：先拼出一段**完整的预设场景文本**给用户改。

推断来源，按优先级取：
1. **本次对话已给的信息**（最高优先级）
2. **用户画像与历史记忆**（赛道、人群、过往选题、表达偏好）
3. **该垂类的常识值** —— 取用时必须在文本里标 `（推断，可改）`

**只有「本篇内容」是必填项**——AI 不可能知道这次要讲哪件事，必须用户给。其余全部预设好。

模板与推断规则见 `references/input-brief.md`。

---

## 四条铁律

1. **先有人群，后有标题。** 同一机制填不同人群得出完全不同的标题。
2. **形态决定骨架。** 先定 A/B/C/D，再动笔。故事型生搬硬套倒金字塔会毁掉画面感。
3. **标题出 3 条，三条三种机制。** 凑不齐三种机制 = 采集信息不够，回去补，不许硬凑。
4. **真实细节一律留占位。** 编造的细节是内容事故，不是效率。

## 形态路由

| 形态 | 适用 | 主攻 | 字数 | 标题主机制 | 小标题 | 配图 |
|---|---|---|---|---|---|---|
| **A 单点放大** | 一件事 / 一个瞬间（踩坑实录、热点事件） | 共鸣→评论 | 300–450 | 共鸣 / 数据 / 好奇心 | 不要 | 0–1 |
| **B 清单干货** | {数字}招、公式、步骤、避坑清单 | 收藏 | 250–400 | 实用价值 / 数据利益 | 要 | 2–3 |
| **C 测评对比** | 同条件不同结果、多方案横评 | 收藏+评论 | 300–450 | 好奇心 / 数据利益 | 要 | 2–3 |
| **D 观点站队** | 反常识判断、立场表态 | 评论 | 200–350 | 好奇心 / 互动性 | 可选 | 0–1 |

**判断**：发生过的事 → A｜可照抄的方法 → B｜几个东西比一比 → C｜我认为 XX 是错的 → D。

**两条硬例外**
- A 型**不遵守倒金字塔**——开场给最强画面，不是结论。
- A 型结尾**必须挂避坑/经验 N 条**，否则只有共鸣没有收藏。

## 分支：旧笔记诊断

用户给的是**已发布笔记 + 数据差** → 走诊断，**不重新采集**。

按顺序定位问题，每层给一句结论 + 改写方向：

| 层 | 看什么 | 常见病灶 |
|---|---|---|
| 1 标题 | 有没有锚点词、信息缺口、数字 | 太泛，谁都能套用 |
| 2 开头 2 行 | 有没有结论或最强画面 | 寒暄铺垫，前 2 行没信息 |
| 3 结构 | 分段、短句、小标题 | 大段不换行 |
| 4 干货密度 | 有没有可照抄的清单 | 全是感受，没有方法 |
| 5 封面 | 主文案可读性、物证是否突出 | 字太小 / 图不对题 |
| 6 违禁词 | 是否被限流 | 命中功效、极限、诱导词 |

输出：**先给诊断结论（哪 1–2 层是主因），再给改写版本**。不要六层平均用力——数据差通常只有一两个主因。

## 交付规格（精简档）

| # | 项目 | 规格 |
|---|---|---|
| 1 | **标题 ×3** | 表格 `标题/机制/评分`，标 ⭐ 推荐 1 条 |

| 3 | **话题标签** | 1 大词 + 中词 + 长尾，总数 5–8 |

## 填写策略：先简后拆（不要一次填满）

重型产物分两遍出，**第一遍只给方向，确认后再展开细节**。一次铺满九段提示词、15 个分数、20 项勾选，既吃力又容易整体返工。

| 产物 | 第一遍：简版（必出） | 第二遍：拆解展开（确认后 / 用户要求时） |
|---|---|---|
| **预设场景卡** | 1 行本篇内容 + 其余预设值 | 补全四类关键词 |
| **标题评分** | 每条：总分 + 最低维度 | 推荐那条展开五维明细 |
| **生图提示词** | 3 段：主体 / 场景 / 风格 | 补全到九段 |
| **配图** | 张数 + 每张一句用途 | 每张展开提示词 + 负面词 |
| **自检** | 必检 8 项 | 按形态展开细项 |

**规则**
- 第一遍出**方向性内容**，等用户确认方向。
- 用户说「展开 / 继续 / 细化」才出第二遍。
- **用户没确认方向前，不要把重型模板全部填满。**

## 标准流程

1. **预设场景卡** — 拼一段完整场景文本给用户改，只等「本篇内容」
2. **搜同类爆款** — 标题避让 + 结构借鉴（见 title-playbook 第 -1 步）
3. **定形态** A/B/C/D，说明依据
4. **标题 ×3** — 三种机制，各附评分
5. **正文** — 按形态骨架，真实细节留【】占位
6. **话题标签**
7. **封面** — 主方案 + 备选方法简版
8. **配图 ×0–3** — 按形态定数量，标发布顺序
9. **违禁词体检** — 标题 + 正文 + 封面文案 + 标签全过一遍
10. **自检**附末尾

---

## 输出格式约定

- 标题用**表格**，不用纯列表。
- 正文直接给成稿，不写"思路"。
- 占位符统一【】，正文上方声明"需要你填的 N 处"。
- 生图提示词给**中文整段**可粘贴，附负面提示词。
- 标题 **≤ 20 字最佳，> 24 字折叠**。

---

## 自检清单（必检 8 项）

- [ ] **标题**：三条三种机制，评分均 ≥ 70
- [ ] **正文**：符合形态骨架（A 画面开场 + 结尾清单｜B 结论前置 + 分点小标题）
- [ ] **真实性**：【】占位全部列出，没有一处是我替他填的
- [ ] **封面**：主文案 ≤ 12 字，缩到 200×260px 可读
- [ ] **配图**：数量在区间内，标了发布顺序，首图是封面，无凑数
- [ ] **合规**：标题 + 正文 + 封面文案 + 话题标签**全部**过违禁词（不只查正文）
- [ ] **合规**：六类高危都查了，命中的给了安全版本
- [ ] **核实**：趋势词与爆款结构已联网核实

> ⚠️ 自检是**软自审**，不能代替违禁词体检。详见 `references/compliance.md`。
> 形态细项（小标题、对比维度、站队钩子等）见 `copy-playbook.md`，按需检查，不必每次全列 16 项。

---

## 禁止事项

- **标题作弊**：标题党到与正文无关，会被限流。
- **功效承诺**：瘦 X 斤 / 7 天见效 / 根治 → 改用视觉或体验描述。
- **绝对化用语**：最、第一、100%、永久、唯一、根治。
- **诱导互动**：点赞过 X 更新 / 加微信 / 私信领取 / 评论区扣 1。
- **变体规避**：谐音、拆字、符号替代（薇信 / +V / 瘦▲斤）——同样会被识别，别写。
- **侵权元素**：品牌 Logo、明星脸、他人作品、可识别车牌与门牌。
- **编造细节**：把【】当真实内容发出，或替用户填"看起来合理"的值。
- **凑数配图**。
- **只戳痛点不给解法**。
