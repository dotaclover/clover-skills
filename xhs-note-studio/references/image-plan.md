# 正文配图（0–3 张）

配图和封面是两件事：**封面是广告位，配图是证据 / 说明书。**

## 发布顺序（交付时必须给）

**首图 = 封面**，配图从位置 2 开始排：

```
位置 1  封面
位置 2  配图 1
位置 3  配图 2
位置 4  配图 3
```

- 小红书单篇最多 9 张，本 skill 建议 **≤ 4 张**（1 封面 + 3 配图）——图多了阅读成本高，且第 5 张之后几乎没人滑到。
- 交付时给出完整顺序，不要只给一堆图让用户自己排。

## 与封面的三个区别

| | 封面 | 配图 |
|---|---|---|
| 作用 | 争取点击 | 证内容、降阅读成本 |
| 构图 | **必须留白压字** | 通常**满幅，不留白**（清单总图除外） |
| 文字 | 三层文案 | 一般不带字 |
| 画幅 | 3:4 固定 | 3:4 或 1:1，一组内保持一致 |

## 数量（按形态，不突破上限）

| 形态 | 数量 | 说明 |
|---|---|---|
| A 单点放大 | **0–1** | 故事靠文字打，图多了稀释情绪 |
| B 清单干货 | **2–3** | 每 1–2 条干货一张，或结尾 1 张清单总图 |
| C 测评对比 | **2–3** | 每个对象一张 + 1 张同框对比 |
| D 观点站队 | **0–1** | 观点靠文字，图可有可无 |

> **0 张是合法答案。** 纯文字情绪流不放图反而更真诚。不凑数。

## 六种类型

| 类型 | 适用 | 拍什么 | 留白加字 |
|---|---|---|---|
| 场景图 | A | 还原正文最有画面感的瞬间 | 不要 |
| 物证特写 | A / B | 小票、账单、报错截图、产品局部 | 不要 |
| 步骤图 | B | 一个关键步骤一张 | 不要 |
| 清单总图 | B | N 条做成一张可保存的图 | **要** |
| 对比图 | C | 左右 / 上下分屏同框 | 可选 |
| 结果图 | B / C | 最终效果 | 不要 |

**选型原则**：一张图只服务**一个信息点**。说不清要表达什么 → 它不该做。

## 中文生图提示词（八段，比封面少【留白】段）

> 配图提示词属于**第二遍**。第一遍只给「张数 + 每张一句用途」，用户确认后再展开这里。

```
【画幅】竖版 3:4（或方版 1:1）配图摄影
【主体】{主体物 / 人物}，{与这个信息点直接相关的特征}
【造型】{材质、颜色、状态}
【姿态】{摆放方式 / 动作}，{关键细节}
【构图】{居中 / 特写 / 俯拍 / 平视}，{要不要留白}
【场景】{环境描述}，{背景元素}
【光线】{自然光/柔光/侧光}，{时间段}
【风格】{风格流派}，色调 {冷暖与饱和度}，高清，4K
```

## 负面提示词

```
文字乱码，水印，品牌 Logo，低分辨率，过曝，畸变，多余肢体，塑料质感，穿模
```
按类型补：物证特写加"票面/屏幕文字乱码"；场景图加"清晰车牌号、可识别门牌、他人清晰面孔"；产品图加"扭曲 Logo、错乱接口"。

## 交付格式（四行一张，不长篇）

```
配图 N / 放在正文第 X 段后 / 用途：{一句话说明它证明什么}
提示词：{中文整段，可粘贴}
负面词：{通用 + 专属}
```
结尾声明**哪几张需要后期加字**（清单总图 / 带标注的对比图）。

## 校验

- [ ] 数量在区间内？没凑数？
- [ ] 每张对应正文某个段落（能说出"放第几段后"）？
- [ ] 每张只有一个信息点？
- [ ] 需要加字的几张已标注？
- [ ] 无 Logo、无可识别车牌门牌、无他人清晰面孔？
