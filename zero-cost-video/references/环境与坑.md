# 环境与坑

## 一、开工前自检

```bash
bash scripts/check_env.sh
```

| 依赖 | 期望 | 说明 |
| --- | --- | --- |
| Python | `/usr/bin/python3` → 3.12.3 | ⚠️ **不要用 `python3`**，它指向 pyenv 3.11，没有 edge-tts |
| edge-tts | 7.2.8 | 免费 TTS，走微软 Edge 的在线接口 |
| Pillow | ≥ 10 | 画底图与弹幕 PNG |
| ffmpeg | N-124111+ | 在 `/usr/local/bin/ffmpeg` |
| 字体 | NotoSansCJK-Bold.ttc | `/usr/share/fonts/opentype/noto/` |

缺依赖时：

```bash
# Python 包（Ubuntu 24.04 有 PEP 668 保护，必须加 --break-system-packages）
/usr/bin/pip3 install edge-tts pillow --break-system-packages

# 中文字体
apt-get update -qq && apt-get install -y fonts-noto-cjk
```

> `python3` 和 `/usr/bin/python3` 在这台机器上不是同一个解释器。
> 用错的表现是 `ModuleNotFoundError: edge_tts`，装到 `/usr/bin/pip3` 也不管用——
> 因为装进了另一个 Python。**运行和安装必须都带绝对路径。**

## 二、本机 ffmpeg 的三个硬限制

| 限制 | 症状 | 对策 |
| --- | --- | --- |
| **没有 `libx264` / `libx265`** | `Unknown encoder 'libx264'` | 一律用 **`libopenh264`**，配 `-b:v 6M`（不能用 `-crf`） |
| **没有 `eq` 滤镜** | `No such filter: 'eq'` | 亮度/对比度/饱和度在 **PIL 里调**，别写进 ffmpeg |
| 其余常用滤镜正常 | — | `zoompan` `overlay` `xstack` `amix` `adelay` `alimiter` `drawtext` 都可用 |

判断某个编码器能不能用，**不要信 `-h encoder=xxx` 的返回码**（加 `-hide_banner` 时尤其不可靠）。
用试编法：

```bash
ffmpeg -f lavfi -i color=c=red:s=64x64:d=0.1 -c:v $enc -f null -
```

## 三、踩坑对照表

| 症状 | 原因 | 解法 |
| --- | --- | --- |
| `ModuleNotFoundError: edge_tts` | PEP 668 保护 / 用错 Python | 装到 `/usr/bin/pip3 --break-system-packages`，运行时用 `/usr/bin/python3` |
| `Unknown encoder 'libx264'` | 本机 ffmpeg 未编入 x264 | 换 `libopenh264`，`-crf` 换 `-b:v 6M` |
| `No such filter: 'eq'` | 滤镜缺失 | 亮度/对比度改在 PIL 里做；或用 `lutrgb` / `colorlevels` |
| `NoAudioReceived` + 截断 MP3 | edge-tts 并发被限流 | **串行 + sleep + 重试**，并判 `getsize > 1200` |
| `Unable to locate fonts-noto-cjk` | 没更新源 | 先 `apt-get update -qq` |
| `Filtergraph 'scale=...' was specified for a stream fed from a complex filtergraph` | 复杂链外又挂了 `-vf` | `scale` 写进 `filter_complex` 链内 |
| 开头几秒没画面 | 弹幕起始时间写太大 | 起点写 `0.05` |
| 结尾人声见底 | 副轨提前跑完 | 放宽副轨间隔，让末条落在 DUR−1 秒内 |
| `-h encoder=xxx` 判断编码器可用性 | 返回码不可靠 | 用试编法（见上） |
| 推拉时露黑边 | 没先放大就 zoompan | 先 `scale` 到 1.1 倍再 zoompan |
| 人声叠多了反而变小 | amix 默认自动归一化 | 加 `normalize=0` |

## 四、换机器的检查顺序

这套参数是按一台具体的 Linux 服务器写的。换机器按这个顺序过一遍，别跳：

1. `which -a python3` 确认有没有多个解释器
2. `/usr/bin/python3 -c "import edge_tts, PIL"` 两个包是否都在
3. `ffmpeg -encoders | grep -E "264|openh264"` 看有什么编码器
4. `ffmpeg -filters | grep -E " eq | zoompan | xstack "` 看滤镜
5. `fc-list | grep -i noto | grep -i cjk` 看字体
6. 跑一次 15 秒最小样片，把第 0.1 / 7 / 14.5 秒抽帧看一眼

第 3 步的结果直接决定 `build.py` 里的编码参数——**不要沿用别人的 `-c:v libx264`**。
