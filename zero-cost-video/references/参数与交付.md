# 参数与交付

## 一、参数速查

| 参数 | 建议值 | 改哪里 |
| --- | --- | --- |
| 画幅 | 1080×1080（朋友圈）/ 1080×1920（竖屏）/ 1920×1080（横屏） | `build.py --size` |
| 帧率 | 30 | `build.py` 的 `FPS` |
| 弹幕密度 | 8 条/秒（短）/ 5 条/秒（长） | `plan_timeline.py --danmaku` |
| 弹幕停留 | 1.5–2.1 秒 | `build.py` 的 `random.uniform` |
| 弹幕字号 | 38–80px；结尾大字 96–126px | `build.py` 的字号列表 |
| 竖向弹幕 | 5% | `random.random() < 0.05` |
| 人声音量 | 主轨 0.60 / 副轨 0.44 | `build.py` 的 `vol` |
| 底图推拉 | ±4% | `zoompan` 的 `0.04*sin` |
| 视频码率 | 6M（1080p）/ 7M（弹幕密集时） | `build.py` 的 `-b:v` |
| 描边半径 | 5px 圆形范围 | `build.py` 弹幕绘制段 |
| 时间轴起点 | 0.05 | `plan_timeline.py` |

## 二、出片后自检（每次必做）

```bash
# 1) 参数对不对
ffprobe -v error -show_entries format=duration \
  -show_entries stream=codec_name,width,height,r_frame_rate \
  -of default=noprint_wrappers=1 成片.mp4

# 2) 抽帧目检：第 0.1 秒（查开头白区）+ 中间 + 结尾（查水印还在不在）
for t in 0.1 2 7 14.5; do
  ffmpeg -v error -ss $t -i 成片.mp4 -frames:v 1 -vf scale=360:360 chk/f_$t.png -y
done

# 3) 拼成一张图一起看
ffmpeg -v error -i chk/f_0.1.png -i chk/f_2.png -i chk/f_7.png -i chk/f_14.5.png \
  -filter_complex "xstack=inputs=4:layout=0_0|360_0|0_360|360_360" \
  -frames:v 1 chk/grid.png -y
```

**三项必查**：

1. **第 0 秒有没有画面**——空画面说明弹幕起点写大了
2. **水印在不在**——尤其结尾弹幕最密时，没描边的水印会被盖掉
3. **时长是否精确等于设定值**——差 0.3 秒以上说明 `-t` 或 timeline 末条越界

抽帧不等于验收。**没看过 `grid.png` 不要说"出片了"。**

## 三、内容底线

涉及**真实的人、真实的企业、真人形象**时，画面不要做成伤害性呈现（受刑、死亡、伤害之类）。
平台会直接下架，白做。

**用「围观 + 象征物」代替**：要做「烧某品牌」的效果，就画一圈围观人群 + 烧一块写品牌名的招牌。
情绪一点不少，片子也留得住。

同一条底线适用于：指名道姓的倒闭/裁员/事故题材，不要用具象伤害画面做情绪支点。

## 四、交付惯例

| 项 | 要求 |
| --- | --- |
| 存放位置 | 成片、脚本、模板放 `/workspace/` 下（用户可见），**不要只放临时目录** |
| 交付说明 | 写 `交付说明.md`：文件清单、规格参数、可调项 |
| 验收材料 | 给**密度表**和**抽帧拼图**，比只丢一个 mp4 有用 |
| 多版本 | 15s / 30s / 横竖屏渲染脚本要支持传参，**别复制多份代码** |
| 不要做 | 不自动上传/发布、不自动删中间产物 |

## 五、多版本的正确做法

同一套文案要出多个版本时：

1. 台词和音色矩阵**只维护一份**（`gen_voices.py` 顶部）
2. 每个版本**单独跑** `plan_timeline.py`——密度按时长算，不能复用
3. 每个版本单独渲到独立目录，避免 `clip/` 与 `out.mp4` 互相覆盖
4. 交付时按版本给对照表（时长/画幅/弹幕数/文件大小）

不要试图用同一份 `timeline.json` 出 15 秒和 30 秒两版——15 秒版的人声排法（burst）
在 30 秒里会前半段堆爆、后半段空掉。

## 六、换题材时的改动清单

同一个模板换一条片子，照这张表改，不要凭印象：

| 想做什么 | 要改的 | 容易漏 |
| --- | --- | --- |
| 换台词 | `gen_voices.py` 的 `TEXT` **和** `build.py` 的 `TEXT` | **两处必须一致**，只改一处会出现「人喊 A、弹幕飞 B」 |
| 换情绪（愤怒→兴奋） | `gen_voices.py` 里 `V` 列表的 rate/pitch：兴奋 = 正 pitch + 快语速 | 只改一处音色，听感会断层 |
| 换人数 | 扩 `V` 列表；音色不够就用同一音色的多组 rate/pitch | 同一音色超过 3 次就听得出是同一人 |
| 换底图 | 替换 `bg.png`（**先缩放到目标尺寸**） | 忘记缩放 → zoompan 推拉时露黑边 |
| 换时长 | 改时间轴脚本的 `DUR`，重算间隔，**重跑密度表** | 复用旧 timeline 是最常见的错 |
| 换画幅 | `build.py` 的 `W`/`H`，底图同步重做 | 横图直接裁会切掉文字，走模糊填充 |
| 加 BGM | 混音输入里多一路 `-i bgm.mp3`，`volume=0.12` 垫底 | 音量超过 0.15 就开始压人声 |

**换台词是唯一需要动两个文件的操作**，其余都只改一处。改完跑一遍 `check_env.sh` 里的自检，
再打一次密度表——换台词会改变每条音频的 `dur`，时间轴必须重算。
