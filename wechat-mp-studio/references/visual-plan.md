# 封面与配图

公众号封面**可以压字**（与头条相反），但规范更严：尺寸固定、高清无水印、与主题呼应。

---

## 封面

### 三条硬规则

1. **尺寸**：首条 900×383（2.35:1），次条 1:1。尺寸不对会被强制裁剪，构图要预留安全区。
2. **高清无水印**，模糊、拉伸、元素杂乱会明显降低点击。
3. **与标题呼应**——封面是标题的视觉延伸，不是独立配图。

### 封面方案输出格式

| 项 | 内容 |
|---|---|
| 主视觉 | 一张什么画面（一句话） |
| 封面文案 | 大字 5–12 字（从标题或核心观点提炼，不另起炉灶） |
| 版式 | 大字位置、留白方向、是否加角标 |
| 配色 | 主色方向，与全文主色调一致 |
| 取材方式 | 实拍 / 正版图库 / AI 生图 |
| 安全区 | 首条图上下会被裁掉多少，文字别压在边缘 |

> 次条封面的文字区域更小，文案要更短。

## AI 生图提示词（仅在用户明确要 AI 生图时给）

先给 **3 段**（主体 / 场景 / 风格），确认方向后再补全到九段：

```
【主体】{…}
【场景与构图】{…}
【风格与色调】{…}
【光线】{…}
【质感】{…}
【镜头】{…}
【留白】{…}
【画幅】900×383
【负面】文字乱码、水印、品牌 Logo、明星脸、低分辨率
```

**负面提示词必带**：文字乱码、水印、品牌 Logo、明星脸、低分辨率、拉伸变形。

---

## 正文配图（4–6 张）

| 项 | 规则 |
|---|---|
| 数量 | **4–6 张** |
| 位置 | 每 4–6 段一张，或放在小标题切换处 |
| 宽度 | 900px |
| 作用 | 视觉缓冲，避免文字堆积拉低完读率 |
| 版权 | 正版图库或自己实拍，无水印 |

### 配图输出格式（精简档：张数 + 一句内容建议）

```
图 1（放在第②段后）：{拍什么 / 取什么图} —— 作用：{为什么在这里}
图 2（放在第③段后）：…
```

**第二遍展开**（用户说「展开 / 细化」才给）：构图要点、取材方式、图注文案。

## 与头条 / 小红书封面的关键差异

| | 小红书 | 今日头条 | 公众号 |
|---|---|---|---|
| 封面压字 | 必须（三层文案） | **禁止** | 可以（5–12 字） |
| 尺寸 | 3:4 竖版 | 1:1 或 16:9 | **900×383 或 1:1** |
| 配图数量 | 0–3 张 | 3–6 张 | **4–6 张** |
| 配图来源 | AI 生图为主 | 实拍 / 正版库为主 | 正版库 / 实拍 / AI 均可 |

---

## 禁止

- 封面文字压在裁剪安全区外。
- 使用带其他平台水印的图。
- 图片里出现品牌 Logo、可识别车牌与门牌、他人肖像。
- 凑数配图——每张必须对应正文某一段。
- 过度花哨的配色与动图。
