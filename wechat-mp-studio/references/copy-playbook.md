# 正文方法论

## 通用硬规则（所有形态）

| 项 | 规则 |
|---|---|
| 字数 | **1500–2000 字** |
| 结构 | **总分总**：开头抛核心观点 → 中间 3–4 个小标题分点 → 结尾升华 |
| 开头 | 200–300 字，**前 3 句直击主题**，禁止寒暄铺垫 |
| 分段 | 手机端单段 **2–4 行**，多换行 |
| 金句 | 每个核心观点配一句，**单独成行并加粗**，方便截图转发 |
| 结尾 | 200 字总结升华 + 温和引导留言 |
| 广告 | 植入占比 ≤ 20% |

> 完读率权重约 35%、分享转发率约 30%，两者合计远超打开率。结构是完读率的地基，金句是转发率的引擎。

## 五套骨架（按形态选，不要混用）

### A 深度故事 — 个人经历 / 案例复盘

| 段 | 内容 |
|---|---|
| ① 开头 | 200–300 字，直接进场景或抛结果 |
| ② 背景 | 时间 + 处境 + 当时的判断 |
| ③ 推进 | 按时间或逻辑推进，每 2–3 句一段 |
| ④ 转折 | 全篇最关键的一次认知变化 |
| ⑤ 复盘 | 做对了什么、做错了什么 |
| ⑥ 升华 | 从个案推到普遍结论（**这是故事型能不能成立的关键**） |
| ⑦ 结尾 | 提问或引导留言 |

### B 清单干货 — {数字}个方法 / 教程

| 段 | 内容 |
|---|---|
| ① 开头 | **结论前置**：`{数字}个方法，第{X}个最容易被忽略` |
| ② 为什么值得看 | 一句，说清读者能得到什么 |
| ③ 干货主体 | 3–4 个小标题，每点 = 一句结论 + 具体做法 + 一句为什么 |
| ④ 常见误区 | 一个补充段 |
| ⑤ 结尾 | 总结 + 引导留言 |

### C 测评对比 — 多方案横评

| 段 | 内容 |
|---|---|
| ① 开头 | **先给结论**：`{X}个方案比下来，{Y}更适合{Z}` |
| ② 对比条件 | 同条件才可比，说清评测前提 |
| ③ 分维度对比 | 一个维度一个小标题，各自优劣 |
| ④ 什么人选哪个 | 分人群给结论 |
| ⑤ 结尾 | 你选哪个？ |

### D 观点站队 — 反常识判断

| 段 | 内容 |
|---|---|
| ① 开头 | 抛反常识结论，**态度鲜明** |
| ② 普遍看法 | 先说大家都怎么想 |
| ③ 为什么它是错的 | 2–3 条理由，每条配一句金句 |
| ④ 让步 | 承认对方成立的部分（增加可信度） |
| ⑤ 站队钩子 | 你怎么看？ |

### E 观察解读 — 趋势判断 / 行业观察

| 段 | 内容 |
|---|---|
| ① 开头 | 抛判断，不是抛事件 |
| ② 现象还原 | 只写已确认的事实 |
| ③ 增量 | 意味着什么、对读者的影响（**E 型的命门**） |
| ④ N 条提醒 | 应对建议 |
| ⑤ 结尾 | 提问或引导留言 |

## 金句写法（公众号的核心竞争力）

转发率高的人转的是那句话。金句三条标准：

1. **可独立成立**——脱离上下文也能读懂。
2. **有判断，不是描述**——"选择比努力重要"是金句，"努力很重要"不是。
3. **短**——一句，不超过两行。

每个核心观点配一句，**单独成行加粗**。

## 转发诱因埋点

在文章 **25% / 50% / 75%** 三个位置埋设，形式任选：

| 形式 | 例 |
|---|---|
| 金句 | 单独成行的判断句 |
| 可截图清单 | 一张整理好的对照表 |
| 共识戳中 | "你大概也经历过…" |
| 资料指引 | "完整清单我整理好了" |

**至少埋 2 处**，不能指望读者自发分享。

## 搜一搜 SEO

在**标题、首段、正文**里自然植入长尾关键词。用户搜问题时你的文章能被搜到，带来持续阅读。

- 标题里放 1 个，首段放 1 个，正文自然出现 2–3 次。
- **不要堆砌**——堆砌会被判定为低质。

## 自检细项（按形态查，不必每次全列）

- **A**：前 3 句直击主题？结尾从个案升华到普遍结论？
- **B**：结论在开头？每个分点有小标题？能照着做？
- **C**：对比维度 ≥3？给了"什么人选哪个"？
- **D**：态度鲜明？有让步？每点有金句？
- **E**：有增量判断而不是复述？事实与观点分开了？
