# 流量池与卡池诊断

用于**已发布笔记的后台数据复盘**。判断笔记停在哪一级流量池、卡在哪一项指标，给出唯一优先动作。

先立一条口径：小红书官方不公布流量池与基准线，以下数字来自运营圈流传的多套口径，彼此矛盾（单是初始池就有 0–200 与 200–500 两种说法）。**只用来做趋势对比和定位，不当作平台承诺，也不向用户报成"官方标准"。**

## 一、平台怎么打分：CES

```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```

点赞与收藏权重最低，评论与转发是 4 倍，关注是 8 倍。所以"求赞"是最没用的引导，真正拉分的是**让人开口、让人转走、让人关注**。15 字以上长评论优于一串水评。

## 二、五级流量池与各级考核

| 池 | 曝光量级 | 主要考核 |
|---|---|---|
| L1 初始 | 0–200 | 封面点击率、初始互动 |
| L2 基础 | 200–500 | 互动率（评论、收藏） |
| L3 中级 | 500–5000 | 深度互动：长评、转发、关注 |
| L4 高级 | 5000–5万 | 收藏率、复访率 |
| L5 爆款 | 5万+ | 综合热度与搜索流量 |

流传的晋级线（同一套口径内使用，不混用）：进入 L2 要点击率 ≥5%、首小时互动率 ≥3%；L2 升 L3 要收藏率 ≥3%、评论率 ≥1%、粉丝转化率 ≥0.5%。

## 三、基准表（经验值）

| 指标 | 合格 | 优秀 |
|---|---|---|
| 视频封面点击率 | ≥3% | 5%–8% |
| 互动率（赞+评+藏+转）÷观看 | ≥2% | ≥5% |
| 视频曝光 | ≥1500（新号 1000 左右可接受） | — |
| 收藏率 | 3% | — |
| 粉丝转化 | 0.5% | — |

曝光、点击率、互动率、收藏率、涨粉，**五个数分开看，不合成一个总分**。合并之后看不出该改哪一层。

## 四、卡池对照表

| 现象 | 判断 | 唯一优先动作 |
|---|---|---|
| 曝光低 + 点击率低 | 封面没接住人 | 只改封面与标题，正文先别动 |
| 曝光低 + 点击率高 | 内容行，系统没加推 | 先等 24–48 小时；期间补首评、回评把互动拉起来；不要因为曝光低就重发 |
| 点击率高 + 互动低 | 标题把人骗进来，正文没接住 | 改正文结构与首屏价值密度 |
| 互动有 + 收藏接近 0 | 缺"可存"落点，卡在 L2 升 L3 | 补可存信息：地点时间表、清单、步骤；或发一条含这类信息的长配置顶评论 |
| 点赞有 + 涨粉 0 | 单条好看，账号没有追更理由 | 强化系列名、置顶前作、结尾明确下一站 |
| 曝光高 + 转化差 | 人群标签不准 | 收窄选题与标签，不追大词 |

**只有一两个主因。** 六项平均用力等于没改。

## 五、复盘怎么记

1. 每篇只记五个数：曝光、观看、点击率、赞评藏、涨粉。写在项目自己的数据文件里，别只留在后台截图。
2. **样本小于 1000 曝光不下结论**，只记方向。单篇数据说明不了什么，至少三条同类才看趋势。
3. 维度优先级：点击率看封面，互动率看内容，收藏率看有没有可存的东西，涨粉率看人设与连载感。涨粉率比赞藏更重要——它衡量"看完这条还愿不愿意看下一条"。
4. 发布后 24–48 小时是数据窗口，中途反复刷新没有意义。要看的是它有没有在加量。

## 六、不许说的话

不承诺播放、收藏、涨粉、推荐、排名。复盘的产出是"下一步改哪一层"，不是"这样发一定爆"。
