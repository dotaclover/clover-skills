# 账号打法（自有视频号）

> **数据状态：本号尚无实测数据**（首条内容 2026-11-19 发布）。以下口径是跨平台推断＋抖音号实测结论的迁移，**必须在积累 3—5 条后用真实数据校正**。
> 不承诺播放、转发与涨粉；平台规则与界面以官方现行说明为准。

---

## 一、平台性质：社交盘，不是搜索盘

| | 抖音（搜索盘） | 视频号（社交盘） |
|---|---|---|
| 流量来源 | 站内搜索，长尾能持续数周 | 好友点赞、转发、群分享，通常 3—7 天到顶 |
| 内容寿命 | 资产，一条能用一个月 | 消耗品，一条用一周 |
| 关键词 | 必须卡品类词 | 不必卡，卡了也没有搜索入口承接 |
| 分发引擎 | 搜索匹配度 | 转发与好友互动 |
| 考核 | 搜索词覆盖、播放→主页 | **转发数、评论数** |

**推论**：视频号不需要词库，需要**转发理由**。每条内容发布前先回答一句：谁会把它转给谁，转了是帮他做什么。答不上来就换选题。

---

## 二、从抖音改编的四处改动

同一条内容直接搬会失效，必须改四个位置：

| 位置 | 抖音 | 视频号 |
|---|---|---|
| 首行（标题位） | 提问式，"AI短剧能做成什么样？" | 陈述成果，"6分钟短剧，全是AI做的，只花了时间没花钱" |
| 品牌名 | 靠后或不提 | 可保留，放第二段（微信里同行会问用什么做的） |
| 结尾 | "关注我，下期做XX" | "转给还在手动干这活的同事"——指向具体的人＋具体理由 |
| 标签 | 3—5 个，卡品类词 | 1—2 个即可，标签权重弱，多挂无收益 |

视频号没有独立的"作品标题"字段，**描述第一行就是标题位**，必须独立成立，不能靠后面的段落补。

## 三、内容分流

视频号只放"看完能转给人"的内容，**不做教程连载**。

| 内容线 | 放不放 | 形态 |
|---|---|---|
| WorkBuddy技巧 | 放，主力 | 结果对比＋关键动作；办公场景转发动机最强（转给同事＝帮他省事） |
| 项目实战（建站、部署、排错） | 放 | 一个具体问题的一次解决，不写系列 |
| Trae开发分享 | 放，只做结果展示 | 15—25 秒，一句话生成一个能跑的小东西；**不做 EP 编号连载**（同形态在抖音实测完播 1.9%） |
| 短剧 | 放，作能力展示 | 完整版一条，不做单集追更 |
| 泛AI概念、行业评论 | 不放 | 没有转发理由 |

**止损**：Trae 线在视频号发满 2 条仍无转发，停掉，不追加。

---

## 四、形态：轻操作＋主讲解，录屏只给结果

**结论：出镜或画外音讲，屏幕只做结果展示，不做过程演示。**

三条理由：

1. 竖屏手机上录屏里的小字看不清——字号低于屏高的 1/20 就失去可读性，代码和菜单尤其明显
2. 视频号是社交场景（通勤、沙发、饭桌），观众不会盯屏幕逐帧跟做
3. 转发理由不需要"我学会了"，只需要"这个有用"

**唯一例外**：神奇感来自界面本身（一句话生成整个页面、一个按钮跑完部署）。这时必须录屏，但要做三件事：

- 放大到关键区域占屏宽 60% 以上
- 只给 2—3 个关键帧，不给全过程
- 用框或箭头标出"变化发生在哪"

**结构模板**

| 段 | 内容 |
|---|---|
| 0—3 秒 | 结果对比（以前 X 小时 → 现在 Y 分钟），或最终成品 |
| 4—15 秒 | 3 个关键动作，每个一句人话，不解释原理 |
| 最后 2 秒 | 一句方法总结＋"转给…的人" |

## 五、考核与观察

| 指标 | 用途 | 备注 |
|---|---|---|
| 转发数 | **主指标** | 决定扩散半径，社交盘的唯一硬指标 |
| 评论数 | 次指标 | 判断内容是否勾人 |
| 播放 | 参考 | 不做优化目标 |
| 完播 | 不看 | 社交场景前 3 秒通过率天然高于抖音，参考价值低 |

发布后 24 小时取一次、48 小时再取一次，**不在 24 小时内判定内容生死**。

取数时同时记下：转发的人里有多少是同行/客户、评论问的是什么（问工具＝有需求，问原理＝内容太硬）。

## 六、跨平台发布

- 同一条内容**可以**在抖音和视频号同时公开，两个平台不构成重复分发
- 顺序：**抖音先，视频号后**。抖音吃搜索长尾越早越好，视频号吃好友活跃时段
- 文案必须分两版，按第二节改四处，不复制粘贴
- **不带他平台水印**：带抖音号水印的版本发视频号，普遍反馈会被降权，改为从创作者中心导出无 watermark 版本

---

## 七、明确不做

- 不做教程连载、不做 EP 编号系列（社交场景没人追更）
- 不用带水印的版本跨平台直发
- 现阶段不投流
- 不用小号或互赞刷互动：同设备、同网络、同通讯录可被识别，代价是不通知的限流
- 不承诺播放、转发、涨粉
