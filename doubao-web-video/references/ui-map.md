# 豆包网页版 UI 发现与状态对照

本文件给出控件发现线索，不是固定坐标、当前套餐或版本保证。每次以授权窗口的 DOM、截图、任务回执为准；不要因历史界面差异推断账号能力。

## 官方入口与路由

官方产品入口与公开路由属于服务知识，不是需要清除的项目硬编码。保留以下导航线索；页面版本变化时核验重定向及实际界面，而非删除入口。

| 位置 | URL 或路由 |
|---|---|
| 豆包官网 | `https://www.doubao.com/` |
| 视频创作入口 | `https://www.doubao.com/chat/create-image`（「AI 创作」页可切换图像/视频，路由名含 image 不代表只支持图像） |
| 会话页结构 | `https://www.doubao.com/chat/<conversationId>`（只记录结构，具体会话 ID 从用户授权页面取得） |
| 侧栏创作入口 | 「AI 创作」，可检查 `href=/chat/create-image` |

## 入口与参数

- 从官方创作入口进入；也可查找创作、视频或「技能」→「常用」→「视频生成」菜单，核已进入视频模式。不同账号可能显示不同入口，不固定为唯一导航路径。
- 优先查 `role=tab` 的视频标签及描述视频的输入框；语义节点不可用时结合新截图定位。
- 参数入口可能显示比例和时长摘要。打开后读取可选比例、时长、模型、收费提示和首尾帧控件，设置后关闭面板并核摘要。
- 上传入口可能为加号或附件按钮。用现有受支持工具操作文件选择器，不调用项目外私人脚本。剪贴板上传仅在环境支持时使用；核缩略图及顺序。
- 换窗口、账号或会话后重新检查；新会话上传失败不代表所有新会话都不支持，也不能自动发送无意义消息以绕过。

## 控件定位细节

以下是已知界面的定位线索，不表示所有账号当前都展示相同模型或参数范围。

| 控件 | 识别与核验方法 |
|---|---|
| 图像/视频切换 | 在 `role=tablist` 下找文本为「图像」「视频」的 `role=tab`，优先 DOM 点击，避免邻近坐标误点 |
| 输入框 | 图像态可能显示「描述你想要的图片」，视频态显示「描述你想要的视频」；结合当前模型与模式核验 |
| 模型按钮 | 视频态可见 Seedance 系列；模型名称用于识别模式，不据此推断套餐、免费资格或输出上限 |
| 参数按钮 | 可能显示「比例 自动」「自动 · 10s」或「9:16 · 10s」；设置后应显示所选参数摘要 |
| 比例弹层 | 已知选项包括自动、3:4、4:3、9:16、16:9、1:1、21:9；只选择当前实际可用且批准的选项 |
| 时长滑杆 | 已知界面出现过 4s～15s 范围；当前最小/最大值与可选档位须读面板，不能把示例当平台保证 |
| 发送按钮 | 输入框右下角上箭头；点击前核提示词、附件与参数，不只凭按钮颜色 |

参数面板可点击外部空白收起。面板动画可能改变焦点，执行“关面板→点输入框→输入→截图核文字→发送”；工具返回输入成功不等于页面已正确填入。底部快捷 chip 不一定随图像/视频切换，不单凭它判断模式。

## 状态与行动

| 状态 | 可能的界面线索（需关联本次请求） | 行动 |
|---|---|---|
| 等待确认 | 参数清单并明确“确认后开始” | 用户已授权且参数无误时确认一次，记录确认已发送 |
| 已受理 | 任务号、排队或预计等待提示 | 保留回执，不重复提交 |
| 生成中 | 进度、正在生成 | 观察最新状态 |
| 完成 | 成功状态及对应结果播放器 | 预览后下载 |
| 失败 | 明确失败/取消记录 | 记录原因与费用，重试另请授权 |
| 不明确 | 异常提示与回执冲突、看不到进度 | 滚到最新消息或查看任务历史，禁止补发确认 |

发送提示词不一定先等待确认；受理也不是成功完成。确认发送后即使没回执也不能再次确认。缩略图须核所属请求，避免旧结果误判。

## 下载与验证

视频详情或播放器工具栏可能提供“保存/下载”；核 tooltip 或 DOM 后点击一次，查看浏览器下载记录。已知路径为“聊天视频缩略图→右侧画布面板→右上角下载图标”，悬停 tooltip 为「保存」；旁边的 `X` 是关闭面板，不要混点。播放器进度条用于核结果可播放及所属片段，不代表本地下载完成。文件名可能取自会话标题，重复下载可能追加编号，但这些不是固定契约，不只按 mtime 判断。

必须同时核浏览器下载完成、文件稳定以及本地媒体校验。`.crdownload` 不代表完整文件，ffprobe 能读出头部也不保证解码完整。仍在下载或状态不明确时不要运行收尾或直接改后缀。

按 `SKILL.md` 使用实际技能目录中的收尾脚本；音轨、尺寸、编码、时长及容差由需求决定。输出规格、等待时间和套餐能力不在此固定。
