# 豆包网页版 UI 对照表

## 页面与入口

| 位置 | 值 |
|---|---|
| 视频创作页 | `https://www.doubao.com/chat/create-image`（标题「AI 创作」，路由名仍叫 create-image） |
| 会话页 | `https://www.doubao.com/chat/<conversationId>` |
| 侧栏入口 | 「AI 创作」（`href=/chat/create-image`） |

## 创作页控件

| 控件 | 图像态文案 | 视频态文案 |
|---|---|---|
| 输入框 placeholder | 描述你想要的图片 | 描述你想要的视频 |
| 模型按钮 | 模型 Seedream 5.0 Flash | 模型 Seedance 2.0 Mini |
| 参数按钮 | 比例 自动 | 自动 · 10s / 9:16 · 10s |
| 底部快捷 chip | AI 抠图 / 擦除 / 标记改图 / 扩图 / 变清晰 | 同左（不随 tab 变） |
| 发送按钮 | 输入框右下角蓝色圆形上箭头 | 同左 |

图像/视频是 `role="tablist"` 下的两个 `role="tab"`，文本分别为「图像」「视频」。

## 参数弹层

点「比例 自动」或「自动 · 10s」都会弹出同一个面板：

- 标题「比例」，7 个方格选项：自动 / 3:4 / 4:3 / 9:16 / 16:9 / 1:1 / 21:9
- 下方「时长」滑杆，左端 4s、右端 15s，当前值以数字显示在滑杆右上

面板不点外部不会自动关闭，点页面空白处收起。

## 会话里的关键状态文案

| 阶段 | 文案 |
|---|---|
| 提问已发送 | 右上角标题自动生成，如「赛博朋克雨夜跑车视频生成」 |
| 等待确认 | 「视频生成参数确认」清单 + 「确认后我再开始生成视频。」 |
| 已受理 | 「本次使用 Seedance 2.0 Mini 生成，预计等待 5 分钟……本次生成将消耗每日免费额度。」 |
| 完成 | 「你的视频生成好了。」+ 竖版视频缩略图 |

## 下载相关

- 点视频缩略图 → 右侧滑出画布面板（标题「创建画布」旁的编辑区，含大播放器与 `00:00 / 00:10` 进度条）
- 面板右上角工具栏：
  - 蓝色下载图标 → hover tooltip「保存」→ 触发下载
  - 最右侧 `X` → 关闭面板（第一次很容易点错成这个）
- 下载文件名 = 会话标题 + `.mp4`
- Chrome 会留 `.crdownload` 不改名，同一片重复点击会追加 `(1)`

## 输出规格（实测）

| 项 | 值 |
|---|---|
| 分辨率 | 720x1280（9:16，Seedance 2.0 Mini） |
| 编码 | h264 + aac |
| 10 秒片大小 | 约 3.4 MB |
| 出片耗时 | 1~2 分钟（官方提示 5 分钟） |
