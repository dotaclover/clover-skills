# 画布与版式

## 令牌表（短边 1080 基准）

`u = min(宽, 高) / 1080`，下表所有值乘 `u`：

| 令牌 | 基准值 | 用途 |
|---|---|---|
| `title` | 108 | 片头主标题 |
| `card_title` | 72 | 卡标题 |
| `h3` | 64 | 小标题 / 黑板四格主词 |
| `body` | 48 | 正文 |
| `sub` | 40 | 副标题 |
| `note` | 34 | 注释 |
| `label` | 30 | 标签 / 集号 |
| `safe_x` | 135 | 左右安全边 |
| `safe_y` | 120 | 上下安全边 |
| `gap` | 64 | 正文行距 |

不同画布的实际像素：

| 画布 | u | 卡标题 | 正文 | 注释 |
|---|---|---|---|---|
| 1920×1080 | 1.00 | 72 | 48 | 34 |
| 1080×1920 | 1.00 | 72 | 48 | 34 |
| 1080×1440 | 1.00 | 72 | 48 | 34 |
| 1440×1440 | 1.33 | 96 | 64 | 45 |
| 1440×1800 | 1.33 | 96 | 64 | 45 |
| 3840×2160 | 2.00 | 144 | 96 | 68 |

**为什么按短边而不是按宽度**：竖屏如果按宽度缩，正文会掉到 27px，手机上看着累；按短边算，竖屏的绝对字号和横屏一样，代价是画布更窄——所以竖屏要**减字**，不是减字号。

## 竖屏的额外规则

1080×1920 的有效阅读区只有中间那一条：

- 正文每行 **≤ 16 字**（横屏是 ≤ 22 字）
- 一屏最多 **2 条**正文（横屏 3 条）
- 关键内容留在 `y ∈ [0.10H, 0.72H]`；底部 25% 会被平台标题、按钮、评论条压住
- 标题可以大，但别超过两行，第二行掉到 0.72H 以下就危险
- 一屏只放一个视觉主体，竖屏没有地方放第二根柱子

## 版式骨架

### 1. 片头卡

```
四叶草标记（左上）      系列名（右上小字）
主标题（1–2 行，title 档）
──── 分隔线 ────
副标题一行（sub，灰）
一句强调（note，强调色）
右下角：EP01 · 日期（label，金色）
```

### 2. 单概念卡

```
左上四叶草 + 卡标题（card_title）        右上系列名
────────── 分隔线 ──────────
第一条  body + 注释 note
第二条  body + 注释 note
第三条  body + 注释 note        ← 竖屏最多 2 条
（可选）底部一句收口（强调色）
```

### 3. 流程卡

- 节点横向排（横屏）或纵向排（竖屏），最多 4 个
- 节点：圆角矩形 `stroke=强调色`，内文 `body`
- 连线细线 `stroke=线色` + 小箭头，禁止粗箭头
- 节点下方一句 `note` 说明，不要塞长句

### 4. 对照卡

- 横屏：中缝竖线在 `x = W/2`，两列各 3–4 行 `note`
- 竖屏：改成上下两段，中间一条横线；A 段在上，B 段在下
- 对照的是**行为差异**，不是形容词（"省时间" → "工具在流程里被调用"）

### 5. 作业黑板

- 标题「课后作业」+ 右上集名
- 四条线把版面等分（横屏 2×2，竖屏 4 行）
- 格内：主词 `h3` + 注释 `note`
- 底部「作业」标签（`label`，金色）+ 题目 `body`

## SVG 骨架（可直接改）

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="{W}" height="{H}" viewBox="0 0 {W} {H}">
  <rect x="0" y="0" width="{W}" height="{H}" fill="#121A14"/>

  <g fill="none" stroke="#6F8F5A" stroke-width="{2u}" opacity="0.9"
     transform="translate({sx},{sy}) scale({0.5u}) translate(-150,-150)">
    <path d="M150 150 C124 142 124 108 150 96 C176 108 176 142 150 150 Z" transform="rotate(45 150 150)"/>
    <path d="M150 150 C124 142 124 108 150 96 C176 108 176 142 150 150 Z" transform="rotate(135 150 150)"/>
    <path d="M150 150 C124 142 124 108 150 96 C176 108 176 142 150 150 Z" transform="rotate(225 150 150)"/>
    <path d="M150 150 C124 142 124 108 150 96 C176 108 176 142 150 150 Z" transform="rotate(315 150 150)"/>
  </g>

  <text x="{sx+90u}" y="{sy+58u}" font-family="Source Han Sans SC, Microsoft YaHei, sans-serif"
        font-size="{72u}" font-weight="500" letter-spacing="{8u}" fill="#EDEAE0">卡标题</text>
  <text x="{W-sx}" y="{sy+50u}" text-anchor="end" font-family="Microsoft YaHei, sans-serif"
        font-size="{30u}" letter-spacing="{3u}" fill="#6F8F5A">EP01 · 集名</text>
  <line x1="0" y1="{sy+118u}" x2="{W}" y2="{sy+118u}" stroke="#2E3B2E" stroke-width="{2u}"/>

```

`{...u}` 表示"基准值 × u"。`init_project.py` 会按选定的画布直接生成这套骨架，改字即可。

## 换画布时最容易漏的

1. **分隔线拉满宽度**（`x1=0 x2=W`），留居中白边会显得没铺满。
2. **`text-anchor="end"` 的右对齐点**用 `W - safe_x`，不要写死 1785。
3. **卡片的 `<title>` 和文件名同步**，后期找卡全靠它。
4. 同一个系列里**不要混画布**。竖屏版就整集竖屏，横屏版就整集横屏；混用会导致成片在渲染时补黑边。
