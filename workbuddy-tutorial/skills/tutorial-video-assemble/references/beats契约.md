# beats.json 契约

`build_film.py` 的全部输入。这份是权威定义——改字段先改这里，再改脚本。

## 顶层

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `episode` | 否 | 目录名 | 集号，用于产出文件名 |
| `title` | 否 | — | 集标题，写进台词稿 |
| `canvas` | 否 | `16:9` | 画布，见下 |
| `voice` | 否 | 云希 +8% | `{name, rate, volume}` |
| `loudnorm` | 否 | `I=-16:TP=-1.5:LRA=11` | 逐段响度归一 |
| `card_tail` | 否 | 0.9 | 卡片段说完后留的停顿（秒） |
| `font` | 否 | Microsoft YaHei | 烧字幕字体 |
| `font_size` | 否 | 短边 × 4.5% | 烧字幕字号（1080p 落地 49） |
| `cards_dir` | 否 | `cards` | 卡片 SVG 目录（相对集目录） |
| `cards_png_dir` | 否 | `cards_png` | 渲染后 PNG 目录 |
| `rec_dir` | 否 | `rec` | 录屏原片目录 |
| `beats` | **是** | — | 分段数组，顺序 = 成片顺序 |

## canvas

```json
"canvas": {"preset": "9:16", "fps": 30}
"canvas": {"width": 1440, "height": 1080, "fps": 30}
```

| preset | 尺寸 | 场景 |
|---|---|---|
| `16:9` | 1920×1080 | 横屏教程（默认） |
| `9:16` | 1080×1920 | 抖音 / 视频号 / 竖屏 |
| `1:1` | 1440×1440 | 方图 |
| `4:5` | 1440×1800 | 小红书 |
| `3:4` | 1080×1440 | 平板 / 投屏 |
| `4k` | 3840×2160 | 大屏母版 |

宽高必须是偶数。显式写 `width/height` 会覆盖 preset。预设表在 `scripts/canvas.py`（三个技能各带一份，内容一致）。

**同一集里所有素材必须是同一个画布**。渲染器用 `contain` 只缩不放，横屏素材进竖屏成片会左右补黑边，不会自动裁。

## beats[]

| 字段 | 卡片段 | 实拍段 | 说明 |
|---|---|---|---|
| `id` | ✓ | ✓ | 段号，同时是音频/片段的文件名，**全片唯一** |
| `kind` | ✓ | ✓ | `card` / `demo` |
| `text` | ✓ | ✓ | 台词。空串 = 纯画面段（自动补静音） |
| `png` | ✓ | — | 卡片 PNG 文件名；缺 PNG 但同目录有同名 SVG 会自动渲染 |
| `src` | — | ✓ | 录屏文件名（相对 `rec_dir`），或绝对路径 |
| `start` / `end` | — | ✓ | **原片**时间（秒），`0 ≤ start < end ≤ 源时长` |
| `speed` | — | 否，默认 1 | 播放倍速，`≥0.05` |
| `seconds` | 否 | — | 无台词卡片段的停顿时长 |

## 时长怎么算

```
卡片段：槽位 = 配音时长 + card_tail
实拍段：槽位 = (end - start) / speed
```

配音时长由 TTS 实测，不是估的。实拍段槽位固定，所以台词超了就是 `OVER`。

`--fit stretch` 时，实拍段会自动把 `speed` 调成 `(end-start)/(配音+0.25)`，让画面刚好兜住台词——只动倍速，不动裁剪范围。

## 校验规则

脚本会直接报错或警告，不静默跳过：

| 情况 | 处理 |
|---|---|
| `id` 重复 | 后一段覆盖前一段的音频文件，产出错乱 |
| `start/end` 越界 | 报错终止，给出源实际时长 |
| 素材缺失 | 列进 `[缺失素材]`，该段被跳过 |
| 配音 > 槽位 - 0.15 | 判定 `OVER`，退出码 2 |

## 示例

```json
{
  "episode": "EP02",
  "title": "把第一份成果做出来",
  "canvas": {"preset": "16:9", "fps": 30},
  "voice": {"name": "zh-CN-YunxiNeural", "rate": "+8%", "volume": "+0%"},
  "card_tail": 0.9,
  "beats": [
    {"id": "c01", "kind": "card", "png": "C01_片头.png",
     "text": "上一集我们说，差别不在谁更聪明。这一集把它做出来。"},

    {"id": "d1", "kind": "demo", "src": "demo01.mp4",
     "start": 0.0, "end": 8.5, "speed": 1.0,
     "text": "把同一句话，粘进去。"},

    {"id": "d2", "kind": "demo", "src": "demo01.mp4",
     "start": 8.5, "end": 68.0, "speed": 3.0,
     "text": "它先去读文件，再挑工具，中间自己写了脚本核对原文。这段压了三倍速，真实跑了两分钟。"},

    {"id": "c99", "kind": "card", "png": "C99_结束卡.png",
     "text": "下一集讲怎么在网页里直接改。我是顺哥，我们下个视频见。"}
  ]
}
```

## 改台词之后

```bash
python scripts/build_film.py --ep episodes/EP02 --force
```

不加 `--force` 会用缓存里的旧配音，表上的数字全是上一版的。这是最容易踩的坑。
