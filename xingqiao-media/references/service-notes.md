# 星桥 · 服务地址与商务信息备忘

来源：服务方 2026-11-17 群通知与《API 接入文档》总集。这里只记接入要看的地址、配置和政策；接口字段与状态机见 `image-api.md`、`video-api.md`。政策与返点随服务方调整，用前当次核实，不把这份快照当长期承诺。

## 服务器区域与地址分工

服务器区域：**美西**。

| 用途 | 地址 |
|---|---|
| 主站、后台、通用API Key（密钥管理） | `https://www.novqiao.com` |
| 文本与流式API（chat/completions、responses） | `https://www.novqiao.com/v1` |
| 图片/视频生成、询价、任务查询 | `https://api.novqiao.com` |
| 新任务成品下载 | `https://image.novqiao.com` 签名链接，客户端跟随302 |

文本API客户端填 `https://www.novqiao.com/v1` 后不要再重复加 `/v1`。业务请求统一 `Authorization: Bearer <KEY>`，JSON 用 `Content-Type: application/json`；密钥分组、IP限制、有效期与额度限制仍然生效。

**旧域名已下线**：`api.rrwkj.cyou` 于 2026-11-16 下线，`www.carpool.ink` 同步停用，不再兼容旧链接。账本里残留的旧下载链接不能再用；历史任务拿原 Key 回 `api.novqiao.com` 重查，换新链接。新任务下载链接含 `image.novqiao.com`，不要带 Bearer，不转发到存储域。

## 客户端生图配置（Codex/CC免安装）

需要让 Codex 或 Claude Code 客户端用星桥生图时，按三步配置：

1. 在「API密钥」创建**异步生图视频专用分组**，打开"使用密钥 → Codex/CC免安装"。
2. 选择 Windows 或 macOS，按页面配置**独立图片URL/Key**，并合并对应客户端调用指令。
3. **完全退出并重启客户端，开启新对话**（不重启不生效）。

图片URL用生成接口地址，Key用该专用分组的密钥；不要复用文本分组或视频分组的Key。配完先用一句简单提示词试一张，确认走的是星桥再正式用。

## 服务器采购返点

需**未关联新用户注册**才计返点；关联过的账号不算。企业不开票档比例更高。

| 云平台 | 适用期 | 每次新购 | 续费/升级 |
|---|---|---:|---:|
| 腾讯云 | 2026-01-01 起关联的账号，至 2026-12-31 | 30%（企业不开票35%） | 15% |
| 阿里云 | 2026-04-01 至 2027-03-31 | 30%（企业不开票35%） | 15% |

返点是渠道政策，不是 SKU 报价，也不进客户交付价。登记采购前先确认账号是否符合"未关联新用户"条件，返点到账以平台结算为准。
