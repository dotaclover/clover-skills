# 网站专项交付

通用授权与证据流程使用 `task-delivery`；本技能负责网站类型选择、构建验收与交接。按项目分配应用开发、运维、复核和商务负责人，不依赖固定姓名。

## 开工依据

读取当前 project brief、合同/服务政策、素材问询与验收清单，确认页面/区块/照片数量、插件预算、修改轮次、费用、服务窗口、售后及不含项。缺项询问，不使用内置SKU、固定页数、售价或SLA。

工具和模板从当前工作区或用户提供的资源目录发现，先确认存在、读说明及`--help`。没有生成器时按同样验收标准手动构建，不假定固定仓库路径或客户订单脚本可用。客户材料放指定私有目录，不进版本库。

## 共用流程

1. 核实项目归属、素材版权、真实联系方式、页面清单及发布授权，不编造评价、案例或资质。
2. 书面确认交付类型、范围、费用、第三方支出、验收与变更流程；账号授权不等于支付或发布授权。
3. 确认主机地域、域名、HTTPS和适用上线条件；账号由用户持有，以最小权限协作者方式操作。
4. 改现有站点前先备份，验证恢复并记录回滚方案。
5. 本地/测试环境验收后，在获准的正式网址复验：真实浏览器逐页检查导航、资源、联系按钮、控制台和响应式布局，视口从目标设备清单选择。
6. 表单、预约、用户创建等写入测试另行确认；记录测试对象ID，清理仅针对本任务创建且用户同意删除的对象，原有业务数据保留。
7. 交接网址、产物、使用说明、备份、验收记录和未完成项；撤销临时权限。

## 静态展示站

- 先区分单页名片、服务展示、多页企业介绍、相册/纪念站；根据照片、页面数量和维护需求选模板、生成器或定制构建，不把站型绑定固定价格。
- 模板复制到项目工作区后替换内容、图片和配色，私有联系方式配置按授权发布；扫描占位符与演示信息。
- 相册检查分页、原图/缩略图、移动端触摸与资源体积；联系栏检查tel链接、复制反馈和二维码。
- 核心正文优先预渲染为HTML，检查子目录部署、相对路径和资源引用。外部字体/脚本是否允许由项目隐私与性能要求确定。
- 构建→静态检查→本地预览→逐页浏览器验收→打包；失败不标完成。无后台站点须明确内容更新需重新构建发布，若要求自助编辑则重新评估CMS。

## WordPress企业站

- 盘点当前核心、主题、插件、PHP和数据库，选择与项目匹配的经典主题/区块主题或既有实现。`opc-*`仅为可选实现示例，不假定存在。
- 制定页面、导航、内容类型、表单、隐私和角色权限清单；页面数及插件上限由项目约定，第三方组件先审查维护状态、许可、兼容性和必要性。
- 开发与加固见 `wp-dev`；后台使用教学与测试见 `wp-admin`。会员、商城、支付、多语言等需专项范围和验收，不隐含在展示站交付中。
- 表单先确认字段、收件人、用途和保存期限；实测后台记录、权限与通知状态，邮件提交成功不等于送达。
- 交付前在隔离环境验证文件+数据库恢复。带用户实际改文字、换图、查看记录，录屏需授权并隐藏凭据和个人数据。

## 已有成品部署

- 先核对产物、运行依赖与授权。仅预览链接或截图不等于可部署源码/产物。
- 本地预演确认文件完整、入口、资源路径及静态/后端类型；部署流程见 `site-launch` 与 `ops-deploy`。
- 部署不隐含改设计、源码修复、迁移、搜索优化或架构改造；发现阻塞先说明并另确认范围，不擅自修改。
- 发现明文密钥或可疑后门先停止发布并告知，保护证据；修复或密钥轮换另行授权，不能带明显泄漏直接上线。

## 售后与边界

按当前合同区分本次缺陷、原有缺陷、第三方故障和新增需求；维护期限、响应窗口、退款抵扣和收费均现场核实，不内置承诺。超范围先给工作量与影响，用户批准后继续。不得承诺排名、收录、AI推荐或业务效果。
