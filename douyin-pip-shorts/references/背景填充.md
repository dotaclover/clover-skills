# 底板编排

先按本次配置决定中段画面顺序，再将浮窗叠在连续底板上。素材不足时先与用户确认补充素材、重复使用或缩短结构，不把某次项目的剪辑偏好当作通用规则。

## 一、选择补充方式

| 方式 | 适用条件与检查 |
|---|---|
| 正序重播片段 | 用户允许重复，动作衔接自然；检查重复是否影响叙事 |
| 补充片段 | 内容与当前讲解相关，使用权明确，视觉规格可统一 |
| 定格、循环、倒放、黑场 | 仅在任务明确需要时采用，评估阅读、节奏与动作自然度；当前构建器不自动生成这些效果，需先制作独立素材 |
| 缩短时间轴 | 重新检查旁白、步骤可读性和总时长，不只裁掉尾部 |

`缺口 = 规划中段长度 − 可用素材长度`。缺口越大，越应检查重复的观感；“超过素材一半”可作为提醒，不是强制阈值。`plan_timeline.py --source` 的建议仅供预算参考，真实构建以JSON配置和实测素材为准。

## 二、使用有序片段配置

中性示例，秒位仅用于说明结构，必须替换为本次素材实际位置：

```json
"base": [
  {"src": "media/clip-a.mp4", "start": 0, "duration": 8},
  {"src": "media/clip-b.mp4", "start": 2, "duration": 4},
  {"src": "media/clip-a.mp4", "start": 8, "duration": 2}
]
```

所有路径相对配置文件，不写进构建脚本。总片段时长须覆盖规划中段；构建器截取所需长度，因此若要求特定结尾，应把片段总长和规划中段对齐，并在成片中确认最后一镜。

若用户选择“从同一素材尾部正序补充”，可使用 `补充起点 = 源时长 − 缺口`，前提是起点非负且允许重复。此公式只保证取段结束在源末尾，不保证叙事衔接自然。

## 三、规格与素材检查

- 按 `layout.width/height/fps` 统一画布和帧率，`setsar=1` 统一像素宽高比。缩放裁切可能损失边缘内容。
- 对旋转标记、VFR、HDR和不同色彩空间素材做单独抽帧及动态检查；必要时预处理到新文件，保留源文件。
- 高分辨率与低分辨率素材可以混用，但应评估算力、清晰度差异和缩放效果，而非一概禁止。
- 真实执行校验取段不超过媒体时长；dry-run不探测媒体，也不证明解码、裁剪区域正确。

## 四、验证跳点

按本次片段表计算目标秒位与源秒位，比较每个边界前后以及浮窗覆盖段的帧。抽帧写入新验收目录，使用 `ffmpeg -n`，不要覆盖素材或已有结果。

先做视觉比对，再用像素差作为辅助：统一尺寸、色彩转换和缩放方式，遮罩浮窗与字幕区域，并考虑编码噪声及帧率取整。用当前素材已知匹配帧和不匹配帧标定阈值，不能把固定差值当作“同一帧”的充分证明。

修改底板序列后重新检查跨素材边界、首尾及旁白所指的画面。验收结论以本次任务约定为准。
