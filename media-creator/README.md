# 影像创作 · media-creator

Agent 型图片视频创作专家，版本 `1.0.0`，分类 `06-ContentCreative`。按生成、加工、数字人、切图与零成本流水线路由，费用、凭据和素材权限逐项确认。

## 文件与技能

- `.codebuddy-plugin/plugin.json`：专家元数据、6个技能路径、3个标签与3条示例提示词。
- `agents/media-creator.md`：媒体路由、执行工作流、费用门禁、外部写与客户资产边界。
- `skills/`：从 `C:/code/cloverhub/clover-skills/` 原样复制全部原目录结构和文件。

| 技能目录 | 职责与限制 |
|---|---|
| `seedance-dev` | 官方Ark / 百度AI网关 / 华锐开发路由；必须显式选择provider，附带CLI仅支持官方 |
| `huarui-dev` | 华锐自用开发、通用协议适配；无客户Key，无现成CLI，不替代客户包 |
| `video-post-production` | 既有本地视频加工，默认原音与质量模式，不提供ASR |
| `zero-cost-video` | 文案+底图的弹幕/多人TTS流水线方案；未附5个实现脚本 |
| `xiaoice-digital-human` | 数字人播报、编辑器模式及形象/声音训练，真实生成与训练需授权 |
| `grid-image-splitter` | 本地宫格切图，自动行列仅为启发式判断 |

独立图片生成需要当前会话另有已授权工具；本包只提供方案及路由，不内置图片生成后端。

## 明确排除

不包含、不加载、不读取配置：`workbuddy-image`、`doubao-web-video`、`workbuddy-tutorial`、教程专家、`huarui-zhisuan` 等客户华锐包、`huarui-video` 等内部视频包。本次也不复制 `baidu-api-dev`。

源技能保留的跨包引用仅为原文，不代表相关能力或配置已随包提供。

## 使用示例

- 帮我规划一条Seedance视频生成流程，区分官方、百度和华锐渠道，先不发请求或产生费用。
- 把我的本地视频剪辑拼接成竖屏版本，保留原音，先检查素材并给出加工方案。
- 把这张九宫格切成九张独立图片，并规划数字人口播方案，暂不上传素材。

## 安全与授权

- 费用上限、任务数量、provider、外部传输和写入范围应在真实请求前确认；查询授权不等于生成、训练或删除授权。
- 官方、百度、华锐与小冰使用各自凭据和账号资产；密钥只通过环境变量或用户指定的本机私有配置读取，不进专家包或日志。
- 不收集客户Key、素材库存、私有真人授权会话、签名链接或内部回调路径。不读取客户包作为开发捷径。
- 真人和声音训练须有本人同意及合法权利；素材Active不等于真人授权成功。
- 源脚本存在上传、生成、训练和移除等真实操作，不能整批当自检运行；本次只进行本地静态校验和复制核对，没有执行任何业务请求。
- 不自动安装依赖、上传发布、覆盖源视频或删除缓存。在线TTS同样需要外传文本授权。

## 已知限制与未处理项

1. `seedance-dev` 百度路由依赖 `baidu-api-dev` 唯一事实源；按要求未复制，缺依赖时停留在规划，不推测执行。
2. `zero-cost-video` 缺少5个流水线脚本，且文档为特定Linux环境口径；本次不补脚本，不保证Windows直接运行。
3. `huarui-dev` 是协议文档，没有可执行CLI；官方Seedance CLI不能拿来直接请求华锐或百度。
4. `video-post-production/SKILL.md` 原文frontmatter使用转义分隔符，可能影响加载器自动识别；保留原文，通过Agent显式阅读兜底，未修改技能。
5. 小冰目录内形象缓存及历史实测不是当前账号可用性证明；本次没有联网验证、生成、训练或付费测试。
6. 头像 `avatars/expert.png` 留给主代理生成，当前只有 `.gitkeep`。本次不生成头像、不打包、不修改共享marketplace注册文件，后续由主代理统一处理。
