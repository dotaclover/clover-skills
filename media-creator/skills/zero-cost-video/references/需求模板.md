# 需求模板（开工前填这张表）

## 一、为什么要模板

这个流水线的返工点不在技术，在**规格没说清**：时长、人数、密度、画幅任何一项含糊，
渲出来就得整条重来。所以开工前把下面这张表填完，缺的项按下表默认值补并标注。

## 二、给用户看的需求模板

把下面这段整块给用户，只改【】里的内容：

```
我要做一条【时长秒数】秒的短视频，风格：底图 + 弹幕刷屏 + 多人 TTS 齐喊。

【主题】：（一句话，比如"大麦倒闭" / "老板还钱" / "项目上线啦"）
【台词】：（所有弹幕和所有人声都用这一句，或给我几句轮流用）
【画面】：（底图要什么内容，比如"一群火柴人围着烧一块招牌"；
          或者直接说"用我给的图"，然后把图发我）
【人数/音色】：【N】个人同时喊，要【情绪，比如愤怒/兴奋/委屈】
【尺寸】：【1:1 朋友圈 / 9:16 抖音 / 16:9 B站】
【时长】：【15秒 / 30秒】
【密度】：弹幕【N】条/秒，人声全程保持【N】个人同时开口
【水印】：右下角【写什么字】，不要就说无

要求：
- 从第 0 秒就开始有弹幕和声音，不要留白
- 全部免费方案：edge-tts + ffmpeg + Pillow
- 先给我时间轴密度表（每秒几个人声几条弹幕），我看完再渲
```

**最后那行不能删。** 密度是这条片子里返工最多的东西——第一版开头空了 2.6 秒就是密度排错。
先把「每秒声/弹」的表格打出来，白区一眼就能看见，改了再渲。

## 三、用户没说的，按这里补

| 缺项 | 默认值 | 备注 |
| --- | --- | --- |
| 时长 | 15 秒 | 短视频场景优先短版，越短越冲 |
| 画幅 | 1080×1080 | 朋友圈/群聊传播最稳；要投抖音再出 9:16 |
| 人数 | 8 人 | 低于 5 人听不出"一群人"，高于 12 人音色组合开始重复 |
| 情绪 | 愤怒 | 这条流水线最擅长的情绪；要兴奋就把 rate/pitch 全取正 |
| 弹幕密度 | 8 条/秒（15s） / 5 条/秒（30s） | 按 `DUR × 密度` 反算总条数 |
| 水印 | 不带 | 用户没提就不加，别自作主张 |
| 底图 | 程序化画 | 用户给了图就用图，先缩放到目标尺寸 |

补默认值时**在回复里明说哪几项是推断的**，别让用户以为是自己说过的。

## 四、开工前的三个确认

1. **台词只有一句还是多句？** 多句要定轮换顺序，否则时间轴排不出节奏。
2. **底图是现成的还是要画？** 现成图要问清原始比例——横图转竖图要走模糊填充，不能硬裁。
3. **给谁看？** 群聊转发（1:1）、平台投放（9:16）、还是横屏平台（16:9）。画幅定错整条白做。

问不超过两个问题，其余按上表预设，别把填表变成审问。
