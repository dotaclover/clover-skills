# 零元短视频

从零做一条「底图 + 弹幕刷屏 + 多人 TTS 齐喊」的短视频。耗材 0 元，不调用任何付费接口。
**输入是文案和底图，不是视频素材。** 输出是一个可直接发布的 mp4。

## 该用 / 不该用

| 该用 | 不该用，改用 |
| --- | --- |
| 只有文案，要从零出一条片子 | 已有视频要剪、要拼、要混、要压体积 → `video-post-production` |
| 要「一群人同时喊」的听感（rate × pitch 矩阵造假） | 要用生成模型出画面 → `seedance-video` / `doubao-web-video` |
| 要弹幕刷屏、弹幕墙、结尾大字强调 | 要口播字幕逐句对齐 → 本技能没有 ASR，做不到 |
| 要 15s / 30s / 横竖屏多版本，同一套文案快速改 | 要数字人口播 → `xiaoice-digital-human` |

## 四条硬约束（不遵守必返工）

1. **参数是 Linux 服务器口径**：`/usr/bin/python3`、`apt-get`、NotoSansCJK 全路径。换机器先改路径，别直接跑。
2. **目标机 ffmpeg 无 `libx264`**，只能用 `libopenh264 -b:v 6M`（不能用 `-crf`）；**无 `eq` 滤镜**，亮度对比度在 PIL 里调。
3. **TTS 必须串行**，带 sleep 和重试，并判断产物大于 1200 字节。改成 `asyncio.gather` 会大量返回截断 MP3。
4. **弹幕起点写 `0.05`**。写成 2.6 会导致开头两秒半是空画面——这是返工最多的地方。

## 第 0 步：先定规格，再动脚本

把 `references/需求模板.md` 里那张表给用户填：**主题 / 台词 / 画面 / 人数情绪 / 画幅 / 时长 / 密度 / 水印**。
缺项按默认值补，并在回复里标明哪几项是推断的。

规格没定就开跑，返工点全在时长、人数、密度这三项上。

## 五步流程

| 步 | 脚本 | 产物 | 干什么 |
| --- | --- | --- | --- |
| ① 人声 | `gen_voices.py` | `audio/NN.mp3` + `lines.json` | 按音色/语速/音调矩阵逐条生成 |
| ② 时间轴 | `plan_timeline.py` | `timeline.json` | 排双轨人声密度 + 弹幕时间点，打印密度表 |
| ③ 弹幕图 | `build.py`（内） | `clip/dNNN.png` | 每条弹幕一张带 alpha 的 PNG，黑描边 |
| ④ 底图 | `gen_bg.py` 或现成图 | `bg.png` | 程序化 8 层绘制 |
| ⑤ 合成 | `build.py` | `out.mp4` | zoompan 推拉 + overlay 叠加 + amix 混音 + 水印 |

**核心设计**：所有「什么时候响、什么时候飞」只写进 `timeline.json`，渲染脚本只读它。
改节奏、改密度只动 JSON，渲染代码一行不碰——这是快速出 15s / 30s / 横竖屏多版本的前提。

**每次渲染前必须给用户看密度表**（逐秒列出声音数与弹幕数）。渲完再改比看表改贵得多。

## 脚本状态

`scripts/` 下需要 5 个脚本：`check_env.sh`、`gen_voices.py`、`plan_timeline.py`、`gen_bg.py`、`build.py`。
**本包未随附实现**——源文档只给了规格，没有给代码。契约见 `references/脚本契约.md`。
复制脚本进来之前，不要声称这个技能可以跑通。

## 与 video-post-production 的分工

两者技术栈有重叠，但任务不重叠。判断只看一句：**手上有没有源视频。**

| | zero-cost-video | video-post-production |
| --- | --- | --- |
| 输入 | 文案 + 底图 | 已有视频文件 |
| 编码器 | `libopenh264`（假定无 x264） | `libx264` + CRF |
| TTS 用途 | 多音色 + 音调，伪装成一群人 | 单人旁白，4 个试听音色 |
| 独有能力 | 弹幕层、程序化底图、多人齐喊 | 剪辑拼接、多源统一、遮挡、限体积 |

**编码器假设相反，两台机器不能混跑。** 在 A 机器上跑 B 的编码参数会直接报 `Unknown encoder`。
详细重合面与冲突点见 `references/与后处理的边界.md`。

## 内容底线

涉及**真实的人、真实的企业、真人形象**时，不要做成伤害性呈现（受刑、死亡、伤害）。
平台会直接下架，白做。

用「围观 + 象征物」代替：要做「烧某品牌」的效果，就画一圈围观人群 + 烧一块写品牌名的招牌。
情绪一点不少，片子留得住。
