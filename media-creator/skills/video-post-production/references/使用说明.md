# 使用说明

适用版本：1.0.0 开发稿；仅在用户正式提交并指示后提升版本，不自动升级。

## 环境与运行

直接在工作区使用，无须安装为用户技能，也无须打包。使用Python 3.10+隔离解释器和已有FFmpeg/FFprobe；需libx264/AAC，burn需libass与本机可用字体。仅网络TTS需要可选requirements，脚本不自动安装任何依赖；本地配音、混音与原音模式不依赖edge-TTS。

```bash
python scripts/video_pipeline.py --ffmpeg C:/ffmpeg/bin/ffmpeg.exe --ffprobe C:/ffmpeg/bin/ffprobe.exe probe D:/Videos/source.mp4
python scripts/video_pipeline.py --ffmpeg C:/ffmpeg/bin/ffmpeg.exe --ffprobe C:/ffmpeg/bin/ffprobe.exe frames D:/Videos/source.mp4 --output D:/Videos/new-frames --interval 2
python scripts/video_pipeline.py --ffmpeg C:/ffmpeg/bin/ffmpeg.exe --ffprobe C:/ffmpeg/bin/ffprobe.exe render --config config.json --output result-new
```

python替换为宿主管理的隔离解释器；全局FFmpeg参数放在子命令前。示例JSON中的source.mp4/voice.mp3需替换为真实本地路径；所有相对路径以JSON所在目录为基准，不是工作区。

## 模板

- config.example.json：原音、完整视频、默认质量，无体积目标。
- talking-subtitles.json：口播显式字幕，保留原音，burn。
- voice-mix.json：本地配音混原音，固定音量。
- size-limit.json：明确体积上限size双遍。
- portrait-contain.json：竖屏画布，等比画面补边。
- multi-source.json：多源重排并有意重复。

模板不隐式读取媒体，不包含测试媒体。针对真实素材调整时间与规格。场景建议见需求分析；脚本不接收preset字段。

## 配音授权

仅明确请求narration时启用在线TTS，先说明旁白将发送至edge-TTS在线服务，审核不含秘密，得到授权再加--allow-tts-network。未授权在创建输出前拒绝。没有授权使用voice_file；第三方语音服务可用性不保证。本次开发稿整理没有调用在线TTS。可选依赖仅在已确认的隔离Python环境内由用户安装，使用标准PyPI来源，不使用全局安装、非官方镜像或远程脚本。依赖内部网络目标与供应链安全不属于本包可保证范围。

## 输出与验收

final.mp4为H.264、yuv420p、SAR=1；非mute为AAC音频。subtitle_mode为sidecar/burn时输出subtitles.srt；timeline.json记录每段源与目标时间、subtitle_timing；report.json记录encoding_mode、target_enabled/target_mb/target_met、输出规格、实际字节数、时长、音频字幕说明及完整解码结果。work保存中间片段/ASS/双遍日志，不自动删除。

source_modified:false仅是行为说明——脚本不写源路径，不是哈希完整性鉴证。独立voiceover.mp3不默认导出，避免混音后误称旁白与额外编码。

检查规格、体积（仅size时）、开头/转场/结尾，人工试听音量、配音裁切及字幕时序，确认crop没有裁掉关键信息、遮挡覆盖所需区域。不把完整解码成功等同听感、画质或隐私验收。

## 限制与失败

- 输出目录已存在：拒绝覆盖，换新目录。处理失败保留缓存，不清理个人路径。
- 旋转源：先另存方向规范化副本再配置，不能直接用原像素坐标套用旋转画面。
- 质量模式体积可大可小，没有默认3–5MB要求。size只保证成功输出不超过明确上限，无法达到则失败，不通过填充伪造下限。
- 单段和多段会重编码，VFR转换到首源平均CFR；多段存在帧和AAC量化偏差。HDR、色彩、无缝专业剪辑未保证。
- 字体缺失可能fallback，必须核查本机字体。没有自动下载字体、ASR、OCR、动态追踪、ducking、外部SRT导入或步骤条。
- protocol_whitelist=file,pipe只限制媒体协议，并非文件系统沙箱；只处理可信本地媒体与配置。
- 既有真实媒体测试记录与本次有限验证边界见tests报告；当前完整静态安全审计见安全审计报告，不把功能测试视作安全保证。
