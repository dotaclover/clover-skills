# 配置字段与时间轴

适用版本：1.0.0 开发稿。

## 全局

|字段|默认/含义|
|---|---|
|source|本地视频，相对配置文件目录。省略segments时必填；每段提供source时可省略全局source|
|encoding_mode|quality；仅显式size启用体积上限双遍编码|
|crf|20，0..51；quality最终视频和size中间片段采用该值|
|target_mb|无默认，仅size必填，十进制MB上限非下限；quality中传入会拒绝|
|width / height|第一段源尺寸；显式时必须同时填写2..7680偶数，奇数源需手动指定偶数画布|
|fps|第一段源平均帧率，1..120；所有片段统一CFR；不等于保留VFR时间戳|
|resize_mode|contain，等比缩小且不放大画面，黑边pad；crop需明确设置，等比中心裁切，可能放大/丢失边缘|
|audio_mode|original / replace / mix / mute，默认original；mute不输出音轨|
|original_volume / voice_volume|1.0，非负数；mix建议原音0.25、配音1.0|
|subtitle_mode|none / sidecar / burn，默认none；burn同时导出SRT|
|font / font_size|Microsoft YaHei；默认max(16,宽度×0.025)，正数；字体需本机可用|
|voice / rate|在线TTS音色及速率，默认zh-TW-HsiaoChenNeural（用户选定的普通话女声11，中国台湾口音）、+0%；其他首选见音色选择.md；不修改本地录音|
|segments|省略代表完整source；非空数组按给定顺序拼接，可重排、重叠、重复；不自动去重|

默认单源方形像素保留原始分辨率。非方形像素按源SAR校正显示比例，再统一SAR=1及画布，必要时缩小/补边，不强行拉伸。多源画布、fps取第一段，不随片段变化。

## 片段

|字段|含义|
|---|---|
|source|覆盖全局source，支持多源，路径仍相对配置文件|
|start / end|源时间秒数，默认0/该源总时长，0≤start<end≤源时长|
|speed|默认1，≥0.05；输出时长=(end-start)/speed|
|duration|明确输出时长≥0.05，与speed互斥；改变视频和原音速度|
|voice_file / narration|互斥，仅replace/mix可用且这两个模式每段必须提供其一；录音从头播放，尾部裁切或补静音，不自动延长片段|
|subtitles|显式数组start/end/text，时间相对该加工后片段；必须在输出时长内|
|subtitle_text|仅subtitle_mode不为none且没有显式字幕时使用，按短句长度分摊整个输出片段，近似计时；不自动使用narration|
|masks|可选矩形数组x/y/w/h、unit；pixels默认源分辨率坐标，normalized为0..1比例；整段不透明灰遮挡，先遮挡后缩放|

mix采用amix(normalize=0)+限幅器，固定音量，无自动ducking。原音缺失时original补静音，mix只使用配音。原音保留指保留内容，不保证原编码/音质完全无损；原音将变速（如配置）、48kHz立体声重采样、AAC编码。

## 多源重排与重复示例

```json
{"source":"source.mp4","segments":[
 {"start":2,"end":4},
 {"source":"portrait.mp4","start":0,"end":2},
 {"start":0,"end":2},
 {"start":2,"end":4}
]}
```

最后一段明确重复首段，不是校验误差。边界帧量化及AAC编码可能产生小的拼接时长偏差；timeline基于实际视频片段时长累计，不保证样本级无缝。

## 字幕与遮挡示例

```json
{"start":0,"end":4,"subtitles":[{"start":0,"end":2,"text":"明确字幕时间"}],
 "masks":[{"unit":"normalized","x":0.1,"y":0.1,"w":0.2,"h":0.1}]}
```

sidecar仅写SRT不改变画面，burn写SRT并ASS烧录；none忽略字幕内容且不生成SRT。显式时间不代表已经校准过听感。没有ASR/逐字对齐，不支持外部SRT输入。遮挡不处理音频、字幕、配置及路径隐私。

audio_mode:voiceover、fit、label不是有效配置。脚本拒绝未知字段，避免无效配置被静默忽略；当前开发与编码边界见开发说明（升级说明.md）。
