# 抖音脚本工坊

四个模块：**选题 → 钩子（标题 + 前 3 秒）→ 时间轴脚本 + 口播稿 → 封面**，发布前过**违禁词体检**。

**三条底线**
- **零预设**：不含任何预设垂类、人群、话术，全部由当次输入或用户画像推断填充。
- **零编造**：数据、案例、时间地点、个人经历一律留【】占位。见 `references/truthfulness.md`。
- **零慢启动**：前 3 秒不进主题，这条视频就结束了。

> 本 Skill 自洽独立，不依赖任何外部技能或平台能力，可单独分发使用。

---

## 抖音的三条平台铁律

| # | 规则 | 后果 |
|---|---|---|
| 1 | **完播率为王**，四级流量池赛马（0–500 / 500–5000 / 5000+ / 10万+） | 完播率 >30%、互动率 >5% 才进下一池 |
| 2 | **24–48 小时定生死** | 与视频号的 7 天长效赛马完全不同，发布后前两天数据不行就是不行 |
| 3 | **前 3 秒决定留存** | 慢启动、自我介绍、寒暄 → 观众直接划走 |

**第 1 条决定了脚本的取向**：一切设计围绕"让人看完"。时长、节奏、信息密度、结尾设计，全部服务于完播率。

---

## 第 0 步：给预设场景卡，不问一串问题

**不要一次抛出 6 个问题。** 先拼出一段**完整的预设场景文本**给用户改。

推断来源，按优先级取：
1. **本次对话已给的信息**（最高优先级）
2. **用户画像与历史记忆**
3. **该垂类的常识值** —— 取用时必须标 `（推断，可改）`

**只有「本篇内容」是必填项**。其余全部预设好。

模板见 `references/input-brief.md`。

---

## 四条铁律

1. **先有人群，后有标题。** 抖音主力 18–35 岁、一二线为主。
2. **形态决定时长与节奏。** 先定 A/B/C/D/E，再定秒数。
3. **标题出 3 条，三条三种机制。** 凑不齐 = 采集信息不够，回去补，不许硬凑。
4. **真实细节一律留占位。**

---

## 形态路由

| 形态 | 适用 | 主攻 | 时长 | 节奏 | 分镜密度 |
|---|---|---|---|---|---|
| **A 痛点开场** | 干货、教程、技巧、工具推荐 | 完播+收藏 | 30–45s | 快 | 高 |
| **B 反常识钩子** | 认知类、职场、财经、涨粉向 | 完播+评论 | 20–40s | 极快 | 高 |
| **C 数字列表** | 知识类、清单、冷门方法 | 收藏 | 30–45s | 快 | 高 |
| **D 剧情反转** | 种草、娱乐、人设、情景剧 | 完播+互动 | 15–30s | 极快 | 极高 |
| **E 热点跟拍** | 24 小时内热点、挑战、BGM 二创 | 时效流量 | 15–25s | 极快 | 高 |

**判断**：教一个方法 → A｜想颠覆一个认知 → B｜能拆成 N 条 → C｜有情节有反转 → D｜跟热点 → E。

**三条硬例外**
- **D 型的反转必须发生在最后 5 秒之前**——放到结尾观众已经划走了。
- **所有形态都禁止慢启动**：前 3 秒必须抛冲突、数字或反常识。
- **E 型时效优先于打磨**，热点过了就没量。

## 分支：旧片诊断

用户给的是**已发布视频 + 数据差** → 走诊断，**不重新采集**。

| 层 | 看什么 | 常见病灶 |
|---|---|---|
| 1 前 3 秒 | 有没有钩子 | 自我介绍、寒暄、慢启动、等 BGM |
| 2 中段节奏 | 信息密度与转折 | 平铺直叙，没有起伏，观众中途划走 |
| 3 时长 | 是否超出内容承载力 | 30 秒的内容拉到 60 秒，完播崩 |
| 4 结尾 | 有没有引导互动 | 直接结束，无 CTA |
| 5 标题 / 封面 | 有没有冲突感 | 太平，信息流里抓不住 |
| 6 合规 | 是否被限流 | 功效承诺、极限词、诱导互动 |

输出：**先给诊断结论（哪 1–2 层是主因），再给改写版本**。

> 数据对应关系：完播低 → 改前 3 秒和时长；互动低 → 改结尾 CTA；播放低 → 改标题与封面。

## 交付规格（精简档）

| # | 项目 | 规格 |
|---|---|---|
| 1 | **标题 ×3** | 表格 `标题/机制/评分`，标 ⭐ 推荐 1 条 |
| 2 | **前 3 秒钩子 ×3** | 与标题配套的三种开场 |
| 3 | **时间轴脚本** | 分段表：`时间段 / 这一段干什么 / 关键信息` |
| 4 | **完整口播稿** | 可直接念的成稿，标注字数与预估时长 |
| 5 | **封面建议** | 主视觉 + 封面文案 + 关键镜头提示 |
| 6 | **违禁词体检** | 命中项 + 替换后的安全版本 |
| 7 | **自检** | 勾选结果 |

**分镜表不在默认交付里** —— 用户说「展开分镜 / 给分镜」才出。

不输出思路说明与过程分析。

## 填写策略：先简后拆（不要一次填满）

| 产物 | 第一遍：简版（必出） | 第二遍：拆解展开（确认后 / 用户要求时） |
|---|---|---|
| **预设场景卡** | 1 行本篇内容 + 其余预设值 | 补全关键词 |
| **标题评分** | 每条：总分 + 最低维度 | 推荐那条展开五维明细 |
| **时间轴** | 段名 + 秒数 + 一句内容 | — |
| **分镜** | **不给** | 展开每镜的景别 / 运镜 / 画面 / 字幕 / 音效 |
| **封面** | 主视觉 + 文案 | 展开构图与生图提示词 |
| **自检** | 必检 8 项 | 按形态展开细项 |

**规则**
- 第一遍出**方向性内容**，等用户确认方向。
- 用户说「展开 / 继续 / 细化」才出第二遍。
- **用户没确认方向前，不要把重型模板全部填满。**

## 标准流程

1. **预设场景卡** — 拼一段完整场景文本给用户改，只等「本篇内容」
2. **搜同类爆款** — 标题避让 + 结构借鉴（见 hook-playbook 第 -1 步）
3. **定形态** A/B/C/D/E，据此定时长
4. **标题 ×3** — 三种机制，各附评分
5. **前 3 秒钩子 ×3** — 与标题配套
6. **时间轴脚本** — 按形态骨架切段
7. **完整口播稿** — 真实细节留【】占位
8. **封面建议** + 结尾 CTA
9. **违禁词体检** — 标题 + 口播稿 + 字幕 + 封面文案全过一遍
10. **自检**附末尾

---

## 输出格式约定

- 标题与钩子用**表格**。
- 时间轴用**表格**：`时间段 | 这一段干什么 | 关键信息`。
- 口播稿单独成块，可直接念，不写"思路"。
- 占位符统一【】，口播稿上方声明"需要你填的 N 处"。
- **语感**：快节奏、高密度，每 12 字左右有一个爆点（数字 / 反差 / 金句）。

---

## 自检清单（必检 8 项）

- [ ] **前 3 秒**：有钩子，无自我介绍与寒暄，无慢启动
- [ ] **标题**：三条三种机制，评分均 ≥ 70，有冲突感
- [ ] **时长**：符合形态区间，没有超出内容承载力
- [ ] **节奏**：每 12 字左右有爆点，中段有转折，无平铺直叙
- [ ] **口播稿**：字数与时长匹配（约 5–6 字/秒），口语可念
- [ ] **真实性**：【】占位全部列出，没有一处是我替他填的
- [ ] **合规**：标题 + 口播稿 + 字幕 + 封面文案全部过违禁词
- [ ] **合规**：无诱导互动（点赞过 X 更新、评论区扣 1）

> ⚠️ 自检是**软自审**，不能代替违禁词体检。详见 `references/compliance.md`。

---

## 禁止事项

- **慢启动**：前 3 秒不进主题。
- **内容注水**：30 秒的内容拉到 60 秒，完播率会崩。
- **无转折**：中段平铺直叙，中途流失率极高。
- **功效承诺**：根治、7 天见效、瘦 X 斤。
- **极限词与绝对化**：最、第一、100%、永久、唯一。
- **诱导互动**：点赞过 X 更新、评论区扣 1、关注才发。
- **变体规避**：谐音、拆字、符号替代——同样会被识别。
- **编造细节**：把【】当真实内容发出，或替用户填"看起来合理"的值。
- **凑数分镜**（展开分镜时）。
