# 豆包网页版 UI 发现与状态对照（图像模式）

控件文案与路由只是发现线索，不是固定坐标、套餐或版本保证。每次以用户授权且已登录窗口的 DOM、截图与任务回执为准。

本节记录**用户已授权的 Edge／Chrome 扩展窗口**多轮只读与出图实测（含同一账号全新窗口的单变量对照），用于把定位线索与真实界面区分开；账号版本、套餐和活动变化时重新核验，不把一次观察写成平台保证。

## 官方入口与路由

官方产品入口与公开路由属于服务知识，不是需要清除的项目硬编码。页面版本变化时核验重定向与实际界面，而不是删除入口。

| 位置 | URL 或路由 |
|---|---|
| 豆包官网 | `https://www.doubao.com/` |
| 创作入口 | `https://www.doubao.com/chat/create-image`（「AI 创作」页；路由名含 image 不代表只支持图像，同页可切视频） |
| 会话页结构 | `https://www.doubao.com/chat/<conversationId>`（只记录结构，具体 ID 从授权页面取得） |
| 侧栏创作入口 | 「AI 创作」，可检查 `href=/chat/create-image` |
| 侧栏其他入口 | 新工作任务、新对话、定时任务、插件·技能·工作台、云盘、更多、草稿、项目 |

未登录状态打开创作入口只能看到落地页、DOM 快照为空；已登录状态才出现侧栏会话历史与下方创作控件，两者不能互相推断。

## 已登录「AI 创作」首屏（实测）

| 控件 | 实测表现 |
|---|---|
| 页面标题 | 「AI 创作」＋副标题「让创作随灵感而生」 |
| 输入框 placeholder | 「描述你想要的图片」，与视频态「描述你想要的视频」不同 |
| 模式切换 | 输入框内左下有 `role=tablist`，两个 `role=tab` 为「图像」「视频」；默认落在「图像」，选中项白底 |
| 工具条 | 输入框内下沿依次为 `+`（上传）、图像/视频 tab、`模型 <当前模型>`、`比例 <当前值>`，最右为麦克风 |
| 发送 | 输入框右下蓝色上箭头；输入多行文字后输入框变高，按钮随之下移，坐标不固定，优先核 DOM 或截图 |
| 快捷编辑 | 输入框下方一排 chip：AI 抠图、擦除、标记改图、扩图、变清晰 |
| 结果展示 | 更下方是作品示例墙，不是本次任务结果，不能误认 |

底部快捷 chip 不一定随 tab 切换，不单凭它判断模式；以 placeholder 与 `role=tab` 选中态为准。

## 参数面板（实测档位）

### 比例

`比例` 按钮打开浮层，实测 8 档，排成 2 行 4 列：

| 第一行 | 自动 | 9:16 | 2:3 | 3:4 |
|---|---|---|---|---|
| **第二行** | 1:1 | 4:3 | 3:2 | 16:9 |

图像态**没有**视频态的 21:9，多了 2:3 与 3:2；不要把视频档位表直接套到图像态。选中项有蓝色边框，按钮文字同步变为「比例 16:9」之类摘要。

### 模型

`模型` 按钮打开浮层，实测 5 个 `role=menuitem`：

| 条目 | 说明文字 |
|---|---|
| Seedream 5.5 | 旗舰生图（默认） |
| Seedream 5.0 Pro | 升级专业出图 |
| Seedream 5.0 Flash | 专业快速 |
| Seedream 4.5 | 日常生成 |
| Seedream 4.0 | 基础生图 |

面板中未出现收费提示，但这**不等于免费**：额度与套餐须按当前账号实时核验。

### 参数浮层的实测坑（重要，两次踩中）

- 比例与模型浮层是**向上弹出、直接盖在输入框文字上方**，不是向下展开；选中档位后**浮层不会自动关闭**。一次实测中浮层覆盖区约为创作区 `x≈705–1070, y≈85–255`（1440×900 视口、侧栏展开），恰好覆盖输入框中部，数值随布局变化只作线索。
- 「点空白收起面板」**不一定有效**：实测点浮层外右上空白后浮层仍在，接着点输入框中部 `(850,215)` 实际命中浮层第二行的 `4:3`，把刚选的 16:9 悄悄改掉，界面无任何提示；随后输入工具返回成功，但文字根本没进输入框（焦点被浮层吃掉）。
- **最可靠的收起方式是按一次 `Escape`**：实测浮层立即消失且比例摘要保持 16:9。收起后截图确认浮层不在、比例正确，再点输入框中部输入，并**再截图核文字**，三项摘要齐了才发送。
- 点输入框左上角边缘（如 `(500,200)`）也可能完全不聚焦、输入内容丢失；要点输入框中部且避开浮层覆盖区。
- 打开模型面板后再操作，也要重新核比例摘要，不假定已选参数保持。
- 工具返回「输入成功」「点击成功」都不等于页面状态正确，一切以截图/DOM 摘要为准。

## 提交后的会话变化（实测）

1. 点发送后立刻从「AI 创作」落地页切到「新对话」，页面出现加载中的三点动画与产品图标；侧栏新增一条会话记录，标题由本次提示词概括而成。
2. 底部输入框变成普通对话输入框，placeholder 为「发消息或按住空格说话...」；下方 chip 变为「对话／项目／视频生成／图像生成／更多技能／快速」，不再是创作页的参数工具条。
3. 用户消息以「生成图片：<提示词>，，16:9」形式回显，参数被写进消息文本，可用于核对本次请求。
4. 生成完成可能追加一条新消息而页面不自动滚到底；判「没出图」前先滚底或点向下箭头，并关联本次请求与参数。

## 账号额度差异（实测对照）

免费额度按账号独立，创作页提交前**不显示剩余次数**，提交后才暴露。同一天两个已登录账号的实测结果：

| 浏览器与账号 | 同样参数提交后的结果 |
|---|---|
| Edge 扩展窗口 | 「今日图片生成免费额度已用完。开通订阅畅享更多额度。」＋「开通豆包订阅」按钮，**无结果图** |
| Chrome 扩展窗口（另一账号） | 正常受理并生成结果图 |

Edge 号那次属于明确失败，不是「系统异常」或「预计等待」：记录证据与费用情况，不自动重发、不重复点确认；开通订阅、换账号、改用付费接口都需用户另行明确授权。用户授权换用另一个已登录窗口后，才在 Chrome 号完成出图。免费额度是否按日重置、具体额度数字、订阅价格均以当前账号页面为准，不写死。

**不同账号的界面也可能不同**：实测 Chrome 号会话底部 chip 为「对话／项目／技能」，Edge 号为「对话／项目／视频生成／图像生成／更多技能／快速」。创作页的参数控件与浮层坑两号一致，但仍按当前窗口核，不照抄账号结论。

## 出图张数由提示词控制（单变量对照实测，重要）

创作页**没有张数设置控件**。同账号、同模型 `Seedream 5.5`、同比例 `16:9`、画面描述逐字相同，只改数量约束，在**全新窗口／新对话**各提交一次：

| 提示词开头 | 生成中占位 | 结果 |
|---|---|---|
| 不写数量（直接以画面描述开头） | 2×2 共 4 个灰块 | **4 张**，消息区排成 2×2 网格 |
| 「只生成一张图片。」＋完全相同的画面描述 | **1 个**灰块 | **1 张**完整大图，消息区单图＋下方点赞/点踩/分享等工具栏 |

因此「默认 4 张」只是当次账号/模型的默认值，不是平台固定契约；**只写「一张」是目前唯一实测有效的单张写法**。「生成一张…」「仅1张」「single image」、数量词放句中或句尾、用否定句「不要多张／不要拼版」控制张数，均未实测，不写成可用技巧。生成中的占位数量可作为早期信号。

## 结果图与下载（实测成功）

- 缩略图是**渐进加载**：先出现灰色占位，再变浅色底，最后才显示画面，期间可能一直有加载图标。判「没出图」前要等渲染并滚底，不要看到灰块就重发；占位的个数＝本次结果张数。
- 鼠标悬停结果图会浮出 4 个图标：引用／重新生成／**下载原图**／编辑（扩图类），tooltip 实测为「**下载原图**」，点击一次即下载该张原图。**位置随布局变**：2×2 网格时在目标卡片底部；单张大图时在**图片左下角**（白色图标压在画面上）。别误点旁边的重新生成。
- 下载文件名实测取自**会话标题**（如 `中国传统水墨山水长卷.png`）。两个不同会话因提示词相近而生成了同一标题，第二次下载被浏览器追加为 `中国传统水墨山水长卷 (1).png`；**同标题会追加 ` (1)` 这类编号**，所以必须用下载前基线文件列表＋下载记录认领，不能只按文件名或 mtime 猜。
- 2×2 网格时点缩略图会打开全屏查看器：左侧保留 2×2 缩略图，顶部有「创建画布」及选择／涂抹／画笔等编辑工具与关闭 `X`，右侧是画布面板。顶部图标无语义标签时优先用单张卡片 hover 的「下载原图」，避免误点关闭或编辑。单张结果是否也进同一查看器未测。
- 两次实测产物规格均为 PNG、2048×1152（对应 16:9）、rgb24 无透明通道、约 3.1–3.3MB；尺寸随所选比例变化，不是平台保证。

## 参考图上传

- 上传入口为输入框内的 `+` 或当前环境受支持的官方控件／系统文件选择器，不调用项目外私人脚本。
- 剪贴板上传仅在环境已提供受支持功能时使用；每次粘贴后截图核缩略图、内容、数量与顺序。
- 新对话与已有对话的上传行为可能不同（网页版视频流程中实测过差异），按当前窗口核实，不为绕过限制发送无意义消息。
- 参考图只借语义，不保证锁构图、人数、道具细节或文字；需要精确复现的内容留给后期层。

## 状态与行动

| 状态 | 可能的界面线索（需关联本次请求） | 行动 |
|---|---|---|
| 等待确认 | 参数清单并明确「确认后开始」 | 用户已授权且参数无误时确认一次，记录确认已发送 |
| 已受理 | 切到新对话、加载动画、会话标题生成 | 保留回执，不重复提交 |
| 生成中 | 进度、正在生成 | 观察最新状态，不提交新任务 |
| 完成 | 成功状态及对应结果图（1 张或 4 张，张数按提示词） | 等占位渲染完再逐张预览后下载 |
| 失败 | 明确失败/取消记录，或免费额度用尽的明确文案 | 记录原因与费用，重试、订阅、换号另请授权 |
| 不明确 | 异常提示与回执冲突、看不到进度 | 滚到最新消息或查看任务历史，禁止补发确认 |

「预计等待」是受理证据不是完成；「系统异常」也不是足以重试的失败证据。缩略图必须核所属请求，避免旧结果误判；一次生成多张时逐张核归属。

## 下载与验证

图像态实测路径为「悬停目标结果图→浮出工具栏的『下载原图』」：2×2 网格时工具栏在**卡片底部**，单张大图时在**图片左下角**；先核 tooltip 再点击一次。这与视频态「缩略图→右侧画布面板→右上角『保存』，旁边 `X` 是关闭」**不是同一路径**，不要混用。全屏查看器顶部另有一排无语义标签的编辑图标，优先用结果图 hover 的下载按钮。随后对照浏览器下载记录与下载前基线文件列表认领文件，不只按 mtime 或文件名判断（同标题会追加 ` (1)`）。

必须同时核浏览器下载完成、文件稳定以及本地完整解码。`.crdownload` 不代表完整文件，只读出图片头也不保证解码完整。仍在下载或状态不明确时不要运行收尾或改后缀。

按 `SKILL.md` 使用实际技能目录中的收尾脚本；格式、尺寸、比例与容差由需求决定，不在此固定出图张数、等待时间或套餐能力。
