# 自媒体创作 · wb-expert-selfmedia

Agent 型内容创作专家，版本 `2.0.0`，分类 `06-ContentCreative`。一个专家，三个技能，只做内容创作。

## 覆盖范围

| 技能目录 | 职责 |
|---|---|
| `douyin-script-studio` | 抖音短视频：前三秒钩子、时间轴、完整口播、封面、违禁词体检 |
| `kuaishou-script-studio` | 快手短视频：真实感、人设连续性、对话感、同城内容 |
| `xhs-note-studio` | 小红书图文笔记：标题、正文、话题标签、封面与配图提示词 |

只用抖音、快手、小红书三个平台。视频号、公众号、微头条、头条长文、对比测评**不在本包范围**，被问到直接说不覆盖，不硬套已有技能。

## 明确不含自动化

本包只出文案，不碰账号。以下动作一律不做，也不提供操作步骤：

- 登录、切换、绑定账号
- 上传、发布、定时发布、删除或修改已发布内容
- 抓取后台数据、热榜、竞品数据
- 批量点赞、评论、关注、私信、养号
- 调用图片／视频生成接口或网页版出图

这样定不是为了省事，是因为账号操作与数据抓取涉及合规与授权，不该打包进一个通用创作工具。需要数据的部分，由用户自己截图或导出。

## 文件

- `.codebuddy-plugin/plugin.json`：专家元数据、3 个技能路径、3 个标签与 3 条示例提示词。
- `agents/wb-expert-selfmedia.md`：路由表、工作流、输出规范、能力边界与事实合规要求。
- `skills/`：三个技能目录，与 `C:/code/cloverhub/clover-skills/` 根目录同名技能保持一致。

## 使用示例

- 围绕我的选题写一条45秒抖音脚本，给出三个标题、开场钩子和完整口播稿。
- 把同一份素材改成小红书笔记，按笔记形态写，不要写成视频脚本。
- 诊断一条已发布但数据差的视频，先指出最可能的1到2个问题。

## 使用限制

- 技能内的平台固定数据、算法权重与处罚说法未经联网核实，只作历史参考，不声称为当前官方规则。
- 不保证流量、过审、涨粉或收益。
- 事实缺口使用【待补：字段】；创作、实测、生成与发布状态分别说明，不伪造经历与核验记录。

## 维护

技能副本与根目录同名技能保持文件一致；改动根目录技能后需同步复制到本包。改版本号或技能清单后重跑校验与注册。
