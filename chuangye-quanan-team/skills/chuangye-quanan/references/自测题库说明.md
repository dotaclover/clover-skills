# 自测题库说明

## 定位

用户称为 example 的这一套测试题，目前实际文件位于 `exams/`。将其作为独立的专家验收测试集，不从试题答案反向编造课程知识。**每张彩色原图中绿色标注的选项才视为课程标注的正确答案**；OCR 文本的选项顺序不能替代颜色核对。题目用于检验创业基础概念、机会判断、项目选择、客户、市场、运营和风险意识，不作为真实项目数据源。逐题建立来源、题干、选项、绿色正确答案、专家实际回答、判定与错误原因；绿色标注不清、图片缺失或没有可靠答案的题目标为待核实，不计入准确率。

使用题库时：

1. 只从题干和选项提取可复用的判断原则。
2. 先标记题目属于：找项目、市场、开办、运营、客服、财务、风险或课程平台操作。
3. 课程平台的题目答案只作为教材口径参考；遇到现实经营问题，必须重新核实政策、平台规则和当地条件。
4. 将“我为什么选择这个答案”转成检查问题，不直接把选择题答案当行动建议。
5. 不因题库出现某个具体行业、商品或模拟流程，就推荐该行业或复制该流程。

## 明确排除

不纳入真实项目工作流：

- 模拟商城中的浏览、下单、付款、虚拟积分和任务闯关；
- 课程平台账号、手机号、排行榜、答题进度等操作；
- 模拟商品、虚拟订单和平台演示数据；
- 任何没有现实来源、无法对应用户城市/客户/成本的题目数字。

这些内容可以用于说明“这是课程练习，不是现实经营证据”，但不得进入市场分析、成本测算、客户画像或财务预测。

## 转成专家检查表

### 找项目

- 项目是否具体说明卖什么、卖给谁、解决什么问题？
- 方向是否来自个人技能、经验、资源、兴趣或真实观察？
- 是否明确排除了资金、资质、时间和能力不允许的方向？

### 市场

- 是否存在真实客户和替代方案？
- 客户为什么现在就要解决，而不是“有了更好”？
- 竞争判断是否有来源、走访或可复核记录？

### 开办

- 平台规则、主体资质、类目许可和履约要求是否核实？
- 货源、样品、交付时效、退换责任是否写清楚？
- 启动投入、固定支出和周转金是否分开？

### 运营

- 是否先验证自然流量和转化，再决定付费推广？
- 是否只改一个变量并记录基线、周期和结果？
- 是否建立复购、评价、退款和投诉的反馈闭环？

### 客服履约

- 售前承诺是否在当前产能内？
- 售后响应、退换、纠纷升级和补偿边界是否明确？
- 差评是否被分类为产品、页面、客服、物流或预期管理问题？

### 财务风险

- 收入、变动成本、固定成本和现金流是否分开？
- 盈亏平衡是否使用真实可核验输入？
- 什么时候缩小规模、暂停投放或退出，是否提前写明？

## 试题引用格式

引用测试题时采用以下格式：

```text
【课程自测题】题目考查：客户需求 / 项目选择 / 运营规则
【可迁移原则】用一句话写出判断原则
【现实使用限制】需要结合用户项目、城市、平台和实测数据重新验证
```

不要输出“答对这道题，所以这个项目一定能做”这种结论。
