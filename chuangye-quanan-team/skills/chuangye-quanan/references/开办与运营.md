# 阶段 8–10｜开办准备、运营与财务、项目优化

> 这三个阶段把"选定的项目"变成"能开门的生意"。
> 顺序不能颠倒：先有条件开门（8），再看门开得怎样（9），最后才是改（10）。
> 跳过 8 直接谈优化，等于给还没开的店设计陈列。

# 阶段 8｜开办准备

四个决定，四个都必须落到文件：**卖在哪（平台）、货从哪来（货源）、谁来做（团队）、合不合法（形态与资质）**。

## 1. 平台选择（五维对比，不看好评看规则）

| 维度 | 要查的具体项 | 怎么查 |
|---|---|---|
| 入驻门槛 | 主体要求、保证金、类目资质 | 平台招商页 + 规则中心 |
| 费用结构 | 佣金率、支付手续费、推广最低预算 | 费率说明页（按类目查，别用平均值） |
| 流量机制 | 搜索/推荐/私域各占多少、新店有没有扶持 | 平台官方运营指南、招商说明会 |
| 履约要求 | 发货时效、退换规则、处罚条款 | 规则中心原文 |
| 规则风险 | 常见违规类型、扣分/清退机制 | 处罚公示、商家社区 |

**判定方法**：先定"我的履约能力上限"（能否 48 小时发货、能否承担退换），再筛平台。**不是选最大的平台，是选规则你能守住的平台。**

> 输出一张表：平台 × 五维，每格写"结论 + 来源"，最后一行写"排除理由"。
> 只留 1 个主平台 + 1 个备选，不要同时铺三个。

## 2. 组织货源（四条路，各有代价）

| 路线 | 优势 | 代价 | 适合 |
|---|---|---|---|
| 产业带/工厂直采 | 成本低、可定制 | 起订量、压货、账期 | 有资金、有确定爆款 |
| 批发市场拿货 | 起订量低、可看货 | 价差小、同质化 | 起步试水 |
| 一件代发 | 零库存、零资金 | 毛利薄、品控不可控、发货慢 | 纯验证阶段 |
| 自有生产/手工 | 差异化、毛利高 | 产能天花板、交付周期 | 有手艺、有独特配方 |

**必做三件事**（任何路线都要）：

1. **样品验货**：拿到实物再上架，不要用供应商图当主图
2. **账期与结算**：写清付款方式、退换责任、破损赔付
3. **断货预案**：主推款至少留 1 个替代供应商

## 3. 组建团队（先定职能，再定人）

| 职能 | 干什么 | 一人多岗时的取舍 |
|---|---|---|
| 运营 | 选品、上架、推广、数据 | 创始人自己扛 |
| 客服 | 售前咨询、售后处理 | 可外包/兼职，但响应时长要定死 |
| 履约 | 打包、发货、退换 | 前期自己扛，日出 20 单后必须拆出去 |

**判据**：**哪一项做不完会直接导致差评，就先招哪一项。** 不要按"岗位齐全"配人。

> 家庭成员的参与要提前写清分工和决策权，不要默认"帮忙"。

## 4. 法律形态与资质

| 形态 | 特点 | 什么时候选 |
|---|---|---|
| 个体工商户 | 注册简单、税负简单、承担无限责任 | 小规模试水、线下小店 |
| 有限责任公司 | 有限责任、可开票、规范成本高 | 需要开票、有合伙人、要融资 |
| 合作社/其他 | 特定行业适用 | 涉农、特定品类 |

**必须核的三类资质**：

- **主体资质**：营业执照经营范围是否覆盖所售类目
- **类目许可**：食品、化妆品、图书音像、医疗器械、酒类等有专门要求
- **平台特殊要求**：品牌授权、质检报告、进口报关单

> ⚠️ 这一节**只给判断框架，不给具体法规条文**。资质与税率以主管部门和平台最新公示为准，
> 涉及具体办理时建议咨询当地政务服务中心或专业代理。

## 5. 启动资金表（三段式）

| 段 | 包含 | 常见漏算 |
|---|---|---|
| **一次性投入** | 保证金、装修/拍摄、设备、首批备货、注册与许可 | 拍摄器材、包装开模、软件年费 |
| **三个月固定支出** | 房租/仓储、人工、软件、基础推广 | 自己的社保、水电、宽带 |
| **周转备用金** | 补货、退款垫付、突发赔付 | 平台账期造成的现金缺口 |

**规则**：周转备用金 ≥ 一个月固定支出。算完如果超出可承受本金 → **回到阶段 3 换项目或缩规模**，不要靠借钱补缺口。

# 阶段 9｜运营管理与财务计划

## 1. 店铺呈现

| 层 | 做什么 | 判定标准 |
|---|---|---|
| 商品结构 | 引流款 / 利润款 / 形象款，比例先定 | 没有引流款 = 没有新客；没有利润款 = 白忙 |
| 主图 | 3 秒说清"是什么 + 给谁 + 凭什么" | 遮住标题也能看懂 |
| 详情页 | 解决疑虑的顺序：是什么→为什么值→怎么用→售后 | 按客户提问顺序排，不按工厂参数排 |
| 店铺装修 | 分类清晰、首页有主推 | 三跳之内能找到商品 |

## 2. 店铺管理

- **交易**：订单、发货、退换的时限与话术模板
- **客服**：响应时长、常见问题库、纠纷处理分级
- **评价**：差评 24 小时内回应；把差评当选品和详情页的改进输入
- **日常**：每日必看三项——访客数、转化率、退款原因

## 3. 店铺推广

**推广规划三步**：目标（要多少单）→ 预算（能承受多少获客成本）→ 节奏（先测后放）。

| 方式 | 适合阶段 | 关键指标 | 风险 |
|---|---|---|---|
| 内容/自然流量 | 起步 | 完播、点击、进店 | 起量慢 |
| 付费推广 | 有转化验证后 | 获客成本、ROI | 没验证就投 = 烧钱 |
| 私域/复购 | 有回头客后 | 复购率、转介绍 | 需要持续供给内容 |

**铁律**：**先用自然流量跑出转化率，再开付费。** 转化率没验证就投流，等于给平台的算法交学费。

## 4. 财务计划

### 三张表

| 表 | 内容 | 用途 |
|---|---|---|
| 启动资金预测 | 阶段 8 的三段式 | 回答"要多少钱才能开" |
| 利润预测 | 收入 − 变动成本 − 固定成本 = 净利 | 回答"多久能回本" |
| 现金流表 | 按月：进账、出账、余额 | 回答"会不会中途断粮" |

### 三个必算指标

```
毛利率 =（售价 − 变动成本）÷ 售价
盈亏平衡月销量 = 月固定成本 ÷ 单件毛利
现金周转天数 = 平均库存天数 + 平台账期 − 供应商账期
```

**判读**：
- 毛利率 < 40% → 提示风险，并给出盈亏平衡月销量让用户自己判断能不能做到
- 现金周转天数 > 60 天 → 说明这门生意需要额外周转金，不是"卖得越多越好"
- 净利为正但现金流为负 → 增长会加速死亡，必须先解决账期

> 数字全部来自用户提供的进价、售价与平台费率。**没有一项可以凭记忆填。**

# 阶段 10｜项目优化

## 1. 优化要素（先定位短板，再动手）

| 要素 | 看什么指标 | 出问题时先改 |
|---|---|---|
| 人 | 客服响应、纠纷率 | 话术与排班 |
| 货 | 转化率、退货率、差评关键词 | 选品与详情页 |
| 场 | 进店率、停留、跳失 | 主图与店铺结构 |
| 流量 | 访客数、获客成本 | 推广内容与渠道 |
| 履约 | 发货时长、破损率 | 包装与供应商 |

## 2. 优化维度（五个可量化的口子）

转化率 / 客单价 / 复购率 / 履约时效 / 退货率。

**一次只动一个**。同时改主图、改价格、改详情，出了结果也说不清是谁的功劳。

## 3. 优化方法（单变量试验 + 周期复盘）

```
第 1 步 选一个指标，记录当前基线（连续 7 天）
第 2 步 只改一个变量（主图 / 标题 / 价格 / 赠品）
第 3 步 跑满一个周期（至少 7 天或 100 个访客）
第 4 步 对比基线，决定保留或回滚
第 5 步 写进复盘表，再动下一个变量
```

### 复盘表

| 日期 | 指标基线 | 改了什么 | 结果 | 保留/回滚 | 结论 |
|---|---|---|---|---|---|
| | | | | | |

**不要优化的三件事**：还没验证转化率就优化 ROI；没有复购就优化客单价；样本不足 100 就下结论。

## 4. 什么时候该停

出现以下任一情况，回到阶段 3 重新评估，而不是继续优化：

- 连续 3 个优化周期，核心指标没有改善
- 毛利结构恶化到无法覆盖固定成本
- 平台规则变化导致原定位不成立

> **止损也是经营决策。** 把"什么条件下退出"在阶段 4 的 SWOT 里就写死，到这里才不用凭情绪判断。
