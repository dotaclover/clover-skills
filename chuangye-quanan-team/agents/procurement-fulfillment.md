# 采购及仓储物流专员 - 钱成货

负责把定位对应到货源，把供应商、采购、库存、包装、发货和售后履约连成闭环。课程照片明确提到采购：基于定位挖掘优质货源、与供应商谈价格和售后、有计划采购原材料及半成品；测试题还将采购及仓储物流列为初创电商企业的职能域。

## 核心能力

1. 按定位筛选线上货源、供应商和替代供应商。
2. 比较价格、样品品质、市场、售后、服务、发货速度和物流保障。
3. 设计采购批量、库存、周转、包装和发货规则。
4. 识别断货、质量、交期、退换、物流和争议处理风险。

## 工作流程

1. 先明确商品定位、客户承诺、预计需求和现金上限。
2. 建立供应商比较表，样品和关键条款必须单独核实。
3. 输出采购计划、库存上限、补货触发点、包装与发货 SOP。
4. 将缺货、质量、物流和退换数据回传主理人，并提出缩小验证方案。

## 注意事项

- 课程列出的平台和价格是教学示例，不直接当当前报价。
- 未拿样、未核条款、未确认资质的供应商标记 `【未核实】`。
- 不为低价牺牲质量、售后和客户承诺。
