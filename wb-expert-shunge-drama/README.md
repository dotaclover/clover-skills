# 短剧专家顺哥

短剧制作方法论专家。给一个想法或一份剧本，按规程把它做到能交付的成片；只提供方法，不预设任何剧集、账号或供应商参数。

## 类型

Agent 型（单个 AI 专家，不依赖其他专家包）。

## 它解决什么

短剧最容易崩在两处：**开场很带感，越做越对不上**（设定漂移、角色串脸、道具数量错），以及**做完了不敢验收**（字幕轴是套剧本秒位猜的，接缝没逐帧看）。这个专家把这两个坑写成了硬规程。

## 技能

| 技能 | 管什么 |
|---|---|
| `short-drama` | 开工六项输入契约、九步制作、可复用的方法库（事实源、字幕实测、切点坐标、局部修复、验收重建） |
| `wb-skill-storyboard` | 分镜表与逐镜 Seedance 提示词：anchor phrase 保角色一致、Motion 清单、单镜单运动、I2V 首帧、三视图定妆，附型号时长与分辨率校验。**只出提示词，不提交生成** |
| `seedance-dev` | 接口出片：显式选渠道（官方 Ark / 华锐），核格式、提交一次不重发、按同一 provider 轮询、下载验收；附收费与写入授权门禁 |
| `doubao-web-video` | 豆包网页版出视频：切模式、核参数、按序传参考图、状态机防重复扣费、下载校验 |
| `doubao-web-image` | 豆包网页版出图：控张数、收参数浮层、逐张认领下载；分镜前的定妆参考图也走这条 |

五个技能全部内置，**不依赖任何外部技能包**。分镜技能只到提示词为止；真出片由专家按渠道调后面三个。

## 制作顺序

1. 核事实源 → 2. 分集与剧本 → 3. 分镜（`wb-skill-storyboard`）→ 4. 参考素材（`doubao-web-image`）→ 5. 生成（接口 `seedance-dev` / 网页 `doubao-web-video`）→ 6. 字幕与后期 → 7. 验收

前一步没确认不进下一步。剧本、分镜、台词改动先给用户拍板；出图、出片、重出、试风格再次确认。第 5 步两条链参数口径不同，不交叉复用；未指定渠道先问。

## 硬规则摘要

- 单条时长按型号取（Seedance 2.0 系列 4–15s，2.5 为 4–30s），下限 4s；分辨率同理，1080p 以上只有 2.0 标准版支持。
- 同一角色的 anchor phrase 逐镜逐字复用，近义词会触发重新生成。
- 字幕按素材实测，不套剧本秒位；静音检测只给候选，ASR 不代替逐字核对。
- 修复先评估剪辑与局部回填，最后才重生成；改时长必须同步映射音频、字幕和所有叠加层。
- 验收抽帧、核切点两侧、放大修复区、实时播放，ffprobe 核规格、ffmpeg 全解码核完整性。

## 可分享性

包里不含任何真实剧名、角色名、客户名称、账号、密钥或供应商套餐承诺。方法库中出现的命令参数（如 `scene` 阈值、频带、模糊半径）均标注为「示例，需按本片素材标定」，不写成通用阈值。

生成链只需要使用者自己的浏览器登录态或环境变量里的 API Key，包里不预置任何凭据，也没有指向包外目录的可执行依赖。百度渠道只保留差异索引：完整协议不在包内，遇到时明确说明缺口，不猜字段。

## 与其他短剧类专家的关系

本包是**自包含**的：规程、分镜、接口出片、网页出片都在包里，装完即可用，不需要另装技能。如果你手里已经有专门的浏览器托管或批量出片工具，两者可以并存，但同一时间只用一个，避免两套流程互相覆盖。
