# 视频号脚本工坊

四个模块：**选题 → 钩子（标题 + 前 3 秒）→ 时间轴脚本 + 口播稿 → 封面**，发布前过**违禁词体检**。

**三条底线**
- **零预设**：不含任何预设垂类、人群、话术，全部由当次输入或用户画像推断填充。
- **零编造**：数据、案例、时间地点、个人经历一律留【】占位。见 `references/truthfulness.md`。
- **零喊麦**：视频号是熟人社交场，喊麦式开场在这里是反效果。

> 本 Skill 自洽独立，不依赖任何外部技能或平台能力，可单独分发使用。

---

## 视频号的三条平台铁律（与抖音最大的差别）

| # | 规则 | 后果 |
|---|---|---|
| 1 | **社交推荐 55% + 算法推荐 45%** | 朋友点赞过的内容优先曝光；冷启动高度依赖私域，新号无社交资产会很吃力 |
| 2 | **指标权重：收藏率 > 复访率 > 铁粉互动** | 不是完播率为王——**追求收藏和复看，不是追求刺激** |
| 3 | **7 天长效赛马** | 抖音 24–48 小时定生死，视频号第 4–7 天仍可能爆发 |

**第 2 条决定了脚本的取向**：抖音要"每 12 字一个爆点"，视频号要"值得存下来再看一遍"。同样一个选题，两个平台写出来是两种东西。

**附加**：转发率 > 评论率——视频号的转发是社交货币，内容要"值得转给身边的人"。

## 第 0 步：给预设场景卡，不问一串问题

**不要一次抛出 6 个问题。** 先拼出一段**完整的预设场景文本**给用户改。

推断来源，按优先级取：
1. **本次对话已给的信息**（最高优先级）
2. **用户画像与历史记忆**
3. **该垂类的常识值** —— 取用时必须标 `（推断，可改）`

**只有「本篇内容」是必填项**。其余全部预设好。

模板见 `references/input-brief.md`。

---

## 四条铁律

1. **先有人群，后有标题。** 视频号 25–50 岁为主，45 岁以上占约 35%——**用户结构比抖音年长**，选题和用语都要跟着变。
2. **形态决定时长与节奏。** 先定 A/B/C/D/E，再定秒数。
3. **标题出 3 条，三条三种机制。** 凑不齐 = 采集信息不够，回去补，不许硬凑。
4. **真实细节一律留占位。**

---

## 形态路由

| 形态 | 适用 | 主攻 | 时长 | 节奏 | 分镜密度 |
|---|---|---|---|---|---|
| **A 知识科普** | 一个知识点讲透、行业洞察 | 收藏 | 60–120s | 稳，留思考间隙 | 中 |
| **B 故事共鸣** | 真实经历、正能量情感、人物故事 | 转发 | 60–90s | 慢，情绪有起伏 | 低 |
| **C 观点洞察** | 反常识判断、立场表态 | 评论+转发 | 45–90s | 前紧后松 | 中 |
| **D 教程实操** | 手把手、步骤演示 | 收藏+复访 | 90–180s | 稳定，可分段 | 中高 |
| **E 热点解读** | 24 小时内事件、政策新规 | 时效流量 | 30–60s | 快 | 高 |

**判断**：讲清楚一个知识点 → A｜有完整真实经历 → B｜我想反驳一个看法 → C｜手把手教 → D｜24 小时内热点 → E。

**三条硬例外**
- A / D 型**必须给"可存下来的东西"**——一张对照表、一组步骤、一个结论。收藏率是视频号第一指标。
- B 型**不要追求快节奏**，情绪需要铺陈，快切会破坏共情。
- E 型**时效优先于打磨**，晚 12 小时基本没量。

## 分支：旧片诊断

用户给的是**已发布视频 + 数据差** → 走诊断，**不重新采集**。

| 层 | 看什么 | 常见病灶 |
|---|---|---|
| 1 标题 / 封面 | 有没有明确价值承诺 | 太泛，看不出看完能得到什么 |
| 2 前 3 秒 | 有没有留住人 | 自我介绍、寒暄、慢启动 |
| 3 中段节奏 | 信息密度与转折 | 平铺直叙，没有起伏 |
| 4 收藏设计 | 有没有可存下来的东西 | 全是观点，没有清单或结论 |
| 5 结尾 | 有没有引导收藏 / 转发 | 直接结束，无 CTA |
| 6 合规 | 是否被限流 | 功效承诺、极限词、诱导分享 |

输出：**先给诊断结论（哪 1–2 层是主因），再给改写版本**。

> 数据对应关系：完播低 → 改前 3 秒；收藏低 → 补可存下来的清单；转发低 → 补情绪共鸣；评论低 → 补站队钩子。

## 交付规格（精简档）

| # | 项目 | 规格 |
|---|---|---|
| 1 | **标题 ×3** | 表格 `标题/机制/评分`，标 ⭐ 推荐 1 条 |
| 2 | **前 3 秒钩子 ×3** | 与标题配套的三种开场，标注各自适配哪个标题 |
| 3 | **时间轴脚本** | 分段表：`时间段 / 这一段干什么 / 关键信息` |
| 4 | **完整口播稿** | 可直接念的成稿，标注字数与预估时长 |
| 5 | **封面建议** | 主视觉 + 封面文案 + 关键镜头提示 |
| 6 | **违禁词体检** | 命中项 + 替换后的安全版本 |
| 7 | **自检** | 勾选结果 |

**分镜表不在默认交付里** —— 用户说「展开分镜 / 给分镜」才出，见 `references/shot-plan.md`。

不输出思路说明与过程分析。

## 填写策略：先简后拆（不要一次填满）

| 产物 | 第一遍：简版（必出） | 第二遍：拆解展开（确认后 / 用户要求时） |
|---|---|---|
| **预设场景卡** | 1 行本篇内容 + 其余预设值 | 补全关键词 |
| **标题评分** | 每条：总分 + 最低维度 | 推荐那条展开五维明细 |
| **时间轴** | 段名 + 秒数 + 一句内容 | —（时间轴本身就是简版） |
| **分镜** | **不给** | 展开每镜的景别 / 运镜 / 画面 / 字幕 / 音效 |
| **封面** | 主视觉 + 文案 | 展开构图与生图提示词 |
| **自检** | 必检 8 项 | 按形态展开细项 |

**规则**
- 第一遍出**方向性内容**，等用户确认方向。
- 用户说「展开 / 继续 / 细化」才出第二遍。
- **用户没确认方向前，不要把重型模板全部填满。**

## 标准流程

1. **预设场景卡** — 拼一段完整场景文本给用户改，只等「本篇内容」
2. **搜同类爆款** — 标题避让 + 结构借鉴（见 hook-playbook 第 -1 步）
3. **定形态** A/B/C/D/E，据此定时长
4. **标题 ×3** — 三种机制，各附评分
5. **前 3 秒钩子 ×3** — 与标题配套
6. **时间轴脚本** — 按形态骨架切段
7. **完整口播稿** — 真实细节留【】占位
8. **封面建议** + 结尾 CTA
9. **违禁词体检** — 标题 + 口播稿 + 字幕 + 封面文案全过一遍
10. **自检**附末尾

---

## 输出格式约定

- 标题与钩子用**表格**。
- 时间轴用**表格**：`时间段 | 这一段干什么 | 关键信息`。
- 口播稿单独成块，可直接念，不写"思路"。
- 占位符统一【】，口播稿上方声明"需要你填的 N 处"。
- **语感**：熟人语感——像跟一个认识的人讲话，不是对着镜头喊。

---

## 自检清单（必检 8 项）

- [ ] **标题**：三条三种机制，评分均 ≥ 70，看得出看完能得到什么
- [ ] **前 3 秒**：有钩子，无自我介绍与寒暄
- [ ] **时间轴**：符合形态骨架，时长在区间内，分段 ≥ 4 段
- [ ] **收藏设计**：A / D 型给了可存下来的清单或结论
- [ ] **口播稿**：字数与时长匹配（约 4–5 字/秒），口语可念
- [ ] **真实性**：【】占位全部列出，没有一处是我替他填的
- [ ] **合规**：标题 + 口播稿 + 字幕 + 封面文案全部过违禁词
- [ ] **合规**：无诱导分享（分享到 X 个群领取这类）

> ⚠️ 自检是**软自审**，不能代替违禁词体检。详见 `references/compliance.md`。

---

## 禁止事项

- **喊麦式开场**："家人们！""三秒钟教你！"——熟人社交场里这是反效果。
- **追求爆点密度**：视频号第一指标是收藏率，不是完播刺激。
- **只讲观点不给清单**：收藏率会很低。
- **功效承诺**：根治、7 天见效、瘦 X 斤。
- **极限词与绝对化**：最、第一、100%、永久、唯一。
- **诱导分享**：分享到 X 个群领取、集赞解锁。
- **变体规避**：谐音、拆字、符号替代——同样会被识别。
- **编造细节**：把【】当真实内容发出，或替用户填"看起来合理"的值。
- **凑数分镜**（展开分镜时）。
