# 理论层：先有判定标准，再做动作

> 这一层不产出结论，只提供**判断的尺子**。
> 阶段 1–11 里每一次"这个方向行不行""这个客户算不算真客户"，判定标准都在这里。
> 不读这一层直接跑阶段，输出会变成一堆正确的废话。

---

## 一、企业想法的四问（一切分析的起点）

一个成型的想法必须能同时回答四问。答不上任何一问，它还是"行业名词"，不是项目。

| 问 | 要答到什么程度 | 常见错误 |
|---|---|---|
| **卖什么** | 具体产品/服务 + 规格 + 与同类的差别 | 答成品类（"做服装"），不是商品（"给 3–6 岁孩子做防水罩衣"） |
| **卖给谁** | 具体到能画出这个人的一天 | 答成人口统计（"25–45 岁女性"） |
| **怎么卖** | 渠道 + 触达方式 + 成交方式 | 只答平台名，不答"他怎么知道你" |
| **满足什么需要** | 省时间/省钱/省麻烦/安心/开心/被关心，选一个主要的 | 四个都要，等于没有重点 |

**用法**：阶段 1 生成方向时用它检验；阶段 3 用它收口；阶段 5 用它展开；阶段 11 用它当计划书第一章。

## 二、你适合创办企业吗（自我评价）

官方课程把自我评价拆成三个维度，这个拆法比"性格测试"有用得多：

| 维度 | 具体看什么 | 结论怎么用 |
|---|---|---|
| **创业素质** | 承担风险的意愿、扛不确定性的耐受力、遇挫后的恢复速度 | 不是打分，是找「哪种压力会让我放弃」 |
| **知识与技能** | 行业知识、专业技能、经营常识（算账/招人/谈判） | 缺哪项，决定要不要找合伙人或先打工补 |
| **条件与资源** | 资金、时间、场地、人脉、家庭支持 | 直接决定项目的**起步门槛上限** |

### 三条判读规则

1. **自我评价不是打分表。** 得分高不代表能创业，得分低也不代表不能——它只用来定位缺口。
2. **缺口必须转成动作。** 写成"缺 X → 用 Y 补 → 补不上就放弃这个方向"，否则评价没有意义。
3. **家庭支持单独看。** 它不是"资源"里的一个子项，而是能一票否决的约束（尤其涉及全职投入和家庭资金）。

### 四种应当暂停的情形（不是劝退，是排序）

- 需要**即时稳定收入**覆盖刚性支出 → 先做副业验证，不要全职跳
- 可投入时间**每周不足 10 小时** → 只做轻履约模式，别选需要守店/囤货的
- 无法承担**本金全损** → 选投入接近 0 的验证方式，先验证再投入
- 明确**不愿与人打交道** → 避开客服密集型、地推型项目

> 这四条并非教材原文，是从大量失败案例归纳的判断规则，属于经验值，供参考。

## 三、想法从哪里来（五种来源）

官方课程把产生想法的方法归为五类。**它们是并列的，不是有先后**——缺哪一类，候选池就会有系统性盲区。

### 1. 头脑风暴

- 规则：先求量不求质，20 分钟内不评价；一人写或多人写都行
- 输出：至少 30 条原始想法，**不许在这一步筛**
- 常见失败：边写边否定，最后只剩 3 条"安全"的

### 2. 调查你准备创业地区的企业情况

- 看什么：同类商家数量、位置、客流时段、价格带、开了多久
- 方法：分工作日/周末各走一次，记录而非估计
- 产出：一张"本地供给地图"，直接喂给阶段 3 的竞争维度
- ⚠️ 电商项目也要做这一步：本地供给决定你有没有"产地/ proximity 优势"

### 3. 调查你准备创业地区的环境

- 看什么：人口结构、消费水平、产业基础、交通物流、季节特征
- 方法：公开统计年鉴、地方政府工作报告、园区招商资料
- **注意**：这是"市场环境"，不是"环境影响评估"（见第六节），两者完全不同

### 4. 利用经验

- 你自己的从业经历、家里的生意、朋友的行业
- 判断标准：**能不能说出这个行业三个"外行不知道"的细节**
- 说不出 → 你只是"接触过"，不是"有经验"

### 5. 利用互联网

官方课程把这一条单列为方法，意味着它和线下调查同等正当，不是捷径。

| 做法 | 具体操作 | 产出 |
|---|---|---|
| 需求反推 | 搜"求推荐/有没有/怎么解决"类问题，看重复出现的抱怨 | 痛点清单 |
| 供给扫描 | 平台按销量排序，看前 20 名的价格带、卖点、差评 | 竞争基线 |
| 趋势判断 | 平台行业报告、指数工具、展会新品 | 品类冷热 |
| 从业者视角 | 招聘信息里的岗位职责 = 这个行业实际在干什么 | 能力缺口 |
| 跨境/产地 | 海关数据、产业带名录 | 货源与价差线索 |

**纪律**：网上看到的一切都是"可见信息"，不是后台数据。写进档案时必须带来源和检索日期。

> **具体怎么取、取不到怎么办、AI 给的答案怎么判真假** —— 见 `AI赋能.md`。
> 这一节说的是"该看什么"，那一页说的是"看不到时怎么逼近"，以及"怎么确认自己看的不是编的"。

## 四、筛选与分析的四个标准

阶段 2–3 的权重顺序（资源可及性 > 个人匹配度 > 市场需求 > 起步门槛）来自这套标准，展开如下：

| 标准 | 问什么 | 不通过的典型信号 |
|---|---|---|
| **资源可及性** | 现有资源能覆盖多少启动条件 | 需要新增 3 项以上关键资源 |
| **个人匹配度** | 技能/经验/兴趣与这件事的重合度 | 只能靠"学"来补，且学习周期 > 3 个月 |
| **市场需求** | 有没有人已经在为同类需求付钱 | 只能找到"应该有人要"，找不到实际付费证据 |
| **起步门槛** | 资金/资质/时间/履约的最小闭环成本 | 首单之前必须先投入超过可承受本金 |

> 四条不是评分项，是**否决项**。任何一条明确不通过，先别算总分。

## 五、痛点与痒点（阶段 3 的核心判断）

| | 痛点 | 痒点 |
|---|---|---|
| 定义 | 不解决会持续难受 | 有了更好，没有也能过 |
| 付费意愿 | 会主动找解决方案 | 需要被激发 |
| 获客成本 | 低（需求现成） | 高（要先教育） |
| 复购 | 稳定 | 波动大 |
| 典型 | 漏水、断货、证件办不下来 | 好看、好玩、显得有品位 |

**判读方法**：问"用户今天是怎么凑合解决的？"——如果他已经在花时间/花钱凑合，是痛点；如果答案是"他也没觉得有问题"，是痒点。

痒点生意不是不能做，但必须在结论里写明：**获客靠内容，复购靠新鲜感，利润靠溢价**。

## 六、环境影响评估（最容易被误当成"市场环境"）

这是**你的企业对外部产生什么影响**，不是外部环境对你有什么影响。

| 问 | 具体内容 | 什么时候必须做 |
|---|---|---|
| 资源消耗 | 水、电、原料、包装用量；是否用一次性材料 | 生产型、餐饮型、包装量大 |
| 污染与排放 | 废水、油烟、噪音、固废、快递包装 | 有加工环节、临街、居民楼内 |
| 对周边的影响 | 人流、车流、扰民、消防通道 | 线下门店、仓储 |

**输出**：三项各一句结论 + 是否需要许可/治理投入 + 治理成本是否进入成本表。

> 常见错误：把这一节写成"本地市场竞争激烈、消费升级"——那是市场环境，不是环境影响。
> 电商项目里，这一节通常落在**包装与快递耗材**上，别直接跳过。

## 七、易混概念对照

| 容易混的两件事 | 区别 | 后果 |
|---|---|---|
| 环境影响评估 vs 创业环境分析 | 你对环境的影响 vs 环境对你的影响 | 写错章节，整段废掉 |
| 需求 vs 想要 | 不解决会难受 vs 有了更好 | 把痒点当痛点，备货压死 |
| 商业模式 vs 盈利模式 | 怎么创造并交付价值 vs 怎么收钱 | 计划书里说不清靠什么赚钱 |
| 客户细分 vs 客户分析 | 把人群切开 vs 验证他们真的会买 | 分得很细，但没人付钱 |
| 市场定位 vs 商品定位 | 在客户心里占什么位置 vs 卖什么规格的货 | 定位写成商品说明书 |
