# 模块地图：课程体系 ↔ 本技能阶段

> 这一页回答一个问题：**这套技能覆盖了培训课程的哪些部分，哪些还没覆盖。**
> 用它来判断"用户提的这个问题该不该由本技能回答"，也用来判断下一步该补哪块。

## 一、三套课程模块与覆盖状态

| 模块 | 课程里讲什么 | 本技能对应 | 覆盖 |
|---|---|---|---|
| **A 企业想法**（通识） | 什么是企业想法四问、你适合创业吗、想法从哪来、怎么筛选分析、环境影响评估 | `理论层.md` + 阶段 1–6 | ✅ 完整 |
| **B 创办企业**（通识） | 市场评估、人员组织、法律形态、启动资金、利润计划、判断能否生存、开办 | 阶段 7–9 + 11 | ⚠️ 方法齐全，**教材章节未逐条核对** |
| **C 网络创业·电商**（八步） | 形势 → 机会类型 → 自我评价 → 项目选择 → 市场分析 → 开办准备 → 运营管理 → 项目优化 | 阶段 1–10 | ✅ 结构对齐（节标题已实物核对） |
| **C-1 电商基础** | 平台、交易、支付、物流、客服等基础认知 | 阶段 8–9 | ⚠️ 按通用方法写，**未对齐该教材目录** |
| **C-2 寻找电商创业项目** | 项目来源途径、筛选方法、结合自身条件选择 | 阶段 1–4 | ✅ 已覆盖（本技能的原点） |
| **C-3 微店运营指南** | 微店场景下的开店、上架、推广、客户维护 | 阶段 8–10 | ❌ **未覆盖**（微店特有规则未写入） |

> 判定口径：✅ = 有对应内容且结构已核对；⚠️ = 有方法但没和教材目录逐条对齐；❌ = 没有。

## 二、课程链路与本技能阶段的对应

```
A 企业想法 ── 阶段 1–6（定位 → 想法 → 筛选 → 对比 → 体检 → 画布 → 客户细分）
                    ↓
C 前置两步 ── 阶段 0 的赛道判断（形势 + 机会类型）
                    ↓
C 第四步   ── 阶段 1–4（找项目 / 选项目）
                    ↓
C 第五步   ── 阶段 7（创业环境 + 客户 + 竞争对手 → 市场定位）
                    ↓
B / C 第六步 ── 阶段 8（平台 / 货源 / 团队 / 形态资质 / 启动资金）
                    ↓
C 第七步   ── 阶段 9（店铺呈现 / 管理 / 推广 / 财务）
                    ↓
C 第八步   ── 阶段 10（项目优化）
                    ↓
B 终点     ── 阶段 11（创业计划书）
```

## 三、三处必须分清的结构性差异

### 1. 两个「环境」不是一个东西

| | 企业想法模块第四章第三节 | 网络创业·电商模块第五步 |
|---|---|---|
| 名称 | **环境影响评估** | **创业环境** |
| 问什么 | 你的企业对自然/资源/周边的影响 | 外部营商环境对你生意的影响 |
| 在本技能 | `理论层.md` 第六节 | `市场分析.md` 第二节 |

**不要把环保评估当成市场分析的前身。** 讲课时把两者混在一起，是这类课程最常见的串味点。

### 2. 市场分析在电商模块里是**独立一步**，企业想法模块里没有

企业想法模块的终点是"筛出最好的想法"，它不负责验证卖给谁、对手是谁。
电商模块把市场分析单列一步，正因为**想法成立 ≠ 生意成立**。
本技能因此把阶段 7 独立出来，而不是并在阶段 3 里。

### 3. 想法的来路相反

- 企业想法模块：**自下而上**——从你自己身上长出来（技能、经验、身边环境、头脑风暴、互联网）
- 电商模块：**自上而下**——先看形势和机会类型，再看自己

本技能默认走"自下而上"（阶段 1 定位扫描）。如果用户是电商方向，**先在阶段 0 补一层赛道判断**，
否则会缺掉电商模块的前两步。

## 四、覆盖缺口（下一步该补什么）

| 优先级 | 缺口 | 补法 |

| P1 | 微店运营指南完全没覆盖 | 需要该书目录 + 平台规则页，再写一节 `开办与运营.md` 的微店变体 |
| P1 | 创办企业模块的章节结构未核对 | 拍目录页，把阶段 7–9、11 的节名对齐 |

| P3 | 直播电商方向完全空白 | 单独评估是否值得做（需要另一套履约与内容能力） |

## 五、AI 取证层：课程体系之外的增强层

`AI赋能.md` **不属于任何课程模块**，上面那张覆盖表里没有它的位置。原因是：三套课程都没有教"怎么判断 AI 给的数据能不能用"，这一层是本技能自己加的方法论。

| 它和教材的关系 | 说明 |
|---|---|
| **不是教材内容** | 不要在任何地方暗示"课程教了 AI 取证"，那是虚假背书 |
| **是「利用互联网」的工具化实现** | 企业想法模块第 2 版新增了「利用互联网」一节，讲的是用网络找想法与信息；本层是同一动作在当前工具条件下的具体做法 |
| **不替代实地调研，只做前置筛选** | 教材里的走访、观察、询价，仍然不可省。AI 层的作用是让实地那一趟「带着问题去」 |

**三条边界**（写进技能，也写进对用户的口径）：

1. **AI 层不产生 A 级证据。** A 级＝自己或熟人真实交易，只能靠真金白银和实地。
2. **决策链不变。** 取证只是为了给阶段 3 的测算、阶段 7 的定位提供输入，不改变「想清楚 → 小规模验证 → 再投钱」的顺序。
3. **"足不出户"有天花板。** 线上能把方案送到"值得花钱验证"，送不到"已经验证过"。这条必须主动告诉用户，否则用户会误以为做完阶段 7 就不用出门了。

> 加这一层的实际收益：原来大量条目只能写【未核实】就卡住，现在有了**降级路径**（L1→L5）和**评级标准**（0–10 分），
> 能把"不知道"变成"知道到什么程度、还差什么、下一步找谁"。这是本层真正的价值，不是"用 AI 更快"。

## 六、命名与合规（对外发布前必看）

1. **对外名称不使用课程体系的缩写**，也不使用培训项目品牌名。缩写属于商标性使用，平台审核会拦。
   本技能对外就叫「创业全流程」，描述里写"参考结构化创业筛选方法论"，不写课程缩写。
2. **列章节结构可以，抄正文不行。** 章节标题、公开方法论（四问、SWOT、五力）不受著作权保护；
   教材原文段落、原版练习表、案例故事不能复制进技能。
3. **不声称"官方""认证""指定工具"。** 这类词在审核里直接触发拒绝。
4. 教材里的案例数据经过教学化处理，**不得当作真实市场数据引用**；引用时必须说明这一点。
