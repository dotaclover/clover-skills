# 阶段 7｜市场分析（创业环境 · 客户 · 竞争对手 → 市场定位）

> 这一阶段回答的是阶段 3 没回答的问题：**这个项目卖给谁、对手是谁、凭什么赢。**
> 阶段 3 的六维对比里虽然有"需求真实性"和"竞争情况"，但那是**三选一时的相对比较**；
> 这一阶段是对**当选项目**做一次完整的市场验证，落点是「市场定位」。

## 一、三要素的关系

```
创业环境  ──┐
客户      ──┼──→ 市场定位（一句话：在什么场景下，为谁，提供什么，比谁强在哪）
竞争对手  ──┘
```

三者缺一：缺环境 → 定位踩到政策/平台红线；缺客户 → 定位写给同行看；缺对手 → 定位是自我感动。

---

## 二、创业环境分析

**别和"环境影响评估"混**：那一节讲你的企业对外部的影响（见 `理论层.md` 第六节），这里讲外部环境对你生意的影响。

| 维度 | 查什么 | 怎么查 | 影响什么 |
|---|---|---|---|
| 政策与准入 | 类目许可、资质要求、平台禁限售 | 主管部门官网、平台规则中心 | 能不能做 |
| 平台规则 | 入驻门槛、佣金结构、流量分发、违规处罚 | 平台招商页 + 规则中心原文 | 成本与风险 |
| 物流与履约 | 时效、覆盖、退换成本、冷链/大件限制 | 快递官网报价、平台履约规则 | 毛利与体验 |
| 支付与结算 | 账期、手续费、提现规则 | 平台结算说明 | 现金流 |
| 产业基础 | 本地/周边有没有产业带、批发市场 | 地方政府/园区公开资料 | 货源优势 |
| 季节与周期 | 淡旺季、节日峰值、气候影响 | 平台行业报告、往年数据 | 备货与排期 |

**输出要求**：每一行写"结论 + 来源 + 检索日期"。查不到就写【未核实】，并写清你自己能去哪查。

> 环境分析不是背景介绍。**每一条都必须能推导出一个动作**：
> "平台佣金 X% → 定价时必须预留 → 写进成本表"；"类目需许可 → 开工前先办证"。推不出动作的条目删掉。

## 三、客户分析

阶段 6 的客户细分是**把人群切开**；这里是**验证他们真的会买**。两者不重复：

| 阶段 6 回答 | 阶段 7 回答 |
|---|---|
| 按什么指标分 | 每一类人里，谁最可能先买 |
| 分成哪几类 | 他今天怎么凑合解决、愿意付多少 |
| 怎么描述他们 | 他在哪、什么时候、因为什么下单 |

### 四问

1. **谁最可能先买？**（不是"谁会买"，是"谁最先买"——首批客户决定你的启动方式）
2. **他今天怎么解决？**（替代方案是什么，包括"忍着不解决"）
3. **他愿意付多少？**（找同类商品的实际成交价带，不是"心理价位"）
4. **他在什么场景下决定买？**（搜索、刷到、朋友推荐、线下看到）

### 证据等级（写档案时必须标注）

| 等级 | 证据 | 可信度 |
|---|---|---|
| A | 自己或熟人真实下过单、有过交易 | 高 |
| B | 平台可见的实际成交价、销量、评价 | 中（可见信息，非后台数据） |
| C | 行业报告、公开统计 | 中低 |
| D | "我觉得""应该会" | **不算证据，只能写进假设** |

**纪律**：结论只能建立在 A/B 级证据上；C 级标来源；D 级必须显式写成"假设，待验证"。

## 四、竞争对手分析（线上可见信息法）

线下调研靠走街，线上调研靠**可见页面**。方法不同，但纪律一样：记录，不估计。

### 4.1 对手清单（先定边界）

- 同品类 + 同价格带 + 同人群 = 直接对手（5–10 个足够）
- 同需求但不同解法 = 替代对手（如"买成品" vs "自己 DIY"）
- 平台头部 = 标杆（不当作对手，用来看上限）

### 4.2 四张表

| 表 | 字段 | 用途 |
|---|---|---|
| **对手清单** | 店名/链接、开店时长、销量档、价格带、主推款 | 看格局 |
| **价格带分布** | 价格区间、对应销量、对应卖点 | 找空档 |
| **卖点对照** | 主图承诺、详情页结构、赠品/服务 | 找差异 |
| **差评痛点** | 差评关键词、出现频次、商家是否回应 | **最值钱的一张** |

> 差评表是唯一能直接告诉你"对手哪里没做好"的东西。
> 把前 50 条差评按关键词归类，出现 3 次以上的就是**可攻击的缺口**。

### 4.3 判读规则

1. **别把"没人做"当成机会。** 先判断是"没人想到"还是"需求不存在"——看有没有人在用别的方式凑合解决。
2. **别用销量榜当唯一标准。** 榜单是结果，不是原因；要看它靠什么拿到的量（价格、内容、履约）。
3. **头部不可复制的地方要标出来**（供应链、资金、达人资源），否则定位会写成"我要做得比他好"。

## 五、市场定位（本阶段唯一交付物）

### 定位陈述公式

```
在【什么场景】下，为【哪一类具体的人】，提供【什么产品或服务】，
解决【什么痛点】，区别于【谁】，因为我【一个可验证的优势】。
```

**不合格的定位**：

```
❌ "面向年轻人的高性价比家居好物"     ← 场景、人群、对手、优势全缺
✅ "给租房的单身青年，提供免打孔的厨房收纳件，
    区别于宜家系成品，因为我按出租屋常见尺寸做套装，且支持单件补货"
```

### 三种定位策略（选一个主策略，别混用）

| 策略 | 靠什么赢 | 适合谁 | 风险 |
|---|---|---|---|
| 成本领先 | 同品质更便宜 | 有货源/产业带优势 | 价格战没有底线 |
| 差异化 | 同价格更好/更特别 | 有技能/设计/内容能力 | 容易被抄，需持续迭代 |
| 聚焦 | 只服务一小群人的特殊需求 | 懂某类人、有信任基础 | 天花板低，需可复制 |

### 与阶段 5 业务画布的一致性检查

定位写完后回看画布四问，四项必须能对上：

- [ ] "卖给谁"与定位里的人群是同一批人
- [ ] "卖什么"与定位里的产品是同一个东西
- [ ] "怎么卖"能触达定位里的场景
- [ ] "满足什么需要"与定位里的痛点一致

对不上 → 改定位，不要改画布去迁就定位。

## 六、本阶段产出

写入 `创业项目档案/07_市场分析.md`：

1. 创业环境表（含来源与检索日期）
2. 客户分析（四问 + 证据等级）
3. 竞争对手四张表（含差评痛点 Top N）
4. 定位陈述（一句话）+ 主策略（成本/差异/聚焦）
5. 与画布的一致性检查结果
6. 【未核实】清单

> 结尾固定一句：结论依赖公开可见信息与用户提供的情况，最终决策与风险由用户自行承担。
