# 正文方法论

## 通用硬规则（所有形态）

| 项 | 规则 |
|---|---|
| 字数 | **800–1500 字**（低于 800 撑不起完读，高于 1500 完读率下滑） |
| 分段 | 每段 **2–3 句**，手机端不超过 3 行 |
| 小标题 | A/B/C/E 型要有，D 型可选 |
| 加粗 | 关键结论加粗，不要整段加粗 |
| 结尾 | **指令式提问**——"你中招几条？评论区说说" |
| 导流 | 零容忍：微信 / QQ / 电话 / 网址 / 二维码 |

> 发布后 **30 分钟**的初始互动（点击 / 完读 / 评论 / 点赞）决定是否进大流量池，所以结尾的评论引导不是客套。

## 五套骨架（按形态选，不要混用）

### A 单点放大 — 真实亲历 / 避坑实录

| 段 | 内容 |
|---|---|
| ① 开头 21 字 | 直接抛结果或最强冲突，**禁止铺垫** |
| ② 背景 | 时间 + 地点 + 当时的处境 |
| ③ 过程 | 按时间推进，2–3 句一段 |
| ④ 峰值瞬间 | 全篇情绪最高点，冲击力最强的一笔 |
| ⑤ 代价 / 教训 | 具体损失，用【】占位填真实值 |
| ⑥ 避坑 N 条 | **必须有**，否则只有共鸣没有收藏 |
| ⑦ 结尾提问 | 指令式 |

### B 清单干货 — {数字}个方法 / 步骤

| 段 | 内容 |
|---|---|
| ① 开头 21 字 | **结论前置**：`{数字}个方法，第{X}个最容易被忽略` |
| ② 为什么值得看 | 一句，说清读者能得到什么 |
| ③ 干货主体 | 分点，每点 = 一句结论 + 一句做法 + 一句为什么 |
| ④ 补充提醒 | 常见误区 |
| ⑤ 结尾提问 | 指令式 |

### C 测评对比 — 多方案横评

| 段 | 内容 |
|---|---|
| ① 开头 21 字 | **先给结论**：`{X}个方案比下来，{Y}更适合{Z}` |
| ② 对比条件说明 | 同条件才可比 |
| ③ 分维度对比 | 一个维度一段，各自优劣 |
| ④ 什么人选哪个 | 分人群给结论 |
| ⑤ 结尾提问 | 你选哪个？ |

### D 观点站队 — 反常识科普 / 反驳普遍看法

| 段 | 内容 |
|---|---|
| ① 开头 21 字 | 抛反常识结论 |
| ② 普遍看法 | 先说大家都怎么想 |
| ③ 为什么它是错的 | 2–3 条理由 |
| ④ 让步 | 承认对方成立的部分（增加可信度） |
| ⑤ 站队钩子 | 你怎么看？ |

### E 热点解读 — 24 小时内热榜

| 段 | 内容 |
|---|---|
| ① 开头 21 字 | 事件 + 你的判断，**不要只复述事件** |
| ② 事件还原 | 只写已确认的事实，不确定的写"据【X】报道" |
| ③ 增量 | 观点 / 影响 / 对普通人意味着什么（**这是 E 型的命门**） |
| ④ N 条提醒 | 避坑或应对建议 |
| ⑤ 结尾提问 | 指令式 |

## 关于倒金字塔

**B / C / D / E 型遵守倒金字塔**：最重要的事放开头。

**A 型例外**：真实亲历类开场给最强画面，不是结论。踩坑实录按时间推进才有代入感，一开场抛结论会把过程感毁掉。

---

## 写作用语

- **口语化**，不用书面语。
- 多用短句。
- 适当使用情绪钩子词：你、千万、别再、难怪、真相。
- 不用感叹号堆砌，不用"家人们""绝绝子"这类小红书语汇——**两个平台的用户结构不同**。

---

## 话题标签

```
#{热点词} #{垂类词} #{泛标签}
#{补充1} #{补充2}
```

- **3–5 个**，不要更多。
- 组合原则：**1 个热点 + 1 个垂类 + 1 个泛标签**。
- 优先 **10 万–100 万的中腰部话题**——头部话题竞争激烈，尾部没有量。
- 热点时效：追 24 小时内热榜，关联要自然。

## 自检细项（按形态查，不必每次全列）

- **A**：前 21 字是最强冲突？结尾挂了避坑清单？
- **B**：结论在开头 21 字内？每个分点有小标题？能照着做？
- **C**：对比维度 ≥3？给了"什么人选哪个"？
- **D**：有反方观点？有让步？结尾有站队钩子？
- **E**：有信息增量而不是复述？事实与观点分开了？时效在 24 小时内？
