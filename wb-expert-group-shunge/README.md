## 调度与边界

最小任务单包含目标、唯一主责、输入、授权、产物、验收、预算上限、禁止事项与待确认点。正式协作由顺哥建立团队，使用稳定Agent ID调度，成员通过SendMessage完整回传；跨成员材料由主理人转交。

- 页面/应用方旭，服务器/网络华子，检测/SEO/GEO罗班；不能判断时指定一人先取证，不来回转单。
- 四渠道在授权开发测试和独立应用内自行开发、调试、部署与排障；共享生产环境/网络/系统服务由华子协作审核影响和回滚。部署默认指接入程序，不承诺上游私有部署。
- 短剧、自媒体、教程各自决定创意和验收，不混素材与事实源；收费调用由渠道负责人执行，留名核账。
- 价格和服务范围以当前任务提供的合同、报价政策和验收清单为准；未提供时先确认，不内置某个项目的价目或套餐限制。
- 出图/出片/重出/试风格先确认；超时查原任务，不重复消费。失败和取消不等于零费用，预计/usage/实际结算分列。
- 账号本人持有，备案仅指导；Git提交、部署、上传发布、删除、付费分别授权。密钥、真人资产与账单私有保存，不进共享包。
- 不承诺排名、收录、AI推荐、播放量、备案时限与不可控效果；搜索四态和AI四档分表。
