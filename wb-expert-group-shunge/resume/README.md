# 顺哥简历

有人明确索取顺哥本人简历时，从这里取已核实资料；这是个人身份资料，不是其他用户的默认人设、经历或商业政策。涉及现行合作范围与年限时须再次确认维护状态。

安装包不保证能访问下述历史私有PDF和开发仓库路径。无法访问时不要假装已读取，不自动搜索个人目录；向资料持有人索取授权来源。历史同步清单仅供维护者参考，未经单独授权不修改外部网站、项目或发布产物。

## 以后要加的版本

命名统一为 `梁顺策-简历-<方向>.md`，例如：

- `梁顺策-简历-WorkBuddy讲师.md`：讲 AI 编程与工作流，突出培训与实操
- `梁顺策-简历-技术顾问.md`：突出架构判断与救火能力
- `梁顺策-简历-兼职.md`：投远程兼职岗位用，按 JD 调顺序

专项版不是把通用版复制一遍再改名字，是**换主线**：讲师版把交付能力放后面、把讲课与实战案例放前面；兼职版去业务口径、只留技术栈与项目。

## 四条规则

1. **不写手机号和邮箱**。仓库里只放微信（`cloverphp`，已在官网上公开）。要带电话和邮箱的完整版从 `_local/private/` 取，那份不入库。
2. **事实来源只有一份**：`_local/private/梁顺策简历.pdf`（2026-10-30 版，3页）。旧版 `RESUME2026.pdf` 已废弃删除，不要再引用；里面没有的经历（ACFlow 内容管理系统）也不要再写回简历。
3. **年限与身份口径只有一处能改**：`AGENTS.md` 的业务红线第 10 条。简历里的「16年」「独立开发者」跟着它走，改一处要回扫 `README.md`、`expert/agents/shunge.md`、`sku/S1-personal-site/profiles/cloverphp-top.json` 与 `gh-pages.json`，以及重建后的 `sites/` 快照与 GitHub Pages 产物。
4. **不编造**。项目、数字、管理人数都来自上面那份 PDF 与真实仓库；不确定的写「参与」，不写「主导」。
