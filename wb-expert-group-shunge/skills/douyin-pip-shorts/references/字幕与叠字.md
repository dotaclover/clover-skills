# 字幕与叠字

## 一、分别设计标签与旁白字幕

使用 `Tag` 和 `Sub` 两种ASS样式区分步骤标签与口播。当前构建器的垂直位置为：

- 标签：浮窗高 + `layout.pip_bottom` − 30；30是当前实现固定内边距。
- 浮窗口播：浮窗高 + `layout.pip_bottom` + `subtitles.pip_margin`。
- 满屏口播：`subtitles.full_margin`。

字体名、标签字号、口播字号均来自 `subtitles`。示例的1080×1920、46/58字号只是一套预设，不适合所有画布、字体或观看设备。标签与口播不重叠、文字不遮关键操作，比沿用某个固定像素值更重要。

当前构建器没有独立Hook样式或任意位置标题配置。需要额外标题时先确认实现范围，或将已制作的本地片头作为 `intro` 输入；不能把额外样式方案描述为当前脚本已支持。

ASS样式诊断要点：`Tag`采用 `BorderStyle=3` 背景块，`Sub`采用 `BorderStyle=1` 描边与阴影；`Alignment=2`表示底部居中，因此MarginV相对画布底边。`PlayResX/PlayResY`应匹配配置画布，避免字号和边距随隐式缩放改变。当前脚本的Tag/Sub是不同样式，事件均写Layer 0，不应把样式名误认为独立图层编号。

## 二、高亮与换行

ASS颜色使用BGR次序；当前高亮和恢复色分别是：

```python
GOLD = r"{\c&H4DC9FF&}"
WHITE = r"{\c&HFFFFFF&}"
```

字幕中的 `{重点}` 转成金色ASS覆写标签，其余文字恢复白色；颜色在脚本中固定。输入反斜杠被处理为普通可见字符，避免注入ASS控制码；使用JSON字符串中的换行字符表达换行，不传原始ASS命令。

不要依靠固定中文字数判断宽度。不同字体、英文长度、字号、边距和WrapStyle会影响排版；libass可能自动折行，但不能保证符合语义，也不会保证任意长文本都可读。用实际字体渲染最长句，检查左右边界、折行与上下遮挡。

中性拆句示例：

```json
"subs": [
  ["先打开示例文件。", 0, 1.2],
  ["再查看{处理结果}。", 1.2, null]
]
```

这些时间只是示例，须按本次背景旁白修改；`null`表示结束位置由背景段与下一拍旁白共同约束。长句按语义拆分，不能断在专有名词中间。

## 三、字幕时间

每拍字幕从规划的 `voice_start` 开始，结束位置为“旁白结束 + `subtitles.hold`”，再受下一句起点和成片终点约束。当前实现的下一句避让量为0.05秒。检查字幕与音频一致、无负时长、不会跨到不相关画面；停留值由任务确定。

## 四、外部卡片制作的Pillow经验

Pillow不是当前构建器依赖；以下只供预制片头、封面时参考。字体文件由当前环境确认，不能依赖个人Windows字体路径；同时检查授权与缺字。

### bbox偏移和裁切

`textbbox`可能返回非零或负偏移。示意逻辑如下，描边须额外预留空间：

```python
left, top, right, bottom = draw.textbbox((0, 0), text, font=font)
image = Image.new("RGBA", (right-left+2*pad, bottom-top+2*pad))
ImageDraw.Draw(image).text((pad-left, pad-top), text, font=font, fill=color)
```

检查alpha通道四边是否紧贴墨迹，并打开渲染图核对笔画。边缘透明不等于内容必然完整，不能只凭最后一行像素作充分判据。

### 透明度范围

明确函数参数是0—1还是0—255；若参数alpha为0—1，像素alpha可用 `int(value * alpha)`，不要再次除255。

### 显式合成

不同图像模式和绘图流程的半透明效果不同，不按未经验证的版本号推断行为。稳妥做法是在独立RGBA图层绘制，使用 `alpha_composite` 与底图合成，再转换RGB。用已知底色抽样验证混合结果，并检查成片而非只看孤立图层。
