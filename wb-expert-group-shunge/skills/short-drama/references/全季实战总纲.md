# 短剧制作实战总纲

将本文件作为可复用方法库，不作为任何剧集的设定或参数来源。开工输入契约见上级 `SKILL.md`。测量结果记录在项目配置，所有阈值按本片素材标定，不把某次实验数字写成通用事实。

## 一、事实源与节奏

- 为设定、角色、台词、素材、包装、规格指定实际来源、版本及裁决人；同一字段只有一个权威来源，其他文档引用它。
- 改设定后搜索旧值，核对数字关联、人物身份、时间规则与伏笔。时间机制须能计算闭环；冲突提交确认。
- 画面、音乐、对白与参考顺序同段描述；剧本秒位只用于表达意图，不代表成片时间轴。
- 先明确当集传达的信息和观众需要知道的因果，再选时长、片段数和对白密度。留白是表演选择，不用固定无对白上限。
- 角色对手戏按事实源选取；新增路人也应约束面貌、服装及与主角的区别，避免串脸。
- 新增生成、修改台词、重出及试风格先确认授权与预算。优先评估已有素材修复，但不能因已花费而降低验收标准。

## 二、参考与渠道

- 拼版节省调用但可能损失细节；按参考识别能力选择拼版或单图，裁切后核角色及场景标签。
- 精确文字用可编辑层绘制，事先验证字体 cmap、实际字形、行宽和安全区。字体路径由环境发现或用户配置，不固定系统字体。
- 参考图约束语义而不保证构图和物件一致。需要精确重复时使用已授权原素材、可追踪贴图或后期统一。
- 当前模型、尺寸、套餐、首尾帧、配额、上传入口与参数范围须从当前界面或官方资料核验；旧回执不代表新任务能力。
- 网络失败先保存错误、请求标识与服务端状态，排查协议、权限、代理和传输；不得默认绕过代理、网络策略或防护，也不得把历史 HTTP 错误当作固定原因。
- 浏览器生成遵循 `doubao-web-video` 状态机；换账号或窗口重新核登录态、附件缩略图、顺序、提示词和参数。接收回执不等于生成完成。

## 三、生成内容约束

- 提示词描述动作因果及起止状态，明确道具数量、持手和换手条件，检查片段之间的姿态、服装、光线及指向物。
- 模型可能把台词画入画面或补全屏幕品牌。避免不必要的可读屏幕；需要可读内容时预留后期层。禁字提示不代替抽帧验收。
- 对语气和节奏给正面动作/发音要求，但不承诺严格实现；实际音频决定字幕轴。
- 续拍可用已批准片段的参考帧保持连续性；普通参考图不等于严格首帧控制，多张参考不等于首尾帧控制。

## 四、可重建后期

按项目规模使用配置管理片段顺序、流规格、字幕、包装、剧情文字和修复窗口。保留源素材标识、无字基础片、音轨及透明层清单；修改字幕或包装只重建相关层，避免无关重复编码。

### 实测字幕

1. 用 ffprobe 读取时长、帧率、时间基准与音轨。试听语音、背景声和静音样本，标定检测窗口与噪声阈值。
2. 用 `silencedetect` 提供候选边界；必要时按人声频段和素材特征选择滤波，保留未滤波音频用于试听。滤波可能削弱音节，不能机械套固定带通。
3. 用窗口 RMS/音量变化辅助区分发声与背景，但仅凭 dB 差不能断定有没有人声。音乐、气口与连续语流须试听。
4. 按核对过的逐字稿确定文本。连读段可按字数初分，再逐句试听校正；ASR时间戳只作候选。转写上传及工具选择须获授权。
5. 生成吞字或改词时标记与批准文本的差异，询问接受实际台词、修复还是重出，不擅自增配音或删除批准内容。
6. 从同一时间轴生成画面字幕和外挂字幕，应用所有剪辑偏移，核条数和边界。

### 切点与坐标

- 用 scene 检测产生硬切候选，按相邻帧内容人工确认；阈值按镜头纹理和运动标定，不能只依赖检测分数。
- 叠加窗口在切点两侧保留合适安全帧；连续运动没有硬切时，逐帧定位目标出现、消失和遮挡。
- 坐标以当前分辨率与目标轮廓测量。用 PIL 颜色/边缘辅助定位，先量文字宽度再绘制；字幕安全区来自配置，不写固定像素行。
- 匀速运动可使用时变坐标表达式；透视变化需关键帧四角及插值，遮挡或运动突变处补关键帧。不要把高光误当目标边界。
- 包装与剧情文字分层，明确各层起止、依赖和可删除性；片尾声明、署名和水印按当前配置处理。

## 五、局部修复方法

### 重排、慢放和定格

保留干净段，评估同镜动作较小处慢放补时，避免硬循环导致动作回缩；定格应使用同镜适合收束的帧。音轨不变时仍需复核口型和动作语义；裁剪导致时间变动时同步更新所有层。定格可用帧差检测验证，容差要考虑压缩噪声，不能以某个固定灰阶值宣称完美静止。

### 背景与文字修复

- 静止背景优先考虑对齐后的干净邻帧回填，先核曝光、纹理与遮挡；人物转身或背景移动时避免无配准的时间复制。
- 无可用邻帧且区域窄、同材质时，可逐行左右插值。区域不可跨人物/墙体边界；复杂纹理或遮挡应改用跟踪、局部修复工具或保留待修，不强行抹平。
- 只抠除亮字核心会遗留描边；整块中位色可能丢纹理；同帧任意位移克隆可能复制衣领等异物。以文字及描边的完整区域设计掩膜。
- 背景亮度变化时静态补丁可能露边，按帧生成或跟踪修复层。羽化宽度随分辨率、纹理、运动与掩膜边界标定，不固定像素值。
- 暗笔画检测可用局部背景与原图差值，先在干净区、笔画区和阴影区采样，再确定模糊尺度、阈值及扩边。局部对比也可能误删纹理，需遮挡掩膜与人工检查。
- 去字前后使用一致的时间基准与帧标识；对可变帧率材料使用时间戳映射。不要混用 seek 抽帧与重采样序列帧号而产生假残留。
- 比较残留像素统计与干净背景基线，同时检查纹理、边缘、闪烁和遮挡；指标通过不能代替实时播放。

### 连续性与末帧

接缝道具重复出现/消失时先找双方一致的姿态区间，评估纯剪辑；不得为省生成费剪掉必要剧情。末帧抽取使用实际可解码帧时间，探测失败须报错，不把空图当成功。补静音、改变速度或帧率都要与输出配置一致。

## 六、验收与版本重建

- 按镜头长度和风险布置代表帧、字幕边界、切点两侧、修复区域与放大图；具体抽帧数量和放大比例是项目检查配置，不是合格证明。
- 逐段看人物、道具、口型、字幕、字体缺字和包装；多集连看核跨集连续性。原尺寸图与实时播放共同提供视觉证据。
- `blackdetect` 可发现候选黑场，不能保证识别带字黑底卡；`signalstats` 可辅助找暗段，也不能自动区分合法夜景与待删片尾。按层清单、时间窗和人工复核确认。
- 拼接前比较视频/音频编码参数、尺寸、帧率、time_base、音频采样率、声道和编码附加信息。确认兼容再流复制，否则按目标规格重编码并验证连接点。
- 用 ffprobe 核时长、尺寸、编码和要求的音轨；用 ffmpeg 完整解码检查错误。警告需解释，不能仅凭退出码称画质合格。
- 删减版从无字中间产物和层清单重建。用户要求只留字幕时逐层确认剧情文字、修复层、品牌、水印及声明范围，不默认全部删除或保留。
- 移除声明承载层时确认声明仍真实适用及新的承载位置，记录交付者责任。保留源素材与中间层便于复验，不把含私号素材放进提交内容。

## 可复现实验与参数标定示例

以下命令和数值仅用于说明如何做实验，不是默认验收阈值，也不是适用于所有素材的已验证结论。先在本片代表片段取样，保存原始测量结果、参数、时间基准及失败样本，再调整。

### 切点、语音和图层

- 硬切候选可从 ffmpeg `select='gt(scene,0.22)',metadata=print` 起步，`0.22`只是示例；运动、闪光与镜头纹理可能误触发，逐帧核切点后再设置叠加窗口。窗口两侧留1～3帧也是示例，按帧率及遮挡实测。
- 语音候选可试 `highpass=250,lowpass=3800` 后接 `silencedetect`；250/3800Hz只是示例频带，低沉人声、嘶音、音乐及压缩处理会改变结果。取约0.25秒窗口的 RMS/`volumedetect` 可辅助比较，但不固定人声与底噪的 dB 值，更不能只凭差值判定人声。
- 匀速竖向运动可写 `overlay=x:y0+v*(t-t0)`，由关键帧测得 `v`、`y0`和`t0`；运动不匀速时改分段表达式或逐帧跟踪。字幕带采用配置中的安全区，不使用固定像素行。
- 逐帧透明层按源时间轴输出，如 `f_%04d.png`；输入 `-framerate <经确认的输出帧率>`，不要把示例24fps写死。对可变帧率素材先建立时间戳映射，避免层与原片错一帧。

### 局部暗字掩膜算法

1. 在目标 ROI 估计背景 `B = GaussianBlur(I, radius)`；在干净背景、笔画、阴影三个样本区比较 `D = max(B-I, 0)`。
2. 从样本选择阈值 `T` 得到候选 `D>T`。例如模糊半径6像素和差值22灰阶仅可作为8位灰度素材的试验起点；更高分辨率、HDR或不同材质必须重新标定。
3. 对候选用 `MaxFilter`/膨胀覆盖笔画边缘，再乘目标 ROI 与遮挡排除掩膜；对结果羽化后仅替换命中像素。羽化6像素同样只是实验示例，不是所有视频的默认值。
4. 检查手影和材质纹理：宽缓阴影可能被背景估计保留，但锐利阴影和细纹也可能误命中；必须查原图/差值/掩膜/合成四层，不把相对灰度算法视为不会误删。

### 亮字、透视与验收

- 对亮字统计近白像素前，先从干净同材质区域取得亮度基线，再确定阈值与检测时间窗。邻帧回填先配准并核曝光；窄矩形逐行插值应取左右未污染边界，矩形跨材质时拆区，不把衣服与墙面混成背景。
- 卡片或纸面透视贴图可用 `select='between(n,起始帧,结束帧)'` 导出并标注关键帧四角，叠网格读取坐标后插值；近白自动检测易抓高光，应用轮廓和角点人工校正。
- 用同时间戳或同帧标识比较去字前后近白像素、局部均值与边界变化；修复后的统计接近背景基线只是必要证据，还要看纹理和播放闪烁。定格帧差同样需考虑压缩，不能用固定灰阶差声称完全一致。
- `blackdetect=d=0.8` 可作为黑场扫描示例；`0.8`秒按交付要求修改。无命中不证明黑底白字片尾卡已删除，仍需结合层清单、`signalstats` 的 YAVG、时间窗和目视检查。
- 完整解码可用 `ffmpeg -v error -xerror -i <成片> -f null -`，再用 ffprobe 核流参数；两者不能替代内容、口型及字幕验收。
