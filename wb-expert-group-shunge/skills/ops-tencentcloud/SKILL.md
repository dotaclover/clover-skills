# 腾讯云运维手册

> 仅在当前项目明确使用腾讯云时应用本手册，不将云厂商、地域、镜像或规格作为默认环境。范围、费用、服务窗口从当前project brief、合同政策及验收清单取得，缺项询问，不内置价格。
> 控制台路径速查见 [references/console.md](references/console.md)。

## 先记住三条账号纪律

1. **只动客户本人账号**，不代注册、不代持、不代付。需要操作的，让客户给子账号/协作者授权，并书面记录授权时间与范围。
2. **所有花钱的动作先列金额和影响**，回主理人交用户确认：升配、续费、加带宽、买流量包、开 CDN、买证书、开快照容量。
3. **不可逆动作先说后果再动手**：快照回滚（覆盖现有数据）、重装系统、解绑弹性公网 IP、删除 COS 桶。

## 服务器选型：轻量还是 CVM

| 场景 | 选哪个 | 理由 |
|---|---|---|
| 单个 WordPress 站、个人站、静态站 | **轻量应用服务器 Lighthouse** | 含带宽包、价格低、够用 |
| 一台机器跑多站、要挂云硬盘、要内网互通、要负载均衡 | **CVM** | 可扩展性与网络能力强 |
| Go / Python / Hyperf 自研服务小量部署 | 轻量 2C4G 起步，量大再上 CVM | 常驻进程吃内存，2C2G 容易 OOM |

**内存口径**：LNMP + WordPress 建议 2C2G 起；再跑 Hyperf/Go/Python 常驻进程建议 2C4G 起，内存不够的表现是 MySQL 被 OOM 杀掉，看起来像「数据库莫名挂了」。

镜像按当前应用兼容性、支持周期和用户维护能力选择；先读取实例实际系统，不统一指定Ubuntu或任何发行版。规格建议仅用于容量评估，最终以负载测试、预算和用户批准为准。

**轻量和 CVM 的关键差异**：轻量的端口放行在**轻量控制台的防火墙**，不在安全组；CVM 在**安全组**。这是「端口开了还是连不上」最常见的坑。

## 域名解析（DNSPod）

- 记录类型：服务器 IP 用 **A 记录**；CDN / COS / 平台提供的地址用 **CNAME**。
- 主机记录：`@` 是主域名，`www` 是带 www。**两个都要加**，只加一个客户会说「另一个打不开」。
- TTL：默认 600 秒即可；准备切换前可先调小（如 60），切完再调回。
- 生效验证：
  ```bash
  dig <域名> +short
  dig <域名> @119.29.29.29 +short    # DNSPod 公共 DNS
  nslookup <域名> 8.8.8.8            # 看境外是否生效
  ```
- **常见坑**：解析改了但本地 DNS 有缓存（等 TTL，或换网络验证）；域名没实名认证会被暂停解析（Serverhold）；域名刚注册还没过实名期。

## SSL 证书

- 腾讯云提供**免费 DV 证书**（TrustAsia/亚洲诚信），有效期 **90 天**，到期要续。
- 验证方式：DNS 验证（加一条 TXT 或 CNAME 记录）或文件验证。DNS 验证更稳，文件验证要求 80 端口可访问。
- 签发后**下载 Nginx 格式**（`.crt`/`.pem` + `.key`），别下成 Apache/IIS/Tomcat 格式。
- 部署到 Ubuntu：`/etc/nginx/ssl/<域名>.crt` 与 `<域名>.key`，vhost 里 `ssl_certificate` + `ssl_certificate_key`，`nginx -t` 后 reload。
- **证书链不完整**的表现：浏览器正常、部分安卓或微信内置浏览器报证书错误。用腾讯云给的完整链证书，不要只上传域名证书。
- 到期前 7 天检查一次；有 Let's Encrypt 自动续期的也要验证一次续期是否真的成功，不要默认它一直有效。

```bash
openssl x509 -in /etc/nginx/ssl/<域名>.crt -noout -dates -subject
```

## 安全组与防火墙（端口放行）

| 端口 | 用途 | 建议 |
|---|---|---|
| 22 | SSH | **限制来源 IP**，不要 0.0.0.0/0 |
| 80 / 443 | 网站 | 全放行 |
| 8888 | 宝塔面板 | **限制来源 IP**，并改默认端口 |
| 3306 | MySQL | **不对外开放**，只本地或内网 |
| 9501 / 8080 / 8000 | Hyperf / Go / Python | **不对外开放**，让 Nginx 反代即可 |

轻量机器去**轻量控制台 → 防火墙**加规则，别只在安全组里找。

## 快照与回滚

- 快照按容量计费，是花钱项，创建前先跟主理人确认。
- **回滚快照会覆盖当前磁盘上的所有数据**，回滚前必须把当前数据（站点文件 + 数据库导出）备份出来，否则客户最近的订单、文章会一起没。
- 建议在「有大改动之前」打快照：系统升级、PHP 版本切换、迁移站点、批量改权限。
- 自动快照策略可以开，但要确认客户愿意承担这部分费用。

## COS（对象存储）

- 用途：WordPress 图片/附件外置、静态资源、备份归档。
- 权限默认**私有读写**；做图床/外链才开公有读，且要提醒客户公有读意味着任何人可访问。
- WordPress 附件转 COS 用插件，配置 SecretId/SecretKey 时用**子账号密钥并只给 COS 权限**，不用主账号密钥。
- 密钥不进仓库、不进聊天记录、不截图外传。

## CDN

- **中国大陆 CDN 节点要求域名已备案**，没备案的域名只能用境外或不开。
- 接入流程：添加域名 → 配置回源（源站 IP 或域名、回源协议）→ 配 HTTPS 证书 → 改解析为 CNAME。
- **常见坑**：配置完页面还是旧的，要**刷新预热**（URL 刷新或目录刷新）；源站开了强制 HTTPS 而回源协议选了 HTTP，会 301 循环。
- 缓存规则：静态资源长缓存，HTML 短缓存或不缓存；后台路径（如 `/wp-admin`）不缓存。
- CDN 流量是花钱项，先给客户估算量级再开。

## 备案衔接（与备案专员配合）

- **中国大陆服务器上的域名必须备案**才能正常访问；境外（中国香港、新加坡等）不需要，但国内访问慢、用不了国内 CDN、投不了百度广告。
- 备案需要「**备案服务码**」，从 CVM 或轻量控制台申请，每台机器有数量限制。
- 域名需完成**实名认证且实名信息与备案主体一致**；域名后缀需在工信部批复列表内。
- 专员只给材料清单与流程说明，**具体通过与时限以管局为准，不承诺下号时间、不承诺包过**。备案主体、材料提交、核验由客户本人完成。
- 备案号展示规范与公安备案的事归 `opc-web-developer`，运维只负责服务器侧：确认机器在境内、服务码可用、解析指向正确。

## 费用与续费

- 续费、升配、带宽调整、流量包、快照容量、CDN 流量、COS 存储与流量，都是**客户本人账号支付**。
- 到期不续费会停机，数据一般有保留期（以腾讯云官方说明为准），**不要把「没及时续费」当成备份策略**。
- 遇到「要充值/要升配」的场景，输出金额与影响后回主理人，不替客户决定。

## 边界

- 不出具任何「合规证明」「安全证明」；不承诺可用性指标或 SLA。
- 不代客户与腾讯云工单对话；需要时可整理事实与截图供客户自己提交。
- 控制台操作前先确认是**生产环境还是测试环境**，避免改错地域或改错机器。
