# 腾讯云控制台速查（按需精读）

> 控制台界面会改版，以下路径以「控制台 → 产品」为准；找不到时直接用控制台顶部搜索框搜产品名。

## 入口

| 用途 | 位置 |
|---|---|
| 控制台首页 | console.cloud.tencent.com |
| 轻量应用服务器 | 控制台 → 轻量应用服务器 Lighthouse |
| 云服务器 | 控制台 → 云服务器 CVM |
| 域名解析 | 控制台 → 云解析 DNS（DNSPod） |
| SSL 证书 | 控制台 → SSL 证书 |
| 对象存储 | 控制台 → 对象存储 COS |
| 内容分发网络 | 控制台 → 内容分发网络 CDN |
| 备案 | 控制台 → 网站备案 |
| 安全组 | 控制台 → 私有网络 VPC → 安全组 |
| 快照 | CVM → 云硬盘 → 快照；轻量 → 实例详情 → 快照 |
| 费用 | 控制台 → 费用中心 |

## 高频操作路径

**轻量**：实例详情 → 防火墙（加端口规则）；实例详情 → 快照（创建 / 回滚）；实例详情 → 重置密码 / 重装系统。

**CVM**：实例列表 → 安全组（配置规则）；云硬盘 → 创建快照；实例 → 更多 → 重装系统。

**DNS**：域名解析 → 解析管理 → 添加记录（A / CNAME / TXT）；域名注册 → 域名实名认证状态。

**SSL**：证书管理 → 申请免费证书 → 填域名 → 选 DNS 验证 → 按提示加解析记录 → 等待签发 → 下载（选 Nginx）→ 部署。

**备案服务码**：轻量 → 备案 → 申请服务码；CVM → 备案 → 申请服务码。每台机器可申请数量有限。

## 判断「服务器在哪」的三步

1. 控制台搜实例 ID 或公网 IP，确认是轻量还是 CVM、在哪个地域。
2. 轻量看「防火墙」，CVM 看「安全组」——端口放行在这两处，别找错。
3. 结合控制台实例ID、网卡与地址映射、SSH主机指纹核对目标；`hostname -I`通常显示接口地址，不能单独证明公网IP；不默认请求第三方公网IP查询服务。

## 常见报错对应

| 现象 | 先看 |
|---|---|
| 域名解析到 IP 但打不开 | 安全组/防火墙是否放行 80、443；Nginx 是否在跑；站点是否绑定了该域名 |
| 证书申请卡在验证 | TXT/CNAME 记录是否加上、是否生效（`dig TXT <域名>`）；80 端口是否被占用或拦截 |
| 页面还是旧内容 | CDN 缓存未刷新；浏览器缓存；opcache |
| 远程连不上 SSH | 22 端口是否放行、来源 IP 是否受限、密钥/密码是否正确、机器是否欠费停机 |
| 站点忽然打不开 | 先看是否欠费停机、是否被流量打满、MySQL 是否被 OOM |
