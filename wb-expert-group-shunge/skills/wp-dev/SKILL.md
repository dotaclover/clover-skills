# WordPress主题与插件工程

先读当前project brief、现有代码、核心/主题/插件清单及验收要求。工具、测试与模板从当前工作区确认，不假定固定SKU仓库或`opc-*`实现已安装；费用、页数、插件预算、支持期限和不含项由合同配置提供，缺项询问。

## 范围与架构

- 区分内容/样式调整、现有表单字段扩展、新内容类型、主题结构变更和完整业务流程；分别评估数据迁移、权限、测试与维护成本，不将其自动判为价内或价外。
- 商城、支付、会员、多语言、外部系统与REST业务接口需专项设计、授权及验收，不因某个固定套餐直接拒绝或默认包含。
- 采用当前项目适合的经典主题或区块主题。优先复用已有代码；第三方插件按许可、维护状态、安全、兼容和性能评估，不限定只能用自研四个插件或最多五个。
- `references/theme-skeleton.md`与`references/plugin-skeleton.md`保留可选`opc-*`示例；示例名称、路径和参数先映射到现场项目，不复制示例身份信息。

## 一、主题

1. 业务逻辑、CPT、短代码和表单放插件，主题负责呈现，换主题不应丢内容。
2. 按模板层级复用`page.php`、详情页及归档模板，不为同结构每页重复建模板。保留`wp_head()`、`wp_body_open()`、`wp_footer()`与跳到正文链接。
3. 通过`wp_enqueue_style/script`管理资源与依赖，版本来自实际构建/组件版本；内联脚本用`wp_add_inline_script`，不要随意移除业务插件资源。
4. 配色用CSS变量、单一配置来源与安全白名单；检查文本/背景对比度和焦点态。`theme.json`与CSS职责根据主题类型分配，避免重复覆盖。
5. 字体、图标和第三方请求按目标网络、隐私、许可及性能约束决定；本地化不等于自动接入外部镜像。

## 二、插件

- 主文件定义元信息、常量与模块入口，按功能拆分；使用项目唯一前缀，不占用`wp_`等通用命名。
- 根据生命周期选钩子：CPT/短代码用`init`，依赖其他插件用`plugins_loaded`，设置注册用`admin_init`，资源用`wp_enqueue_scripts`，响应头用`send_headers`，主查询调整用`pre_get_posts`。
- 设置使用`register_setting`与类型校验、sanitize回调；输出按上下文`esc_html`/`esc_attr`/`esc_url`，SQL使用预处理。nonce不替代权限校验，写操作同时检查capability与对象归属。
- CPT按业务设置公开性、REST能力、权限和分类；私有预约/询盘不能照抄公开产品配置。表单校验nonce、字段、限流/反垃圾、隐私同意及安全回跳。
- 优先CPT/postmeta满足简单数据需求；确需自定义表时设计迁移、备份与卸载策略并单独批准。
- 更新迁移须幂等、有版本记录、失败可恢复；卸载默认保留业务数据，清理须明确列出本插件对象并获授权，不自动删除客户文章或表。

## 三、性能与本地化

按实际瓶颈逐项验证，不做无依据的一键优化。页面缓存区分匿名公开页、会话、表单、后台和AJAX；实际缓存时长由项目策略决定，含个人数据不得共享缓存。心跳、emoji、feed、oEmbed等调整先核对业务影响。语言、时区、文件名、slug和必要站点声明从用户需求取得，不固化中文后台或某个镜像。

## 四、安全加固

参考`references/hardening-checklist.md`按当前实现逐项核对副作用，不将示例默认值视为所有站点要求。

- XML-RPC、作者页和REST权限按使用需求控制，不能无差别删端点导致区块编辑器损坏。
- 禁用后台代码编辑与最小权限分开处理；隐藏菜单不能代替授权。
- 登录限速考虑可信代理、共享出口和管理员恢复路径；仅在批准测试副本验证阈值，生产登录测试须额外授权。
- 安全头/CSP先验证资源与嵌入兼容；不要宣称几项响应头即可全面安全。
- 保留安全更新能力；自动更新策略按兼容验证、维护窗口和恢复能力制定，不一律关闭。
- 避免在`map_meta_cap`调用`current_user_can()`造成递归；不能通过去掉更新权限锁死版本。

## 五、验证与交付

先对修改PHP文件做语法检查，再运行实际项目单元/钩子行为测试，最后隔离副本端到端验证：后台登录、权限、编辑保存、表单记录/邮件、模板、资源、缓存、安全头及恢复。测试脚本需先确认路径、读取行为与参数；语法通过不代表行为正确。

前台验收可在获批正式域名只读复核；写入/删除按`wp-admin`记录基线与任务对象ID，清理不碰原有数据。输出修改范围、测试证据、未验证项、兼容风险、备份恢复和用户操作说明，不在客户站做未授权“顺手优化”。
