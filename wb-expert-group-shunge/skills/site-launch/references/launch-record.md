# 上线记录模板与常见坑

> 本文件是`site-launch`的附件，随交付填写，放用户指定的私有项目目录，客户资料与凭据不进 Git。

## 二、常见坑（上线前先看一遍）

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 页面白屏、资源全 404 | 资源用了绝对路径`/assets/...`，放在子目录就失效 | 改上传位置到根，或改站点的 base/资源路径（**改源码需另确认修复范围**，先确认） |
| 首页 403 | 目录没有`index.html`，或目录索引被关 | 确认入口文件名；Nginx 的`index`指令是否含`index.html` |
| 上传后文件还在旧版 | 浏览器/CDN 缓存 | 清缓存再验；微信内尤其严重，用带参数 URL 复验 |
| HTTPS 报「不安全」 | 页面里混了 http 图片或脚本（混合内容） | 找出混用资源，提醒客户（替换素材属改代码，需核对本次授权范围） |
| 证书签发失败 | 解析未生效、80 端口不通、`.well-known`被拦截 | 先查解析与 80 端口；面板建站的`well-known`目录要存在 |
| 表单提交没收到信 | 主机未开启 mail 函数或 SMTP 未配 | 属档位内的要配好；需要第三方邮件服务时说明费用客户直付 |
| 刷新内页 404 | 单页应用需要伪静态/重定向到 index | 按复杂档配重定向；属配置不属于改代码 |
| 微信里打开排版乱 | 微信内置浏览器兼容性 | 记录现象，告知客户；要修另确认修复/开发范围 |
| 上传到站点根目录却覆盖旧站 | 未先备份 | **先备份再覆盖**，备份没验证写「未验证」 |

## 三、上线前后速查命令

```bash
# 解析是否生效（本地）
nslookup <域名>
# 证书到期日
echo | openssl s_client -connect <域名>:443 -servername <域名> 2>/dev/null | openssl x509 -noout -dates
# HTTP 状态码与跳转
curl -I http://<域名>
curl -I https://<域名>
# 页面里有没有混用 http 资源
curl -s https://<域名> | grep -o 'http://[^\"]*' | head
```
