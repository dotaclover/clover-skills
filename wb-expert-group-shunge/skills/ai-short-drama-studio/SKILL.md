# AI短剧制作工作台

这是把一部 10 集竖屏短剧从零做到可发布的完整实战提炼成的可复用规程。**本技能只讲方法与验收口径，不含任何一部剧的设定、人名、数字或镜头**——那些一律从用户本次输入和项目事实源取。

按需要读 `references/`，不要凭记忆省略：

| 文件 | 什么时候读 |

| `references/实测铁律.md` | 动手生成/后期前，本次验证过的硬知识与踩坑 |

| `references/验收清单.md` | 交付前逐项核对 |
| `scripts/README.md` | 要跑工具脚本时，先看用法总览 |

## 九步流程速览

1. **立项设定**：写死设定总表（机制闭环/人物/时间线/数字/命名查重），它是全剧唯一事实源，先给用户确认。
2. **拆剧本分镜**：每集一个提示词，画面/音乐/对白写同一段；台词逐字定稿，改动先确认。
3. **定妆场景**：批量出角色/场景/道具图，中文后期 PIL 叠；出图二次确认。
4. **原片生成**：豆包网页版按分镜生成 A/B/C 段，跟踪状态防重复扣费。
5. **字幕轴实测**：本地 `ffmpeg silencedetect` 找静音边界，不用云端 ASR。
6. **后期合成**：只加字幕不额外加工；删台词要字幕+人声一起删。
7. **剧情剪辑与过渡**：换日黑场卡、时间大跳蒙太奇、片头海报、片尾署名。
8. **抽帧验收**：切点/字幕/修复区逐帧核，完整解码验流。
9. **交付归档**：封面/文案/成片按五类归档，对外名统一。

## 三条最高优先级铁律

1. **确认关卡**：剧本、台词、出图、出片、重出、试风格，动手前一律先给用户确认；"开始制作"不等于跳过看稿。
2. **事实源唯一**：设定、人物、时间线、数字只有一个权威来源；改一处要全局搜旧值核对关联；对外名统一，内部旧名不露出。
3. **实测为准**：字幕轴以本地静音边界为准，切点以 scene 检测+逐帧核为准，坐标以 PIL 量色块为准；不靠分镜秒位和肉眼估，不冒称逐字精准。

## 边界

- 只做短剧创作与交付，不报价、不代运营、不擅自发布或提交 Git；收费 API 与额度需用户授权，费用如实登记。
- 生成工具当前能力实时核验，历史回执不代表今天可用；"预计等待"是受理、"系统异常"不等于失败，绝不自动重发。
- `scripts/` 内置一套**参数化的通用工具**（字幕轴实测、中文叠字、日期卡、音轨静音、抽帧验收、多宫格切图），不含任何一部剧的设定或硬编码秒位，直接用即可；剧目专属的叠字层清单、分镜配置仍在项目里就地生成，职责与实现要点见 `后期与脚本.md`。
- 脚本依赖ffmpeg/ffprobe与Pillow，字体路径在 `scripts/common.py` 顶部按系统配置。
