# 后期、字幕、过渡与脚本职责

每部剧在工作时于项目 `tools/` 目录就地生成所需的通用脚本。这里写清**每个脚本的职责与关键实现要点**，不是可照抄的成品代码。具体设定、人名、秒位、坐标由本剧事实源和实测填入。

## 需要生成哪些脚本（职责分工）

| 脚本 | 职责 |
|---|---|
| 出图配置脚本 | 集中维护角色/场景/道具的提示词清单（ASSETS/CHARACTERS）；接口 OpenAI 兼容，Key 不进代码；Cloudflare 拦 Python urllib 时走 `build → curl(浏览器UA, --noproxy '*') → 解析` |
| 角色卡/场景卡脚本 | 一图流拼版生成，保证角色一致；切格后按格导出 |
| 字幕轴脚本 | 本地抽音轨 + `silencedetect` 找静音边界，连读按字数比例拆，台词铺进发声段 |
| 字幕层/后期脚本（每集一个） | 把台词逐句烧成透明 PNG 层，标注起止；分层合成；只改字幕时只重建相关层 |
| 全季拼接脚本 | 按 PLAN 顺序拼黑场卡、正片段、蒙太奇、片头、片尾；统一编码参数 |
| 局部修复脚本 | 逐帧抹画内白字、背景回填、画面重排慢放定格 |
| 封面/海报脚本 | 从无字底片抽帧做封面、PIL 叠中文大字、拼版联系表 |

## 字幕轴（本地实测，不靠云端）

1. `ffprobe` 读时长、帧率、时间基准、音轨。试听语音/背景/静音样本，标定检测窗口与噪声阈值。
2. `ffmpeg -af "silencedetect=noise=-XXdB:d=0.12"` 找候选静音缝；阈值按素材标定（示例 -32dB，不是通用值）。
3. 按静音缝切成发声段；模型连读的两句按字数比例初分，再逐句试听校正。
4. 按核对过的逐字稿写字幕文本（用剧本原话）；边界吸附静音缝。
5. 从同一时间轴生成画面字幕和外挂字幕，应用所有剪辑偏移，核条数与边界。
6. ASR 时间戳只作候选；转写上传需授权。不冒称逐字精准。

## 分层后期与删台词

- 保留源素材标识、无字基础片、音轨、透明层清单；改字幕/包装只重建相关层，避免无关重复编码。
- **删台词**：字幕层不生成该句 PNG；同时音轨静音该句人声——
  ```
  ffmpeg -i seg.mp4 -af "volume=0:enable='between(t,15.10,17.90)+between(t,26.90,30.00)'" \
    -map 0:v -map 0:a <统一视频编码参数> <统一音频编码参数> out.mp4
  ```
  区间用 `silencedetect` 实测语音边界，前后各让 0.3—0.6s 压进静音缝；视频流重编码（因用了滤镜），画面保留。
- 中文叠字用 PIL + 微软雅黑（`C:/Windows/Fonts/msyh.ttc` / `msyhbd.ttc`），先量 `getbbox(stroke_width=...)` 再居中；数字字母两侧不加空格。

## 切点与坐标实测

- 硬切候选：`ffmpeg select='gt(scene,0.22)',metadata=print`；阈值只是起点，按镜头纹理标定，逐帧核；叠加窗口两侧留1—3帧。
- 屏幕坐标用 PIL 逐像素扫色块量，不按分镜秒位或肉眼估。先量文字宽度再绘制，安全区来自配置不写死像素。
- 去字前后用一致时间基准和帧标识；可变帧率先建时间戳映射，别混 seek 抽帧与重采样序列帧号（会差一帧）。

## 片头/黑场/蒙太奇/片尾（拼接金件）

- **编码参数全片统一**，否则 concat copy 失败：
  - 视频：`-c:v libx264 -crf 18 -preset medium -profile:v high -level 3.1 -pix_fmt yuv420p -r 24`
  - 音频：`-c:a aac -b:a 128k -ar 44100 -ac 2`
- 黑场卡：黑底+居中白字天数+灰白日期，静音，编码同上；时长约1.2s。
- 片头：海报静帧约2s+淡出到黑，静音，编码同上。
- 蒙太奇：固定机位反复"按下"，一天一镜；原声丢掉只用统一"滴"声，保证节奏一致；逐镜缓慢推近+压暗。
- 片尾：黑卡＋虚构声明＋署名＋AI生成声明；静帧＋静音 concat。
- 拼接用 concat 清单（每行 `file '绝对路径'`），`-f concat -safe 0 -c copy`。预期时长与实际差应在毫秒级，差太多说明某段编码参数不一致。
- 换日点若落在集内：先把该集按实测切点切成 a/b/c 段再参与拼接。

## 不能重出时的画面修复

- 三段法：干净前段＋同镜头动作最小处慢放补时＋末帧原地定格。硬循环会看到动作缩回去；别接别的镜头会穿帮。
- 三段帧数压回原时长，台词与字幕轴一个字不动；切口卡在台词缝上。
- 音轨整轨不动；改速度/补静音要与输出配置一致。
