# 豆包网页版出图出片操作要点

用浏览器操作豆包网页版时的核心流程与排障。控件文案/入口会随账号和版本变化，只当发现线索，**当前能力实时核验**。

## 通用前置

- 确认：批准的提示词与参考素材、上传权限、目标比例/时长/声音、预算与次数、交付目录与覆盖策略。
- 官网 `https://www.doubao.com/`，官方创作入口 `https://www.doubao.com/chat/create-image`（「AI创作」页，图像/视频在同一页切 tab）。
- 枚举可见浏览器与标签，定位用户授权的豆包标签并认领，核登录态；工具看不到的窗口请用户绑定，不反复新建错误窗口，不读凭证。
- 当前账号可用模型、套餐、比例、时长、配额、首尾帧能力必须实时核验，不拿历史结论替代。严格首尾帧只有界面明确提供并验证有效才承诺。

## 出图

- **数量靠提示词控制**：出图张数没有独立控件。实测同账号同模型同比例、描述逐字相同的单变量对照：不写数量返回4张2×2网格；开头写「只生成一张图片。」返回1张大图。别写"不要多张/不要拼版"这类未验证的否定词。
- 参数浮层**向上弹出盖住输入框，选中后不自动关**：按一次 `Escape` 收浮层最稳，再截图确认比例摘要没变、浮层消失，再点输入框中部输入。点空白未必收起，点输入框可能命中浮层第二行把比例悄悄改掉。
- 发送前核五项：提示词文字、模型摘要、比例摘要、附件、然后才发送。输入工具返回成功≠文字已落框。
- 结果认领：2×2网格时下载工具栏在目标卡片底部，单张大图在图片左下角；先核 tooltip 再点「下载原图」，别误点「重新生成」。按浏览器下载记录+下载前基线认领，不按 mtime/文件名猜（同标题会追加 `(1)`）。
- 只想要1张却出4张：确认授权后在**新对话**里把「只生成一张图片。」放开头重出，别在旧结果上反复点重新生成。
- 额度：「免费额度已用完」且无结果图是明确失败态；留证请用户决定订阅/换号/改渠道，不重发、不点订阅。创作页提交前不显示剩余次数。

## 出片

- 用语义节点点 `role=tab` 的「视频」，确认输入框和模式已切换；底栏快捷 chip 不一定随 tab 切。
- 参数面板读完实际选项与费用提示，选批准规格；面板关闭后核摘要。每条提交前重设比例/时长（会退回默认）。
- 参考图用当前可用官方上传控件或环境支持的剪贴板，每次上传后截图核缩略图、内容、数量、顺序。
- 动作描述写起因→反应→结果+镜头收束；精确文字留给后期层；道具数量、持手、动作终态写死。
- 续拍选站位/服装/道具/光线清楚的已批准参考帧，写后续动作；先核网页是否提供专用首帧功能，普通参考图不等于严格锁帧。

## 请求状态机（防重复扣费）

| 状态 | 证据 | 允许动作 |
|---|---|---|
| 等待确认 | 本次请求明确要求确认、无受理回执 | 核参数与授权后仅确认一次，记录状态 |
| 已受理 | 本次任务编号/受理回执/排队信息 | 记录并观察，不补确认、不重发 |
| 生成中 | 进度明确对应本次任务 | 按工具节奏刷新，不提交新任务 |
| 完成 | 本次成功状态+可用结果 | 预览、下载、验证；不看旧消息 |
| 失败 | 本次明确失败/取消 | 存证据与费用，解释；重试另请授权 |
| 不明确 | 异常文案/超时/矛盾回执/无最新状态 | 滚到底核最新消息，必要时请用户看；绝不自动重发 |

- "预计等待"是受理证据不是完成；"系统异常"不足以判失败。生成完可能是追加新消息而页面不自动滚底，判"没出图"前先滚底或点向下箭头。
- 确认已发送但无回执，记"不明确"，不能再次确认。升级/付费/换号/重出都需明确授权。

## 常见排障

| 现象 | 核查 |
|---|---|
| 输入工具成功但输入框空 | 参数浮层没收回/点到了输入框边缘没聚焦；`Escape` 收浮层→点输入框中部→输入→截图核字 |
| 比例摘要与所选不符 | 浮层盖住输入框且选中不自动关；`Escape` 关闭、重读 DOM、截图核三项摘要 |
| 发完看不到进度 | 滚到对话底部或点向下箭头，核追加消息与本次回执，不盲补确认 |
| 上传无缩略图 | 核上传控件、会话状态、系统文件选择结果；截图验证后再继续 |
| 保存按钮误关画布 | 右上工具栏「保存」tooltip 旁边 `X` 是关闭；重开结果后查下载记录，避免重复下载 |
| 看见旧视频/旧回执 | 滚底并关联本次请求与参数，不用旧消息宣布完成 |

## 下载收尾

- 浏览器显示下载完成、文件大小/mtime 在观察间隔内稳定、无写入迹象才算下完。`.crdownload` 只代表可能未完成，不能改名当成功。
- 本地脚本（在工具实际目录，不假设工作区路径）：`finalize_video.py` / `finalize_image.py`，用完整下载源路径+新目标路径，`--download-complete` 仅是调用者已核验的声明。脚本默认拒绝覆盖已存在目标。仅稳定或仅 ffprobe 能解析不足以证明下载完整。
