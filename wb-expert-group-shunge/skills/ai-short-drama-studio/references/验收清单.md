# 验收清单（交付前逐项核对）

## 内容

- [ ] 设定总表机制能计算闭环；改设定后旧值全局清零（含 pyc 缓存）
- [ ] 时间线每集对应第几天/日期正确；相邻不同日子已拆段
- [ ] 台词与用户确认的定稿逐字一致；角色名、中文冒号、数字无误
- [ ] 每集开头有钩子，当场有观众能懂的戳点
- [ ] 对手戏角色身份符合设定；路人串脸风险已处理
- [ ] 对外名统一，内部旧名全仓零命中

## 画面（抽帧）

- [ ] 按镜头长度和风险布置代表帧、字幕边界、切点两侧、修复区、放大图
- [ ] 人物、道具数量与持手、口型、服装连续性、光线一致
- [ ] 屏幕未被补满界面/品牌（或已接受并按约定处理）；画内白字已抹净
- [ ] 多集连看跨集连续性；末帧不是空图/意外黑屏
- [ ] 原尺寸图与实时播放共同取证；抽帧时间基准一致（不混 -ss 与序列帧号）

## 字幕与音轨

- [ ] 字幕边界吸附本地实测静音缝；连读段已按字数拆开
- [ ] 字幕文本=批准逐字稿；字体无缺字；行宽不溢出；安全区没压字幕
- [ ] 删台词的句子：字幕层无字 + 音轨人声已静音（中段约 -91dB）；相邻台词音量正常
- [ ] 中文排版：数字字母两侧不加空格，`·` 两侧不留空格，`@` 开头文案已核码位

## 过渡与包装

- [ ] 换日黑场卡天数/日期正确；同一天连续处未误加黑场
- [ ] 蒙太奇天数递增可数、单镜时长与加速符合约定
- [ ] 片头海报时长与淡出正常；片尾署名与声明齐全
- [ ] 包装层起止正确，水印压在安全区不压字幕

## 技术验流

- [ ] 拼接前各段编码参数一致（尺寸/帧率/time_base/采样率/声道/编码）
- [ ] `ffprobe` 核时长、尺寸、编码、音轨符合要求
- [ ] `ffmpeg -v error -xerror -i 成片 -f null -` 完整解码无错
- [ ] concat 预期时长 vs 实际差在毫秒级
- [ ] 警告已解释，不单凭退出码判定画质合格

## 交付

- [ ] 成片复制到发布目录（产出目录与发布目录都要更新）
- [ ] 封面版式统一、文案三项齐全（标题/内容/话题）、末行 AI 合成标识
- [ ] 交付物按五类归档（剧本/定妆/过程/发布/技能）
- [ ] 给出：事实源、成片、抽帧证据、费用凭证位置、待确认与遗留项
- [ ] 收费 API 与额度使用如实登记；未观察到的费用不编造
- [ ] 未擅自发布、未提交 Git、未接代运营
