# 表达风险与替换表

以用户确认的品牌brief、事实证据与授权为前提。词表用于语义自审，不是法律定性或平台通行证。数字、身份、排期均不可照抄示例。

## 一、绝对化与效果承诺

| 风险表达 | 改写方向 |
| --- | --- |
| 保证收录／排名／有客户 | 说明执行动作、交付物与结果的不确定性 |
| 全网最低／最好／唯一 | 写有证据的特点、适用条件与限制 |
| 保证通过／当天获批 | 写实际提交安排；审核结果与周期不保证 |
| 必火／引流神器 | 写解决什么具体问题，不预言传播结果 |
| 无限修改／终身维护 | 写已确认的范围、轮次与维护期限 |

确有证据的比较也要交代比较范围、时间与口径，不能用“个人体验”包装无依据功效。

## 二、演示与脱敏：不可偷换

| 素材情况 | 正确表述 |
| --- | --- |
| 合成或虚构的示例资料 | 功能与版式演示；名称及数据为合成示例，不代表真实客户或业绩 |
| 不是真实客户案例 | 明确标注演示案例，不隐藏到客户追问才承认 |
| 真实资料匿名处理 | 仅在确有来源、授权与匿名处理记录时写“已脱敏” |
| 来源未知 | 来源待核实，不称真实案例，也不称脱敏案例 |

禁止把虚构、编造或合成改称脱敏；禁止伪造客户来源、评价或案例授权。演示站可以展示真实可运行的功能，但运行状态不证明客户来源。

## 三、冒认与虚假证言

- 客户数量、交付数、成功率、好评、营收及增长需要证据和可公开授权。
- 客户评价不得自编或把演示对白当证言。
- 点名客户或展示项目必须确认授权和本人贡献。
- 不凭空写“资深团队”“行业领先”，也不把真实团队强行写成一人服务。

## 四、品牌、身份与履历

- 品牌名、公司／团队／工作室、第一人称和职务以用户提供的品牌brief与真实主体为准。
- 前雇主和公司名是否披露，由保密义务、事实依据与用户授权决定，不采用固定个人禁令。
- 简历按真实日期、职责、任职类型和可公开成果写；外包、兼职与任职不能互换。
- 不擅自填入任何个人品牌、雇主、项目名称或职业年限；缺失用【待确认】。

## 五、价格与交易

| 情况 | 处理 |
| --- | --- |
| 原价与折扣 | 核对有效报价、真实原价依据、期限及条件，禁止虚构优惠 |
| 页面价格表与下单入口 | 按业务资质、站点用途、现行规则和用户需求决定，不默认禁止或跳转某平台 |
| 联系方式与站外链接 | 按用户指定渠道核实允许范围，不擅自添加私域入口 |
| 排期与加急 | 有真实履约能力与授权才写，不从示例复制日期 |

平台规则未核实就标“待核实”，不要把历史渠道经验写成当前禁令。

## 六、空话与语气

高端大气、极致体验、一站式、赋能等词能删就删，替换为具体动作、交付物、条件与限制。是否使用行业术语由受众决定，不作无差别禁用。

去掉自怜或夸张措辞时不得篡改事实：

| 原句情况 | 处理 |
| --- | --- |
| 好不容易完成项目 | 核实后写实际完成情况，不能自动改成“按期交付” |
| 勉强跑通旧系统 | 如实写已跑通部分和剩余限制，不能改成“已升级上线” |
| 最近换职业 | 与场景相关才按真实时间写，不凭空补履历 |
| 做得不好请见谅 | 改为具体待改进项和确认步骤，不掩盖质量问题 |

## 七、排版建议（可按品牌调整）

中文使用中文标点，并列项优先顿号，避免破折号堆叠。中英文空格、字号与符号遵循本次品牌风格规范，不把个人习惯当硬约束。

## 八、交付检查

- [ ] 每个事实有来源，所有待确认项可见。
- [ ] 品牌、主体、渠道和报价来自本次授权资料。
- [ ] 演示资料显著标注，没有伪称脱敏或真实客户。
- [ ] 无虚假业绩、未经授权的客户证言及不可控效果保证。
- [ ] 仅在实际核验后标“已核实”；未联网不宣称掌握当前平台规则。
