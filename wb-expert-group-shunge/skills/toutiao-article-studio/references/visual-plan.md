# 封面与配图

优先使用与主题有关、来源和权利清楚的实拍或授权图；实拍不自动排除肖像、商标或隐私问题，不声称平台排序或点击优势。
所以本模块**弱化 AI 生图提示词**，重点给「拍什么、放哪、为什么」。

---

## 封面

### 头条封面的三条硬规则

1. **优先尝试简洁无字封面**，避免文字遮挡证据；压字是否适合按内容和当前规则判断，不将压字直接等同低质。
2. **高清无水印**，不使用模糊截图、网络拼接图、偷拍或低俗图片。
3. **贴合主题**，图文不符会直接影响推荐。

### 封面方案输出格式

| 项 | 内容 |
|---|---|
| 主视觉 | 一张什么画面（一句话） |
| 拍摄 / 取材方式 | 实拍 / 正版图库 / 截图（注明来源） |
| 构图 | 主体位置、留白方向、横图还是方图 |
| 避坑 | 这张图容易踩什么雷（水印 / 人脸 / 品牌 Logo） |

> 封面尺寸：支持 1:1 与 16:9，系统会自动裁剪与校验，两种都给一版描述。

## 正文配图（3–6 张）

| 项 | 规则 |
|---|---|
| 数量 | 可先规划3–6张，按证据和说明需要调整，不保证阅读提升 |
| 位置 | 每 4–6 段插一张，或按小标题分段处插 |
| 图文关系 | 图配文、文衬图，不无关堆砌 |
| 版权 | 正版无版权图片，或自己实拍 |
| 水印 | 检查来源、授权及当前展示规则，不预测限流 |

### 配图输出格式（精简档：张数 + 一句内容建议）

```
图 1（放在第②段后）：{拍什么 / 取什么图} —— 作用：{为什么在这里}
图 2（放在第③段后）：…
```

**第二遍展开**（用户说「展开 / 细化」才给）：
- 构图要点
- 拍摄角度与光线
- 需要出现的道具
- 图注文案（图注能提升停留时长）

## 与小红书配图的关键差异

| | 小红书 | 今日头条 |
|---|---|---|
| 封面文字 | 必须压字（三层文案） | **可先尝试无字** |
| 配图来源 | AI 生图为主 | **实拍 / 正版图库为主** |
| 配图数量 | 0–3 张 | **3–6 张** |
| 首图 | 首图即封面 | 首图即封面，另可设三图封面 |

---

## 禁止

- 用文字遮挡证据或与正文不符的文字叠加。
- 使用带其他平台水印的图。
- 无关美女图、惊悚表情包诱导点击。
- 未确认权利与授权范围的Logo、肖像、作品，以及无必要且未经同意的车牌门牌信息。
- 凑数配图——每张必须对应正文某一段。
