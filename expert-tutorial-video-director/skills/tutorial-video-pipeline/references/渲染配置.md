# 渲染配置

`build_film.py` 自动生成 `build/config.json`，交给 `scripts/video_pipeline.py render`。
正常情况不需要手写；要改行为时改 `beats.json` 或直接改生成后的 config。

## 全局字段

| 字段 | 本流水线取值 | 说明 |
|---|---|---|
| `width` / `height` | 1920 / 1080 | 必须偶数；显式给定时所有分段统一到这个画布 |
| `fps` | 30 | 统一 CFR，不做 VFR 保留 |
| `crf` | 20 | 0–51，越小越清晰越大 |
| `resize_mode` | `contain` | 等比缩小 + 补黑边，**不放大** |
| `audio_mode` | `replace` | 用配音替换原音；每段必须给 `voice_file` |
| `subtitle_mode` | `none` / `burn` | `burn` 同时导出 SRT；`sidecar` 只出 SRT |
| `font` / `font_size` | Microsoft YaHei / 48 | 字体必须本机可用 |
| `segments` | 见下 | 数组顺序 = 成片顺序，可重排/重复 |

## 片段字段

| 字段 | 说明 |
|---|---|
| `source` | 路径**相对 config.json 所在目录**（`build/`） |
| `start` / `end` | 源时间秒数，`0 ≤ start < end ≤ 源时长` |
| `speed` | 默认 1，`≥0.05`；输出时长 = `(end-start)/speed` |
| `voice_file` | 该段配音 wav，从头播放，超长裁切、不足补静音 |
| `subtitles` | 显式 `[{start,end,text}]`，时间相对加工后片段 |
| `masks` | 矩形遮挡，`pixels`（默认，源分辨率坐标）或 `normalized` |

`duration` 与 `speed` 互斥；`voice_file` 与 `narration` 互斥。

## 由 build_film.py 生成的形态

```json
{
  "width": 1920, "height": 1080, "fps": 30, "crf": 20,
  "resize_mode": "contain", "audio_mode": "replace",
  "subtitle_mode": "burn", "font": "Microsoft YaHei", "font_size": 48,
  "segments": [
    {"source": "clips/c01.mp4", "start": 0.0, "end": 6.27,
     "voice_file": "audio/c01.wav",
     "subtitles": [{"start": 0.0, "end": 2.31, "text": "大模型和智能体，到底差在哪。"}]},
    {"source": "../../rec/demo01.mp4", "start": 3.4, "end": 23.5, "speed": 4.0,
     "voice_file": "audio/w2.wav",
     "subtitles": [{"start": 0.0, "end": 3.12, "text": "点发送。它没有直接写字，先去读文件。"}]}
  ]
}
```

注意两件事：

1. 卡片片段 `end` 是**实测时长 - 0.002**，不是设定值。`ffmpeg -t N` 会少 1–3 帧，写死会报越界。
2. 录屏段 `source` 用 `../../rec/...`，因为路径相对 `build/`。

## 输出

```
out/EP01_render/
  final.mp4       成片
  subtitles.srt   字幕（burn/sidecar 时）
  timeline.json   每段实际起止
  report.json     规格、编码、音频处理摘要
```

## 手工调用

```bash
python scripts/video_pipeline.py --ffmpeg C:/ffmpeg/bin/ffmpeg.exe \
       --ffprobe C:/ffmpeg/bin/ffprobe.exe \
       render --config episodes/EP01/build/config.json \
       --output episodes/EP01/out/EP01_render
```

全局二进制参数必须放在子命令**之前**。路径用正斜杠，含空格加引号。

## 边界

- 不做 ASR、不做自动场景切分、不做自动 ducking、不支持外部 SRT 导入。
- `size` 模式（限体积双遍）本流水线没用；需要时显式设 `encoding_mode: size` + `target_mb`。
- 旋转标记的源会被拒绝，先另存规范化方向副本。
- 多源统一到第一段源画布；要改画布就显式给 `width/height`。
