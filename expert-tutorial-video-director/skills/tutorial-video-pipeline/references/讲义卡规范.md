# 讲义卡规范

卡片就是视频的"幻灯片"，也是独立交付的 PPT。一份 SVG 源同时喂两个出口。

## 画布与安全区

| 项 | 值 |
|---|---|
| 画布 | `1920 × 1080`，`viewBox="0 0 1920 1080"` |
| 安全边 | 左右 135，上下 120（贴边元素除外） |
| 字号 | 主标题 108 / 卡标题 72 / 小标题 64 / 正文 40–48 / 注释 30–34 |
| 行距 | 主标题行间隔 144；正文行间隔 64 |
| 字距 | 大标题 `letter-spacing 4–8`，标签类 `10` |
| 最少字号 | 34（1080p 投屏可读下限，再小就别放） |

## 色板（四叶草 · 墨绿粉笔）

```svg
<!-- 底 -->      #121A14
<!-- 主文字 -->  #EDEAE0
<!-- 次要文字 --> #97A38F
<!-- 强调绿 -->  #6F8F5A
<!-- 金/强调色 -->#D8A73C
<!-- 分隔线 -->  #2E3B2E
```

浅色变体（需要白底投屏时）：底 `#F5F2E9`，主文字 `#1A2418`，强调 `#4A6B3C`，线 `#D8D3C4`。

字体栈统一写：`font-family="Source Han Sans SC, Microsoft YaHei, PingFang SC, sans-serif"`。
本机没装思源会自动落到雅黑，不会变方块。

## 五种常用版式

### 1. 片头卡
- 左上四叶草 + 系列名（`28px`，字距 6）
- 主标题两行，`108px`，`y=452 / 596`
- 分隔线 `y=672`，长 720
- 副标题一行 `40px` 灰 + 一行 `34px` 强调绿
- 右下角集号与日期，`30px`，金色，`text-anchor="end"`

### 2. 单概念卡（讲一件事）
- 卡标题 `72px` 在 `y=178`
- 正文区从 `y=300` 起，最多 **3 条**，每条：`48px` 主文字 + 下方 `30px` 灰注释
- 右侧留白可放示意图；图优先于字

### 3. 流程卡（智能体四件事这类）
- 四个节点横向或 2×2 排布
- 节点：圆/圆角矩形 `stroke=#6F8F5A`，内文 `40px`
- 连线用细线 `stroke=#2E3B2E`，加箭头，别用粗箭头

### 4. 对照卡（A vs B）
- 中缝竖线 `x=960`，`stroke=#2E3B2E`
- 两侧列标题 `48px`，下面 3–4 行 `34px`
- 对照的是**行为差异**，不是形容词堆砌（"省时间"→"工具在流程里被调用"）

### 5. 作业黑板（固定底版，每集只改三处）
- 标题「课后作业」+ 右上集名
- 三条横线 `y=238 / 567 / 896` + 一条竖线 `x=960`，拉满整屏（不要留居中白边）
- 四格：主词 `64px` + 注释 `34px`
- 底部「作业」标签 `30px` 字距 10（金色）+ 题目 `48px`

## 制作纪律

1. **一屏一个论点。** 出现第二个论点就拆卡。
2. **字要能被念出来。** 卡上的字和台词说的是同一件事，观众不用二选一。
3. **不加装饰性图标。** 没有信息量的图形只是噪音。
4. **卡片文件名带序号**：`C01_片头.svg`、`C03b_三个拎清.svg`（插页用 b）。
5. **改文案只改 SVG**，然后重跑 `svg2png.py`；不要拿 PNG 去 PS 里改。

## 渲染与导出

```bash
# SVG -> PNG（1920×1080，1x）
python scripts/svg2png.py --svg-dir episodes/EP01/cards --out-dir episodes/EP01/cards_png

# 需要 2 倍图（印刷/大屏）
python scripts/svg2png.py --svg-dir cards --out-dir cards_png --scale 2

# PNG -> PPT（16:9 满屏，台词进备注）
python scripts/svg2pptx.py --png-dir episodes/EP01/cards_png --out out/EP01_讲义.pptx \
       --beats episodes/EP01/beats.json
```

PPT 里每页是整页图片，**字不能在 PPT 里改**——这是刻意的：视频和 PPT 用同一份源，永远不会两个版本不一致。要改字改 SVG 重导。

## 校验

渲染完至少看一张：文字有没有出安全区、有没有被换行挤掉、中文有没有缺字。
批量检查尺寸：

```bash
# 全部应为 1920x1080
for f in cards_png/*.png; do ffprobe -v error -select_streams v -show_entries stream=width,height -of csv=p=0 "$f"; done
```
