# 系列教程的策划与分镜

从「一个主题」到「一集可以开工的 `beats.json`」。这一段不碰素材、不碰 ffmpeg，只产出文字。

**判断这一集能不能开做，只有一个标准**：看完之后，观众手上多了什么。答不出就回去重想。

## 立项

```bash
python scripts/init_project.py --root <项目目录> --title "系列名" --preset 16:9 --episodes 6
```

`--preset` 是画布，跟着**分发平台**走，不是跟着审美走：

| 平台 | preset |
|---|---|
| B 站 / YouTube / 课程后台 | `16:9` |
| 抖音 / 视频号 / 小红书视频 | `9:16` |
| 小红书图文 / 方图封面 | `4:5`、`1:1` |

同一个系列不要混画布。要竖屏版就整集竖屏重做分镜——竖屏一屏能放的信息量不到横屏一半，台词和卡片都得重写，不是缩放。

生成后填 `series.json`：受众基础、一句话承诺、固定开头结尾、分集表。每集必须有 `goal`（一句话目标）。

## 分集

- **集数由「几个成果」决定**，不由时长决定。每集交付一个能看见的东西。
- 5–10 集为宜。少于 5 集讲不透，多于 10 集活不到最后。
- 每集 3–6 分钟。超过 8 分钟要拆。
- 集与集之间留钩子：这一集结尾明说下一集做什么，不要"敬请期待"。
- **第一集必须给结果**，不能是"先讲讲什么是 XX"。观众不会等到第二集才看到价值。

分集表格式：

| 集号 | 标题 | 一句话目标 | 手上的成果 | 状态 |
|---|---|---|---|---|
| EP01 | 大模型和智能体差在哪 | 分清模型产品和智能体 | 一次对照实验 | done |
| EP02 | 把第一份成果做出来 | 从原始记录到可交付文档 | 一份 Word | planned |

## 分镜

每集写成 `beats`：卡片段和实拍段交替。字段定义见 `tutorial-video-assemble` 的 `references/beats契约.md`——**那份是唯一权威**，这里只讲怎么写。

### 每集骨架

```
片头卡 → 钩子（15 秒内给结果）
→ 正文：card 讲一个点 → demo 演一个证据 → card 收口
→ 对照卡（把两边放一起看）
→ 收尾卡（回扣开头）
→ 作业黑板
→ 结束卡（下一集钩子 + 固定结束语）
```

### 写法

1. **card 与 demo 必须交替**。连讲三张卡，观众会走；连放三段实拍，观众不知道在看什么。
2. **单段台词 40–90 字**（8–18 秒）。超过 100 字必拆。
3. **对着画面写**，不对着概念写：

   | 别这么写 | 这么写 |
   |---|---|
   | 它具备文档生成能力 | 它生成了一份 Word，三页，右边直接开了预览 |
   | 效率提升明显 | 这几步你平时自己干，一步都省不掉 |
   | 模型具有局限性 | 记录里没写的负责人，它标了"未明确"，没编名字 |

4. **开场 15 秒给结果**。第一句话就是"这件事做完了长什么样"。
5. **每个 demo 段写清三件事**：看哪一段（`start/end`）、压多少倍速、这段要证明什么。
6. **压速要主动交代**。台词里说"这段我压了三倍速，真实跑了两分钟"，比让观众自己发现你偷快进可信得多。
7. **估算时长**：中文口播约 **5.5 字/秒**（`+8%` 语速）。80 字 ≈ 14.5 秒，加 0.9 秒尾部停顿 ≈ 15.4 秒。
8. **一集总时长 = 所有槽位之和**，配音时长由 TTS 实测决定，这里的估算是为了排结构，不是为了对表。

### 台词稿格式

分镜表给用户过的时候用这张表：

| 段 | 类型 | 画面 | 台词 | 预估 |
|---|---|---|---|---|
| c01 | 卡 | 片头卡 | 大模型和智能体，到底差在哪 | 6s |
| d1 | 实拍 | DeepSeek 输入框，1.0x | 先给 DeepSeek | 3s |
| w3 | 实拍 | WorkBuddy 执行过程，2.6x | 它先读文件，再挑工具…… | 25s |

**分镜和台词先给用户过一遍再动手做素材。** 这一步返工最便宜。

## 别做的事

- **不要替用户编人设**。固定开头结尾按用户给的口径，不加"十年经验""AI 专家"这类标签。
- **不要写没拍到的功能**。"它能自动发邮件"——没录就不写；要么改成"下一集给你看"。
- **不要编数据**。台词里出现的字节数、页数、耗时，必须是真跑出来的。
- **不要写书面语**。"基于以上分析可以得出结论"念出来是灾难，改成"所以你看"。
