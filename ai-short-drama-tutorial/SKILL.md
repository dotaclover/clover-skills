# 用 WorkBuddy 纯 AI 创作短剧（教程 + 脚本）

这是把《失业华子的打工奇遇》10集竖屏短剧的完整制作经验提炼成的可复用教程。**负责人：汪总（短剧负责人），与顺哥共同维护。**

## 先读教程正文

完整七步流程、每步的事实源、铁律与踩坑记录见本技能目录：

- `references/纯AI短剧创作教程.md` —— 七步全流程 + 交接清单

## 七步速览

1. **立项设定**：先写死设定总表（机制、人物、时间线、数字、命名查重），它是全剧唯一事实源。
2. **定妆场景**：用出图脚本批量生成角色/场景图；提示词逐字保存，中文后期 PIL 叠。
3. **分集剧本**：每集一个提示词文件，画面/音乐/对白写在同一段；台词改动先给用户确认。
4. **原片生成**：豆包网页版，注意屏幕必被补满、道具数量禁死、参考图只能进已有对话。
5. **字幕轴实测**：本地 `ffmpeg silencedetect` 找静音边界，不用云端 ASR。
6. **后期合成**：只加字幕不额外加工；不能重出时只重排画面、音轨整轨不动。
7. **发布归档**：封面/文案/交付物按五类归档；对外名统一，内部旧名不露出。

## 使用方式

- 用户要"教程/教学"：按 `references/纯AI短剧创作教程.md` 逐章讲，结合实际项目路径举例。
- 用户要"照着做一个新短剧"：按七步走，每步先确认事实源，再动手；生成类操作一律二次确认。
- 用户要"脚本"：脚本在项目的 `tools/` 目录（`gen_assets.py` 出图、`subtitle_axis.py` 字幕轴、`ep*_post.py` 分层后期、`full_season.py` 全季拼接），本技能只讲怎么用，不重复代码。

## 边界

- 剧本/台词内容由内容负责人决定，收费 API 由渠道负责人执行，财务由留名统管。
- 新经验先写入项目制作记录，能纠正行为的再同步到 `short-drama/references/全季实战总纲.md`。
- 规程版本与最终交稿口径由顺哥收口。
