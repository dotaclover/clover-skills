## 类型

Agent 型（单个AI专家，不依赖其他专家包）

## 功能

把《失业华子的打工奇遇》项目的全流程经验固化成可复用规程，覆盖十一道工序：

1. 故事设定与唯一事实源（角色、公司、数字、时间线查重锁定）
2. 拆剧本与分集分镜（前3秒钩子、每2—3秒一个信息点、30秒内必须有观众当场能懂的戳点）
3. 定妆与场景卡（一图流九宫格、中文PIL叠字、出图前二次确认）
4. 豆包网页版出片（多镜塞一次请求、屏幕不入画、道具数量与手位反向禁死）
5. 本地静音检测定字幕轴（ffmpeg silencedetect，不用云端转写）
6. 后期叠字（排版铁律、数字与字母两侧不加空格、固定包装层与署名）
7. 剧情剪辑与台词静音（音轨单独静音、压在实测静音缝、字幕层同步删）
8. 片头海报与换日过渡（黑场白字卡、GAP蒙太奇、片头海报淡入淡出）
9. 封面制作（先看底图、竖版3:4与横版4:3、悬念文案）
10. 成片验收（抽帧、音量、字幕、码率逐项过硬门槛）
11. 归档与备份（分类目录、旧名清理、微云上传核验）

核心资产在 `skills/ai-short-drama-studio/`：一份SKILL骨架 + 五份references（全流程SOP、实测铁律、豆包操作要点、后期与脚本、验收清单）+ `scripts/` 七个参数化工具（字幕轴、叠字、日期卡、音轨静音、验收、多宫格切图等）。

随包附带五个配套技能，开箱即可干活：`computer-use`（浏览器/桌面操作）、`doubao-web-image`（豆包出图）、`doubao-web-video`（豆包出片）、`video-post-production`（通用后期）、`douyin-pip-shorts`（抖音竖屏画中画包装）。

## 使用示例

- 我这里有个故事，帮我拆成一部短剧并做到能发布。
- 帮我做角色定妆和场景图，并把全剧设定写成唯一事实源。
- 帮我完成后期：字幕实测、加片头、插入换日过渡并拼成成片。
