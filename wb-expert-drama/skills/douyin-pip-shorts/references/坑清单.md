# 常见问题与排查

将以下条目视为诊断线索，先核对本地工具版本、素材和命令日志，不把历史现象当作唯一原因。

## 媒体链

| 现象 | 可能原因与处理 |
|---|---|
| libx264提示尺寸不能被2整除 | yuv420p通常要求偶数尺寸；使用配置中的偶数画布和浮窗宽，浮窗高按比例取偶数 |
| 滤镜或选项不存在 | 本机ffmpeg版本或编译功能不同；查看本地帮助，不臆断所有旧版只支持某一种模式 |
| 尾部少帧、定格或时长不符 | 检查源时长、取段终点、帧率取整和时间戳；重新规划到新输出目录，不自动靠循环或定格掩盖 |
| 换素材仍看到旧画面 | 检查播放器缓存和路径；每次使用新输出目录，不复用中间文件，也不擅自删除旧文件 |
| reverse消耗大量内存 | 倒放需要缓存帧，开销随分辨率与时长增长；确有需要时先缩短取段或降低分辨率，保留源文件；当前构建器不自动倒放 |
| concat后音画或时长异常 | 检查编码参数、时间基、帧率、SAR、像素格式和片段边界；必要时在新文件中转码并复验，不直接认定丢帧 |
| 节点抽帧没出现浮窗 | 检查抽取时间是否在实际窗口内及时间戳；同时看窗口中段和边界相邻帧，不能仅凭第0帧判断 |
| 表格残行或文字被裁 | 在录屏原分辨率量crop坐标，抽帧检查四边；保留的空白量按当前画面决定 |
| 静图一直输出 | 循环静图须有显式dur；帧率按layout配置，而非固定30 |
| 旁白位置错或重叠 | 复核voice_duration、统一时间轴、adelay和章节过渡，听验限幅前后的结果 |
| probe返回为空或不是数字 | 检查退出码和stderr，再检查文件路径、解码支持及文件完整性；浮点转换通常是ValueError，不应一概归为TypeError |
| 路径在Windows/Bash下异常 | CLI路径加引号，Bash使用正斜杠；素材相对配置文件解析，ASS滤镜使用固定相对文件名，避免把盘符与转义混入表达式 |
| 超过时长上限 | 核对容器时长与帧时长；按任务留编码余量，勿把固定0.1秒或某个档位当作通用平台要求 |

## 文字与画面

- Pillow文字被平切：检查textbbox偏移和边缘留白，参见 `字幕与叠字.md`；不要只检查某一个字。
- 透明度异常：明确接口使用0—1还是0—255；绘制半透明元素后采用显式alpha合成，再转RGB。
- 配音发音不符：不同引擎、音色、版本对缩写处理不同；用当前音频听验或转写辅助，不把大小写替换当作通用修复。
- 步骤太快：按录屏信息密度重新分配窗口，脚本最低窗口限制不代表观众一定能读清。
- 素材不够：补充素材、改时间轴或经确认使用重复片段；缺口取决于当前片头尾和章节配置，不固定等于某个秒数。

## 安全与交付

当前入口必须显式传入 `--config` 和 `--output-dir`。输出目录已有即拒绝，所有字幕、concat列表、音轨与中间片都隔离在新目录；ffmpeg使用 `-n`。失败后保留现场，另选目录重试，不移动旧版到trash，不修改源素材。

`--help`和`--dry-run`不运行媒体程序、不写文件；dry-run仅说明配置可规划，不证明媒体链已验证。运行环境仍应只处理受信任的本地媒体。
