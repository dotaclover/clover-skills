# 按任务验收

先确认本次交付约定，再按时长、结构、画面、声音和文案检查。记录哪些项目已验证、哪些不适用、哪些仍待真实素材验证；dry-run或mock通过不等于成片验收。

## 一、时长与规格

对实际输出 `video.mp4` 使用ffprobe检查容器时长、画面尺寸、帧率、像素格式及音频流：

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 "$OUTPUT_DIR/video.mp4"
ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate,pix_fmt -of json "$OUTPUT_DIR/video.mp4"
ffprobe -v error -select_streams a:0 -show_entries stream=codec_name,sample_rate,channels -of json "$OUTPUT_DIR/video.mp4"
```

这些命令只读媒体，但会启动子进程，不属于dry-run。画布和帧率应匹配 `layout`，不是固定1080×1920/30fps。当前脚本输出yuv420p和AAC旁白混音，实际采样率与声道仍应检查。

以用户约定的时长上限为准，结合帧率和编码结果预留余量。脚本最终时长误差保护不能替代平台或用户更严格的限制；不要求所有短片填满10/15/30/60秒档位。

## 二、抽帧与动态检查

按本次规划而非固定秒位抽样：

| 节点 | 检查内容 |
|---|---|
| 片头/片尾（如有） | 图文完整、内容与当前任务相符、旁白未截断 |
| 开头停顿（如有） | 是否符合已约定的纯画面设计 |
| 背景交代 | 字幕完整、旁白与画面匹配 |
| 每拍窗口 | 标签对应真实操作，裁剪不残字，浮窗和字幕不互相遮挡 |
| 章节过渡（如有） | 按当前设计正确切换，无非预期黑场或浮窗残留 |
| 收尾 | 所需镜头与时长正确，不要求首帧等于源片末帧 |
| 素材边界 | 检查边界前后相邻帧和动态播放的连续性 |

抽帧写入独立新验收目录，使用 `ffmpeg -n`；命令中起点必须来自当前规划。示例变量 `CHECK_TIME` 为已计算的窗口中点，`CHECK_DIR` 为已确认的新验收目录：

```bash
ffmpeg -n -v error -ss "$CHECK_TIME" -i "$OUTPUT_DIR/video.mp4" -frames:v 1 "$CHECK_DIR/window-middle.png"
```

打开抽帧并播放关键片段，不能只看文件是否生成。

## 三、声音

先听验，再辅以silencedetect。以下仅为起始检测示例，不是合格阈值：

```bash
ffmpeg -v info -i "$OUTPUT_DIR/video.mp4" -af "silencedetect=noise=-35dB:d=1.5" -f null -
```

从stderr读取 `silence_start/silence_end/silence_duration`。检测阈值和最短静音时长须用当前旁白噪声底、音量和设计停顿标定；例如某次检测用的分贝值并不适合所有素材。

将检测到的静音区间与配置对照。片头、章节、演示等待或收尾都可能有设计静音，不把中间超过固定秒数直接判成漏音。检查非预期漏句、重叠、截断、峰值过载及响度不一致。当前脚本不保留底板原声、不提供背景音乐轨；任务有要求时明确报告缺项。

## 四、底板与跳点

根据 `base[].start/duration` 推导映射，比较拼接边界与源素材；先视觉检查，像素差只作辅助。遮罩浮窗与字幕，统一色彩和尺寸，再用当前素材标定误差阈值，不使用固定10/35/50作为普遍判据。

时长偏差需结合帧率和封装评估，不把固定0.15秒直接当作规格不一致的证明。收尾是否落在特定源镜头由用户要求决定。

## 五、文字与布局

- 按配置与目标终端检查浮窗宽度、透明度和安全区，不强制铺满960像素。
- 核对真实字体、缺字、裁切、折行、笔画和字幕时间。
- 检查关键主体、操作控件与文字是否被遮挡；标签编号连续或分章重置按任务约定。
- 检查非预期黑边、花屏、色偏与旋转，不以单一技术原因解释全部异常。

## 六、发布前内容核对

合成成功不表示已获得发布授权。核对标题所述步骤数、工具名称、功能、价格或免费条件与实际素材一致；无法核实时不要写成事实。标签与画面相符，时长表述明确“上限”“约”或实测值的口径。

检查素材使用权、必要的生成内容标识以及当前目标平台要求。对可能误导、骚扰或不适宜的内容先调整，不将历史处罚个案推断为固定的下架、禁言或收益处置结果。平台规则如需确认，应另行核验可靠来源；本次离线检查不作现行规则认证。

## 七、交付与保留

- 每次构建使用新的独立输出目录，交付 `video.mp4` 与需要的字幕、规划说明；固定文件名可以由不同运行目录区分版本。
- 不覆盖、删除或擅自移动旧版到trash；归档路径及清理策略须用户确认。
- 分镜文档、工作日志、标题、标签和发布包仅在本次任务要求时更新或生成。
- 报告实际执行的验证、结果与限制。未真实渲染时明确写“仅离线mock验证”，不宣称画面、音频和媒体兼容性已通过。
