# 版式与时间轴

## 一、以配置和旁白确定预算

档位只是选型参考，不是平台强制规格。先确认用户的时长上限、步骤量、画布与可读性要求。

构建器的时间预算为：

```
中段预算 = timing.target − 片头dur − 片尾dur
浮窗起点 = timing.pause + 背景voice_duration − timing.ops_lead
每拍窗口 ≈ (中段预算 − 浮窗起点 − timing.tail − 章节间隔总长) / 拍数
```

当前实现向下取整到百分之一秒，每拍须至少1.4秒；这是脚本保护条件，不是所有教程的最佳阅读时长。可读性仍须用本次录屏验证。旁白在窗口前按 `timing.voice_lead` 提前，并避让上一条旁白；装不下时缩短旁白或减少拍数。

- `timing.pause/tail`、章节数、章节间隔由任务确定，不是固定常数。
- `voice_duration` 必须填写本地音频实测值；dry-run只用声明值，真实执行再次校验。
- 严格时长上限可预留若干帧余量，再实测容器时长；不要声称整数目标必然超限。
- `plan_timeline.py` 可做粗排，但不要将其常量输出粘入新构建器；正式入口为 `--config --output-dir`。

## 二、选择布局预设

示例配置提供1080×1920、30fps、960宽浮窗、40底边距、0.7透明度，仅作为起始预设。根据画布、录屏文字大小、终端界面遮挡和主体位置调整 `layout`。当前构建器采用居中贴底浮窗，不支持任意逐拍位置；需要其他布局时另行确认实现范围。

浮窗高按原裁剪框宽高比计算并取偶数，适配当前yuv420p编码。画布与浮窗宽同样要求偶数。居中位置为 `(画布宽−浮窗宽)/2`；底边距不等于平台安全区保证，须在目标设备检查。

字幕字体、字号、满屏边距和浮窗边距使用 `subtitles` 配置。不要因为改了时长就机械缩小字号，也不要因为使用同一档位就禁止调整版式。

## 三、先拼底板，再切窗口

`base` 为有序的 `src/start/duration` 列表，详见 `背景填充.md`。构建器逐段统一画布、帧率、SAR并编码，随后拼为连续底板。满屏与浮窗窗口均在中段时间轴上切取；字幕与旁白使用加上片头偏移的成片时间轴。

底板须足够铺满中段。源取段的声明与实测时长不同、VFR或编码取整可能导致误差；检查源段、拼接边界和最终时长，不将某个固定误差直接归因为规格不一致。

## 四、浮窗合成

保留以下滤镜骨架供诊断与扩展参考，变量取自当前配置和规划，不是直接执行的完整命令：

```python
fc = (
    f"[0:v]setpts=PTS-STARTPTS,setsar=1,fps={fps}[bg];"
    f"[1:v]crop={cw}:{ch}:{cx}:{cy},scale={pip_width}:{pip_height},"
    f"setsar=1,setpts=(PTS-STARTPTS)/{speed},fps={fps},"
    f"format=yuva420p,colorchannelmixer=aa={alpha},"
    f"drawbox=x=0:y=0:w=iw:h=ih:color=black@0.30:t=2[pip];"
    f"[bg][pip]overlay={(width-pip_width)//2}:main_h-overlay_h-{bottom}:"
    "format=auto,setsar=1[v]"
)
```

`setsar=1`分别用于两路视频；仅统一像素宽高不一定统一显示宽高比。`setpts`归零后再变速；`fps`统一输出采样。保留alpha像素格式后再调透明度，避免在不含alpha的格式上误判效果。浮窗尺寸计算示例：

```python
height = round(pip_width * crop_height / crop_width)
height = max(2, height - height % 2)
```

处理顺序为：裁剪录屏 → 按配置缩放 → 统一SAR → 重设时间戳并变速 → 设置透明度和描边 → 居中贴底叠加。

当前变速系数为 `录屏取段时长 / 该拍窗口时长`，不是固定的最慢速度。过度减速可能卡顿，加速可能看不清操作；在配置中换取段或调整拍数，不能只以“覆盖时长”判定合格。

编码使用libx264、yuv420p；中间片段统一编码参数后concat copy，最终烧字再编码。编码质量与性能参数目前是脚本固定值，不是可配置字段。

## 五、旁白与卡片

每条旁白按成片绝对起点使用 `adelay`，再与静音底轨一起 `amix`；限幅器降低峰值过载风险，但不能代替响度测量或听验。当前脚本只混配置旁白，不保留底板原声，也不提供背景音乐配置；如任务要求这些音轨，应单独确认扩展。

片头片尾可以省略；启用时用 `card` 静图或 `anim` 视频，并声明 `dur`，可附带 `voice/voice_duration`。循环静图必须有显式时长。输出以新目录隔离，失败保留现场；不要复用旧中间片段。

混音诊断骨架（轨道编号与延迟以实际命令为准）：

```text
[2:a]aformat=sample_fmts=fltp:channel_layouts=stereo,aresample=48000,adelay=2500|2500[a2]
[1:a][a2]...amix=inputs=N:normalize=0:dropout_transition=0,alimiter=limit=0.95,atrim=0:总长[audio]
```

静音底轨由 `anullsrc=r=48000:cl=stereo` 提供完整时间范围；`adelay`单位为毫秒。`normalize=0`避免自动按输入数降低音量，但多条声音重叠仍可能过载；限幅器并不能证明响度符合交付标准。旁白排序变化时优先修改规划，而不是拼接很多静音文件。

## 六、调整顺序

超出任务时长时，结合信息优先级讨论删步骤、缩短旁白、减少停顿、收尾或卡片。每次调整重新dry-run，真实渲染后再检查实测时长、字幕阅读和关键操作。不要将固定的删减顺序或停留区间当作用户未确认的硬性要求。
