# 封面与分镜展开

**封面在默认交付里；分镜表只在用户说「展开分镜」时才给。**

---

## 封面（默认交付）

### 快手封面的三条规则

1. **真实优先**——真人出镜、实拍画面优于设计感强的图。
2. **文字够大**——信息流与关注页里封面缩得很小。
3. **看得懂在干什么**——不要抽象构图，观众在关注页刷到熟人，靠封面判断"这条讲啥"。

### 封面输出格式（简版）

| 项 | 内容 |
|---|---|
| 主视觉 | 一个什么画面（一句话） |
| 封面文案 | 大字 5–12 字，口语，从标题提炼 |
| 关键镜头提示 | 这个画面怎么拍（一句话） |
| 方向 | 真人出镜 / 实拍场景 / 结果展示，选一并说明理由 |

**第二遍展开**（用户说「展开 / 细化」才给）：构图、机位、光线、生图提示词与负面词。

## 分镜表（第二遍，按需展开）

### 分镜密度

| 时长 | 镜头数 | 单镜上限 |
|---|---|---|
| 20s | 约 6 镜 | 4s |
| 30s | 约 8 镜 | 5s |
| 45s | 约 11 镜 | 5s |
| 60s | 约 14 镜 | 5s |
| 90s | 约 18 镜 | 6s |

> **快手节奏比抖音慢**。A / B 型可以放宽到单镜 5–6 秒，保留过程的真实感；D 型要更碎。

### 分镜表格式

| 镜号 | 时间 | 景别 | 运镜 | 画面 | 口播对应 | 字幕 | 音效 |
|---|---|---|---|---|---|---|---|
| 1 | 0–3s | 中景 | 固定 | {画面} | {对应口播} | {关键信息} | {环境音} |
| 2 | … | … | … | … | … | … | … |

### 字段说明

| 字段 | 取值范围 |
|---|---|
| 景别 | 特写 / 近景 / 中景 / 全景 / 远景 |
| 运镜 | 固定 / 推 / 拉 / 摇 / 移 / 手持跟随 |
| 画面 | 一句话描述，具体到"画面里有什么、人在做什么" |
| 口播对应 | 这一镜念哪一句 |
| 字幕 | 只上步骤编号、价格、地名、结果 |
| 音效 | 环境音优先，BGM 可后置 |

> **快手 A / B 型建议保留环境音**，不用全程铺 BGM——真实感的重要来源。

### 拍摄备注（分镜展开时一起给）

| 项 | 内容 |
|---|---|
| 演员 | 几人、是否需要出镜 |
| 道具 | 清单（**快手观众会问道具在哪买的，提前想好**） |
| 场景 | 拍摄地点（真实值留【】） |
| 后期 | **轻剪辑**、字幕样式、是否需要卡点 |

---

## 与抖音分镜的关键差异

| | 抖音 | 快手 |
|---|---|---|
| 单镜时长 | ≤ 4s | 4–6s，可留过程 |
| 节奏目标 | 拉完播、防划走 | 拉关注与复看 |
| 剪辑风格 | 卡点、特效、强节奏 | **轻剪辑、保留真实感** |
| 声音 | BGM 主导 | **环境音可用**，不必全程铺乐 |
| 封面取向 | 冲突感最强的一帧 | 看得懂在干什么 |

---

## 禁止

- A / B 型过度剪辑——真实感优先。
- 封面文字过小或压在边缘。
- 凑数分镜——每个镜头必须对应口播的某一句。
- 品牌 Logo、明星脸、他人作品、可识别车牌与门牌入镜。
- 未确认方向就一次性铺满分镜表。
