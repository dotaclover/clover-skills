# 预设场景卡（第 0 步）

## 核心原则：给文本，不问问题

**不要一次抛出 6 个问题让用户填。** 用户的实际行为是甩一句话选题过来，答不了九问。

正确做法：先拼出一段**完整的预设场景文本**，用户改几个词就行。

## 推断来源（按优先级）

| 优先级 | 来源 | 标注 |
|---|---|---|
| 1 | **本次对话已给的信息** | 直接用，不标 |
| 2 | **用户画像与历史记忆**（赛道、人群、过往选题、**已建立的人设**） | 标 `（来自你的画像）` |
| 3 | **该垂类的常识值** | 标 `（推断，可改）` |

> 从记忆里取到就别问。取不到才用常识，并且必须标出来让用户知道这是猜的。

## 预设场景卡模板

```
【垂类】{垂类}                                    （来源标注）
【人群】{年龄区间}，{职业或身份}，{城市线}，{心理诉求}
【痛点】{痛点1} / {痛点2} / {痛点3}
【场景】{场景1}、{场景2}、{场景3}
【本篇内容】⚠️ 必填 —— 这一条视频到底讲什么
【形态】{A/B/C/D/E} —— 选它的理由：{一句}
【时长】{N}秒 —— 由形态决定
【人设】{你在这条视频里是什么身份 / 什么口吻}   ← 快手是信任经济，人设必填
【同城元素】{地名 / 方言 / 本地场景，无则写"无"}
【拍摄条件】{一个人出镜 / 有场地 / 只能桌面拍 / 有产品}
【锚点词】{…}  【痛点词】{…}  【场景词】{…}   ← 第二遍补全，第一遍可留空
```

**只有「本篇内容」是必填项。** AI 不可能知道这次要讲哪件事，这项永远留给用户。

「人设」是快手特有项——平台是老铁关系与信任经济，观众关注的是**这个人**，不是单条内容。用户没给就从画像里取并标注来源；取不到就按"接地气的实操派"预设并标 `（推断，可改）`。

「同城元素」决定能不能拿到同城权重。E 型必填，其他形态写"无"也可。

## 交付话术

给完文本后只说一句：

> 上面这段改哪都行，**【本篇内容】得你填**——这一条视频到底讲什么。
> 其余不改就直接回「确认」，我接着往下走。

**不要追问"消费力是什么""还有别的场景吗"**。用户不填就是用预设值，直接往下走。

## 形态速判（文本里没指定时这样选）

| 判断 | 形态 |
|---|---|
| 在教一个实用技能 | A 实用技能 |
| 在记录一段真实过程 | B 真实记录 |
| 在表达自己的经历或观点 | C 人设故事 |
| 有情节、有反转 | D 反转剧情 |
| 跟某个地方有关 | E 同城本地 |

都没命中 → 默认 **A**（复看率高，最容易积累信任）。

## 人群默认值

未指定人群时，按快手用户结构预设：**18–40 岁，下沉市场占比高**。
内容偏好：接地气、真实生活记录、实用技能分享、强人设 IP。

**这与抖音（18–35 岁、一二线为主）和视频号（25–50 岁）都不同，不要沿用其他平台画像。**

## 关键词提取

从最终文本里各提 **2–3 个**词，由 AI 自动提取，不需要用户填。

- **锚点词**：观众自称的身份词 → 写进标题
- **痛点词**：他会主动搜的问题词 → 写进标题与封面
- **场景词**：时间 / 地点 / 状态 → 写进口播稿

## 一个例外：用户明确要换人群

用户说"这次不是我的常规人群" → 按本次给的重填，**不要沿用画像**。
