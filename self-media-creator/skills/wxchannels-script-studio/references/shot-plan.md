# 封面与分镜展开

**封面在默认交付里；分镜表只在用户说「展开分镜」时才给。**
原因：一份 60 秒脚本展开后有 15+ 个镜头，一次铺满既吃力又容易整体返工。

---

## 封面（默认交付）

### 视频号封面的三条规则

1. **看得出价值**——封面文案要让人知道看完能得到什么。
2. **文字够大**——视频号信息流里封面缩得很小，字小了等于没有。
3. **真实感优先**——真人出镜或实拍画面优于设计感强的图。

### 封面输出格式（简版）

| 项 | 内容 |
|---|---|
| 主视觉 | 一个什么画面（一句话） |
| 封面文案 | 大字 5–12 字，从标题提炼，不另起炉灶 |
| 关键镜头提示 | 这个画面怎么拍（一句话） |
| 角标 | 是否需要，写什么 |

**第二遍展开**（用户说「展开 / 细化」才给）：构图、机位、光线、配色、生图提示词与负面词。

---

## 分镜表（第二遍，按需展开）

### 分镜密度

| 时长 | 镜头数 | 单镜上限 |
|---|---|---|
| 30s | 约 8 镜 | 4s |
| 60s | 约 16 镜 | 4s |
| 90s | 约 20 镜 | 5s |
| 120s+ | 约 24 镜 | 5s |

> 视频号节奏比抖音慢，**科普与故事型可以放宽到单镜 5–6 秒**；教程型要更碎。

### 分镜表格式

| 镜号 | 时间 | 景别 | 运镜 | 画面 | 口播对应 | 字幕 | 音效 |
|---|---|---|---|---|---|---|---|
| 1 | 0–3s | 近景 | 固定 | {画面} | {对应口播} | {大字} | {BGM 起} |
| 2 | … | … | … | … | … | … | … |

### 字段说明

| 字段 | 取值范围 |
|---|---|
| 景别 | 特写 / 近景 / 中景 / 全景 / 远景 |
| 运镜 | 固定 / 推 / 拉 / 摇 / 移 / 甩 |
| 画面 | 一句话描述，具体到"画面里有什么、人在做什么" |
| 口播对应 | 这一镜念哪一句 |
| 字幕 | 只上关键数字、清单、结论 |
| 音效 | BGM 起止、转场音效、静音留白 |

### 拍摄备注（分镜展开时一起给）

| 项 | 内容 |
|---|---|
| 演员 | 几人、是否需要出镜 |
| 道具 | 清单 |
| 场景 | 拍摄地点（真实值留【】） |
| 后期 | 剪辑要点、字幕样式、转场方式 |

---

## 与抖音分镜的关键差异

| | 抖音 | 视频号 |
|---|---|---|
| 单镜时长 | ≤ 4s，越快越好 | 4–6s，可留思考间隙 |
| 镜头数（60s） | 约 16 镜 | 14–16 镜，科普型可更少 |
| 节奏目标 | 拉完播、防划走 | 拉收藏、让人想存下来 |
| 封面取向 | 冲突感最强的一帧 | 价值最清楚的一帧 |

---

## 禁止

- 封面文字过小或压在边缘。
- 凑数分镜——每个镜头必须对应口播的某一句。
- 品牌 Logo、明星脸、他人作品、可识别车牌与门牌入镜。
- 未确认方向就一次性铺满分镜表。
