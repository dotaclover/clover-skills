# 正文规范

内容全部来自本次采集的「本篇要讲的内容」。本文件只给结构与语气，不给素材。
真实细节按 `truthfulness.md` 留【】占位。

## 硬指标

| 项 | 要求 |
|---|---|
| 字数 | 100–500，按形态取区间（A 300–450 / B 250–400 / C 300–450 / D 200–350） |
| 段落 | 每段 1–3 句，段间空行 |
| 句式 | 短句为主，单句 ≤ 20 字 |
| 手机端 | 连续不换行不超过 4 行 |

## 风格四要素（贯穿全篇，不是可选项）

**真诚友好 · 鼓励建议 · 幽默轻松 · 口语化有共情**

- **多用叹号「！」**增加感染力，适量省略号「…」制造停顿
- **多分段、多用短句**
- 自称"我"，说"我自己试下来"，不说"研究表明""专家指出"
- 鼓励而非说教：给建议，不下命令

| ✅ 要 | ❌ 不要 |
|---|---|
| 我觉得 / 我自己试下来 | 研究表明 / 专家指出 |
| 姐妹们听劝！ | 建议您 |
| 踩坑 / 翻车 / 真香 | 效果显著 / 显著改善 |
| 具体画面感描述 | 抽象形容词堆砌 |

## 倒金字塔（B / C / D 型默认）

**最重要的事放开头说明。** 读者第 1 行看不到收益就划走——结论、最大利益点、反常识判断，放在第 1–2 行。

> ⚠️ **A 型不遵守**：故事型开场给最强画面，结论后置。倒金字塔是干货型的规则，不是通用规则——故事型生搬硬套会毁掉画面感。

## 四套骨架（按形态选，不混用）

### A 单点放大（300–450 字）
| 段 | 长度 | 写什么 |
|---|---|---|
| ① 画面开场 | 1–2 行 | 最强画面，具体数字或动作（不给结论） |
| ② 细节递进 | 3–5 行 | 白描环境与他人，不空喊"我理解你" |
| ③ 峰值瞬间 | 1–2 行 | 冲击力最强的一笔，全篇情绪最高点 |
| ④ 转折 / 算账 | 1 段 | 把痛点换算成可感知的代价 |
| ⑤ 解法 | 1 段 | 我最后怎么做的 |
| ⑥ 避坑清单 | 3 条 | ①…②…③… 可照抄（**A 型必挂**） |
| ⑦ 互动钩子 | 1 行 | 提问 / 征集 / 比惨 |

### B 清单干货（250–400 字）
① 结论前置（1 行）→ ② 为什么（1 段）→ ③ 分点干货（每点 = 小标题 + 做法 + 为什么）→ ④ 个人例证（给结果不给保证）→ ⑤ 正向收束 → ⑥ 互动钩子

### C 测评对比（300–450 字）
① 结论前置（谁赢了）→ ② 声明对比维度（≥3）→ ③ 分维度对比（小标题 `维度名：谁赢`）→ ④ 适用人群（什么人选哪个）→ ⑤ 站队钩子

### D 观点站队（200–350 字）
① 抛观点（不留余地）→ ② 反方观点（显得公允）→ ③ 我的理由（2–3 点）→ ④ 让步（承认反方何时成立）→ ⑤ 站队钩子

## 小标题规则（按形态自动决定，不用问用户）

| 形态 | 小标题 | 理由 |
|---|---|---|
| A | **不要** | 故事流插小标题切碎画面感。唯一例外是结尾「避坑 N 条」清单 |
| B | **要** | 信息密度高，没小标题读者找不到重点 |
| C | **要** | 按维度做，读者才能横向比 |
| D | 可选 | < 250 字不要 |

**写法**：≤ 12 字，独立成行，前缀用 ①②③。
**必须是结论式短句，不是分类名**：❌ `第一点` ✅ `① 剩35%就规划下一站`
B 型的小标题 = 那条干货的结论句，只读小标题也能拿到 70% 信息。

## 互动钩子库

| 形态 | 钩子 |
|---|---|
| A | 比惨式：`评论区报个号，我看看谁最惨` |
| B | 征集式：`你最想看哪个场景？我下一期写` |
| C | 站队式：`{A} 还是 {B}？评论区投票` |
| D | 自曝式：`我先说，我最头疼的是 {XX}` |
| 通用 | 求助式：`这题我也没解出来，谁有办法？` |

## 话题标签

```
#{垂类大词}
#{中词1} #{中词2} #{中词3}
#{长尾1} #{长尾2} #{长尾3}
```

- 结构：**1 个大词打面 + 中词打垂类 + 长尾打精准**，总数 **5–8 个**。
- 取词来自锚点词 / 痛点词 / 场景词 + 已核实的趋势词。
- ⚠️ **具体数量别写死**：平台对标签数量的权重在变，堆太多也有堆砌嫌疑。不确定的时候**联网核实当前规则**，不凭经验定死 7 个。
- 标签本身也要过违禁词（见 `compliance.md`）。

## 避坑清单

- ❌ 绝对化用语：最 / 第一 / 100% / 永久 / 根治 / 唯一
- ❌ 功效与医疗承诺：瘦 X 斤 / 7 天见效 / 治愈（改用视觉或体验描述）
- ❌ 只戳痛点不收尾，必须落到解法 + 正向收束
- ❌ A 型不挂清单（共鸣有了，收藏没了）
- ❌ B 型不前置结论
- ❌ 大段不分行、结尾无钩子
- ❌ 编造本篇内容里没有的数据、工具名、案例
