# 封面与配图

头条优先**实拍图**——平台明确：实拍生图 > 网图，真实感强、点击率高、无版权风险。
所以本模块**弱化 AI 生图提示词**，重点给「拍什么、放哪、为什么」。

---

## 封面

### 头条封面的三条硬规则

1. **不要任何文字叠加。** 这与小红书完全相反——小红书封面必须压字，头条封面压字会被判定为低质。
2. **高清无水印**，不使用模糊截图、网络拼接图、偷拍或低俗图片。
3. **贴合主题**，图文不符会直接影响推荐。

### 封面方案输出格式

| 项 | 内容 |
|---|---|
| 主视觉 | 一张什么画面（一句话） |
| 拍摄 / 取材方式 | 实拍 / 正版图库 / 截图（注明来源） |
| 构图 | 主体位置、留白方向、横图还是方图 |
| 避坑 | 这张图容易踩什么雷（水印 / 人脸 / 品牌 Logo） |

> 封面尺寸：支持 1:1 与 16:9，系统会自动裁剪与校验，两种都给一版描述。

---

## 正文配图（3–6 张）

| 项 | 规则 |
|---|---|
| 数量 | **3–6 张**，优先九宫格或横图（比单图高约 40% 阅读量） |
| 位置 | 每 4–6 段插一张，或按小标题分段处插 |
| 图文关系 | 图配文、文衬图，不无关堆砌 |
| 版权 | 正版无版权图片，或自己实拍 |
| 水印 | **不能带其他平台水印**——这是高频限流原因 |

### 配图输出格式（精简档：张数 + 一句内容建议）

```
图 1（放在第②段后）：{拍什么 / 取什么图} —— 作用：{为什么在这里}
图 2（放在第③段后）：…
```

**第二遍展开**（用户说「展开 / 细化」才给）：
- 构图要点
- 拍摄角度与光线
- 需要出现的道具
- 图注文案（图注能提升停留时长）

## 与小红书配图的关键差异

| | 小红书 | 今日头条 |
|---|---|---|
| 封面文字 | 必须压字（三层文案） | **禁止压字** |
| 配图来源 | AI 生图为主 | **实拍 / 正版图库为主** |
| 配图数量 | 0–3 张 | **3–6 张** |
| 首图 | 首图即封面 | 首图即封面，另可设三图封面 |

---

## 禁止

- 封面压任何文字。
- 使用带其他平台水印的图。
- 无关美女图、惊悚表情包诱导点击。
- 图片里出现品牌 Logo、可识别车牌与门牌、他人肖像。
- 凑数配图——每张必须对应正文某一段。
