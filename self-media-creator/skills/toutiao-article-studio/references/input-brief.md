# 预设场景卡（第 0 步）

## 核心原则：给文本，不问问题

**不要一次抛出 6 个问题让用户填。** 用户的实际行为是甩一句话选题过来，答不了九问。

正确做法：先拼出一段**完整的预设场景文本**，用户改几个词就行。

## 推断来源（按优先级）

| 优先级 | 来源 | 标注 |
|---|---|---|
| 1 | **本次对话已给的信息** | 直接用，不标 |
| 2 | **用户画像与历史记忆**（赛道、人群、过往选题、表达偏好） | 标 `（来自你的画像）` |
| 3 | **该垂类的常识值** | 标 `（推断，可改）` |

> 从记忆里取到就别问。取不到才用常识，并且必须标出来让用户知道这是猜的。

## 预设场景卡模板

```
【垂类】{垂类}                                    （来源标注）
【人群】{年龄区间}，{城市线}，{职业或身份}，{心理诉求}
【痛点】{痛点1} / {痛点2} / {痛点3}
【场景】{场景1}、{场景2}、{场景3}
【本篇内容】⚠️ 必填 —— 这次到底讲哪一件事
【形态】{A/B/C/D/E} —— 选它的理由：{一句}
【增量】{本篇的观点 / 技巧 / 情绪价值是什么}   ← 头条对"复述型"内容零容忍
【锚点词】{…}  【痛点词】{…}  【场景词】{…}   ← 第二遍补全，第一遍可留空
【热榜词】{联网核实 / 无}
```

**只有「本篇内容」是必填项。** AI 不可能知道这次要讲哪件事，这项永远留给用户，不要替他猜。

「增量」一项若用户没给，AI 先猜一个并标注 `（推断，可改）`——但它决定文章能不能过"低质"判定，不要留空。

## 交付话术

给完文本后只说一句：

> 上面这段改哪都行，**【本篇内容】得你填**——这次到底讲哪件事。
> 其余不改就直接回「确认」，我接着往下走。

**不要追问"消费力是什么""还有别的场景吗"**。用户不填就是用预设值，直接往下走。

## 形态速判（文本里没指定时这样选）

| 判断 | 形态 |
|---|---|
| 是真实发生过的事，有具体时间地点 | A 单点放大 |
| 读者看完能照着做，能拆成几条 | B 清单干货 |
| 在比较两个以上的东西 | C 测评对比 |
| 核心是想反驳一个普遍看法 | D 观点站队 |
| 24 小时内的热榜事件 / 政策新规 / 辟谣 | E 热点解读 |

都没命中 → 默认 **B**（完读与收藏最稳，风险最低）。

## 关键词提取

从最终文本里各提 **2–3 个**词（不用凑 5 个），后续所有环节从这里取词。
**这四类词由 AI 从文本里自动提取，不需要用户填**——属于第二遍补全的项。

- **锚点词**：读者自称的身份词 → 写进标题
- **痛点词**：他会主动搜的问题词 → 写进标题与开头
- **场景词**：时间 / 地点 / 状态 → 写进正文
- **热榜词**：24 小时内热榜词 → 写进 E 型标题与标签（**必须联网核实**，搜不到写"无"，不硬编）

## 人群默认值

未指定人群时，按头条主力用户结构预设：**30–65 岁，大众刚需导向**——养生、家电用车、省钱技巧、居家菜谱、社保养老金、出行攻略、家庭相处、中年感悟。
这与小红书的主力人群差异很大，**不要沿用小红书那套年轻女性画像**。

## 一个例外：用户明确要换人群

用户说"这次不是我的常规人群" → 按本次给的重填，**不要沿用画像**。历史画像只在用户没说别的时才用。
