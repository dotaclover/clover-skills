# 发布前违禁词体检

> ⚠️ 自检清单里的"无极限词、无诱导分享"是**软自审**，不能代替这一步。
> 一篇内容写得再好，卡在审核就是零。

---

## 六类高危（公众号特有的在最后两类）

| 类别 | 典型命中 |
|---|---|
| **功效承诺** | 根治、治愈、7 天见效、瘦 X 斤、包过 |
| **医疗用语** | 消炎、杀菌、治疗、处方、症状、疗效 |
| **极限词** | 最、第一、100%、永久、唯一、顶级、全网最低 |
| **诱导互动** | 不转不是、转发才能看、集赞解锁、点赞过 X 更新 |
| **收益承诺** | 稳赚、保本、月入 X 万、躺赚、零风险 |
| **诱导分享与关注** | 分享到 X 个群领取、关注后回复关键词领取、朋友圈集赞 |

> **诱导分享是公众号的高频违规项**，且与"引导留言"的界限容易混淆——引导讨论可以，用利益换分享不行。

---

## 替换对照表

| 违禁 | 安全改法 |
|---|---|
| 根治 / 治愈 | 缓解 / 我自己的情况改善了 |
| 7 天见效 | 我自己试到第【X】天开始有感觉 |
| 最 / 第一 | 我个人用下来最顺手的 / 少见的 |
| 100% 有效 | 大部分情况 / 我遇到的几次都 |
| 月入 X 万 | 收入结构我是这么搭的（不给具体数） |
| 不转不是 / 转发才能看 | 觉得有用的话可以转给需要的人 |
| 关注后回复关键词领取 | 完整版我整理在下一篇里 |
| 点赞过 X 更新 | 想看下一期的话留言告诉我 |
| 永久 / 终身 | 很长一段时间 / 至今 |

> 替换的原则是**改成体验描述**，不是换个同义词继续吹。

---

## 体检范围：三个地方全查

| 位置 | 常见遗漏 |
|---|---|
| **标题** | 极限词、夸张前缀 |
| **正文** | 功效承诺、诱导分享、收益承诺 |
| **封面文案** | 主副文案里的极限词与功效词 |

公众号没有话题标签机制，比头条少查一处，但**封面文案同样会被判定**。

---

## 额外两项（公众号特有）

### 1. 原创与洗稿
- 轻度改写（换逻辑、换案例、重构语句之外的内容）会被原创检测命中，降权。
- 引用第三方内容需在文末标注来源，避免版权投诉。
- 使用 AI 辅助后必须做深度人工二次创作。

### 2. 流量作弊
- 刷阅读、刷在看、刷点赞 → 检测到直接降权。
- 互阅群互相点阅读 → 大量异常设备访问，判定无效流量。

这两项不做替换，只做提醒——不属于违禁词，但直接影响账号权重。

---

## 体检流程

1. 上面三个位置各过一遍六类高危。
2. 命中就**给替换建议**，并输出**仅替换违禁词后的安全版本**（不要让用户在原文里自己找）。
3. 标出命中位置：`标题` / `正文第 X 段` / `封面主文案`。
4. 没命中就明说"未命中六类高危"，不要含糊带过。

---

## 两条提醒

- **词库会更新。** 不确定某个词当前是否敏感 → 联网核实，不凭记忆判断。宁可改掉也不赌。
- **变体规避无效。** 谐音、拆字、符号替代（薇信 / +V）都会被识别，而且被判定后性质更差。别写。

---

## 发布前最后一步

发布后可修改次数有限（通常每篇限改 3 次，且字数有限）。**预览到手机端再发**，重点检查排版错乱、图片加载、错别字。
