# 封面与分镜展开

**封面在默认交付里；分镜表只在用户说「展开分镜」时才给。**
原因：一份 45 秒脚本展开后有 12+ 个镜头，一次铺满既吃力又容易整体返工。

---

## 封面（默认交付）

### 抖音封面的三条规则

1. **冲突感最强的一帧**——不是最好看的一帧，是最有张力的一帧。
2. **文字够大**——信息流里封面缩得很小。
3. **大字报或人物特写**——两种经过验证的高点击方向。

### 封面输出格式（简版）

| 项 | 内容 |
|---|---|
| 主视觉 | 一个什么画面（一句话） |
| 封面文案 | 大字 5–12 字，从标题提炼 |
| 关键镜头提示 | 这个画面怎么拍（一句话） |
| 方向 | 大字报 / 人物特写，二选一并说明理由 |

**第二遍展开**（用户说「展开 / 细化」才给）：构图、机位、光线、配色、生图提示词与负面词。

---

## 分镜表（第二遍，按需展开）

### 分镜密度（抖音的核心节奏）

| 时长 | 镜头数 | 单镜上限 |
|---|---|---|
| 15s | 约 5 镜 | 3s |
| 30s | 约 8 镜 | 4s |
| 45s | 约 12 镜 | 4s |
| 60s | 约 16 镜 | 4s |

> **单镜不超过 4 秒**是抖音的硬节奏。超过 4 秒观众会感到停滞。

### 分镜表格式

| 镜号 | 时间 | 景别 | 运镜 | 画面 | 口播对应 | 字幕 | 音效 |
|---|---|---|---|---|---|---|---|
| 1 | 0–2s | 特写 | 推 | {画面} | {对应口播} | {爆点大字} | {BGM 起} |
| 2 | … | … | … | … | … | … | … |

### 字段说明

| 字段 | 取值范围 |
|---|---|
| 景别 | 特写 / 近景 / 中景 / 全景 / 远景 |
| 运镜 | 固定 / 推 / 拉 / 摇 / 移 / 甩 |
| 画面 | 一句话描述，具体到"画面里有什么、人在做什么" |
| 口播对应 | 这一镜念哪一句 |
| 字幕 | 只上爆点：数字、反差、金句 |
| 音效 | BGM 起止、卡点、转场音效 |

### 拍摄备注（分镜展开时一起给）

| 项 | 内容 |
|---|---|
| 演员 | 几人、是否需要出镜 |
| 道具 | 清单 |
| 场景 | 拍摄地点（真实值留【】） |
| 后期 | 卡点剪辑、转场方式、字幕样式、特效 |

---

## 与视频号分镜的关键差异

| | 抖音 | 视频号 |
|---|---|---|
| 单镜时长 | **≤ 4s**，越快越好 | 4–6s，可留思考间隙 |
| 镜头数（60s） | 约 16 镜 | 14–16 镜 |
| 节奏目标 | 拉完播、防划走 | 拉收藏、让人想存下来 |
| 封面取向 | **冲突感最强的一帧** | 价值最清楚的一帧 |
| 卡点 | BGM 鼓点驱动剪辑 | 可无卡点 |

---

## 禁止

- 单镜超过 4 秒（教程演示除外，需标注理由）。
- 封面文字过小或压在边缘。
- 凑数分镜——每个镜头必须对应口播的某一句。
- 品牌 Logo、明星脸、他人作品、可识别车牌与门牌入镜。
- 未确认方向就一次性铺满分镜表。
