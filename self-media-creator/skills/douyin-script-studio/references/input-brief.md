# 预设场景卡（第 0 步）

## 核心原则：给文本，不问问题

**不要一次抛出 6 个问题让用户填。** 用户的实际行为是甩一句话选题过来，答不了九问。

正确做法：先拼出一段**完整的预设场景文本**，用户改几个词就行。

## 推断来源（按优先级）

| 优先级 | 来源 | 标注 |
|---|---|---|
| 1 | **本次对话已给的信息** | 直接用，不标 |
| 2 | **用户画像与历史记忆**（赛道、人群、过往选题、表达偏好） | 标 `（来自你的画像）` |
| 3 | **该垂类的常识值** | 标 `（推断，可改）` |

> 从记忆里取到就别问。取不到才用常识，并且必须标出来让用户知道这是猜的。

## 预设场景卡模板

```
【垂类】{垂类}                                    （来源标注）
【人群】{年龄区间}，{职业或身份}，{城市线}，{心理诉求}
【痛点】{痛点1} / {痛点2} / {痛点3}
【场景】{场景1}、{场景2}、{场景3}
【本篇内容】⚠️ 必填 —— 这一条视频到底讲什么
【形态】{A/B/C/D/E} —— 选它的理由：{一句}
【时长】{N}秒 —— 由形态决定，宁短勿长
【转折设计】{中段在哪一秒转折 / 反转}   ← 抖音中途流失率的解法
【拍摄条件】{一个人出镜 / 有场地 / 只能桌面拍 / 有产品}
【锚点词】{…}  【痛点词】{…}  【场景词】{…}   ← 第二遍补全，第一遍可留空
```

**只有「本篇内容」是必填项。** AI 不可能知道这次要讲哪件事，这项永远留给用户。

「转折设计」是抖音特有项——完播率为王，中段没有转折观众就划走了。用户没给就 AI 给一个并标 `（推断，可改）`。

「拍摄条件」决定分镜能不能落地，第一遍若用户没说，按"一个人出镜 + 固定机位"预设并标注。

## 交付话术

给完文本后只说一句：

> 上面这段改哪都行，**【本篇内容】得你填**——这一条视频到底讲什么。
> 其余不改就直接回「确认」，我接着往下走。

**不要追问"消费力是什么""还有别的场景吗"**。用户不填就是用预设值，直接往下走。

## 形态速判（文本里没指定时这样选）

| 判断 | 形态 |
|---|---|
| 在教一个方法或技巧 | A 痛点开场 |
| 想颠覆一个普遍认知 | B 反常识钩子 |
| 能拆成 N 条清单 | C 数字列表 |
| 有情节、有反转 | D 剧情反转 |
| 24 小时内的热点 / 挑战 / BGM 二创 | E 热点跟拍 |

都没命中 → 默认 **A**（完播与收藏最稳，风险最低）。

## 时长判断（宁短勿长）

内容承载力决定时长，不是反过来：

| 内容量 | 建议时长 |
|---|---|
| 一个反常识结论 | 15–20s |
| 一个方法 | 25–35s |
| 三个方法 | 40–50s |
| 有情节有反转 | 20–30s |
| 完整教程 | 45–60s（超过 60s 需特别理由） |

**超过 60 秒的脚本必须说明为什么需要这么长**——完播率会显著下滑。

## 人群默认值

未指定人群时，按抖音用户结构预设：**18–35 岁，一二线为主**。
内容偏好：强节奏、高颜值、剧情反转、新奇特效、热门 BGM 二创。

**这与视频号（25–50 岁、全年龄段）差异很大，不要沿用视频号画像。**

## 关键词提取

从最终文本里各提 **2–3 个**词，由 AI 自动提取，不需要用户填。

- **锚点词**：观众自称的身份词 → 写进标题
- **痛点词**：他会主动搜的问题词 → 写进标题与封面
- **场景词**：时间 / 地点 / 状态 → 写进口播稿

## 一个例外：用户明确要换人群

用户说"这次不是我的常规人群" → 按本次给的重填，**不要沿用画像**。
