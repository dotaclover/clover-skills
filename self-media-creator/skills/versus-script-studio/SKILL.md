# 对决稿 · Versus

> ⚠️ **未完成，待完善（v0.1）**
>
> **已可用**：九段骨架、段落节奏表、四条写法规则、金句收束范式、事实纪律。
> **未完成**：没有可执行脚本；案例库只有 1 条（Codex vs WorkBuddy）；不出分镜、不出封面、不做平台分发。
> 被调用时先说明这一点，再交付稿件，**不要说"这个技能已经完备"**。

两个东西放在一起，讲清楚该选哪个。**不卖货，不评优劣，只给判据。**

## 一、这个技能只管一件事

| 是 | 不是 |
| --- | --- |
| 两个工具/产品/方案的**横向测评**，3–4 分钟纯口播 | 单产品种草（走平台工坊的 A 知识科普 / D 教程） |
| 两边都真实用过，能说出各自短板 | 只深度用过一边，另一边靠听说 |
| 观众已经在问"该选哪个" | 观众还不知道这是什么东西（先做科普） |

**判断只有一句**：有没有人同时提到这两个名字，并问"选哪个"。没有 → 这不是对决稿。

## 二、与三个平台工坊的边界

抖音 / 快手 / 视频号三个 `*-script-studio` 管**平台规则**（钩子、时长、封面、违禁词、赛马机制）；
本技能管**文体**（怎么把两个东西公道地比完）。两者正交：

```
选题 → [平台工坊：钩子 + 封面 + 合规] ─┐
                                        ├→ 一条成片
        [本技能：九段骨架 + 口播稿] ────┘
```

**不要**在本技能里写平台话术（"家人们""3 秒抓住你"）。也不要让平台工坊去写 3 分钟长稿——
它们的骨架最长到 180 秒，而且节奏取向是"每 12 字一个爆点"，会把测评写成功利广告。

## 三、最短工作流

### 第 0 步：三问定对阵

1. **两边你都真用过吗？** 有一边没有 → 停，改写成"我为什么选 A"。
2. **谁在问？** 写清提问者的身份（开发者 / 运营 / 老板），九段的详略按他关心什么排。
3. **多长？** 3 分钟（默认，180–200 秒）或 4 分钟（维度多到 7 个以上）。

三问不问完就开写，最后一定写成产品说明书。

### 第 1 步：填九段表

段名、时长、这段干什么——见 `references/九段骨架.md`。先把表填满，再动笔。
**九段不是模板填空题**：段长要按"用户最在意哪个维度"重排，最在意的那段加 10 秒，别的段减。

### 第 2 步：先出节奏表，再写稿

```
开场 15s｜来路 18s｜痛点 30s｜短板 32s｜生态 22s｜自动化 22s｜安全 20s｜价格 18s｜怎么选 30s
```

这张表先给用户看。**节奏不对，稿子写再好也是废的**——这是这类片子唯一的结构性返工点。

### 第 3 步：按四条规则写

1. **去编号腔**：不写"第一点、第二点"，用主语切换推进（`A 解决的是… B 解决的是…`）。
2. **每组对比后一句金句收束**：`一个……，一个……`。观众记住的就是这句。
3. **短板双向写**：写完对方短板，紧接着写自己的，中间用"但这两边也都有话得说回来"过渡。
4. **结尾不给赢家**：给一个用户自己能回答的问题（"明天早上打开电脑，你第一件事是写代码还是写文档"）。

细则与范式见 `references/九段骨架.md` 第三节。

### 第 4 步：事实体检

价格、功能、时间三项逐条过。**拿不准的写"以官网为准"，不要写"目前""现在"这种会过期的词。**

## 四、交付规格（精简档）

| # | 项目 | 规格 |
| --- | --- | --- |
| 1 | 对阵卡 | 两个对象 + 提问者身份 + 时长 + 一句话对阵关系 |
| 2 | 段落节奏表 | 九段 × 秒数 × 语气，合计等于目标时长 |
| 3 | 完整口播稿 | 可直接念，短句，标注每段字数与预估秒数 |
| 4 | 金句表 | 每个对比维度一句「一个……一个……」，标哪句做记忆点 |
| 5 | 事实体检 | 价格/功能/时间逐项标注「已核实 / 以官网为准 / 未核实」 |

**不出**：分镜、封面、标题、违禁词体检（那是平台工坊的活）、拆条（见待完善清单）。
