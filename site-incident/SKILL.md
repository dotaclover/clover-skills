# 网站安全事件响应

先读取当前project brief、事件记录、授权、合同政策与恢复验收要求。费用、服务窗口、响应级别及报告义务由用户当前约定和专业意见确定，不内置诊断费、按天价、固定SLA或法律期限。

普通故障走 `site-rescue` / `site-maintenance`；出现陌生账号、恶意跳转、异常文件或反复篡改时使用本流程。只做用户拥有或书面授权资产的防御处理，不进行未授权测试。

## 五步

1. **确认与分级**：核对资产、症状、首次发现时间、最近变更、涉及数据及可操作边界。确定负责人和沟通渠道，区分事实与猜测。
2. **止损决策**：评估隔离、暂停服务、撤销凭据等选项及业务影响，由用户批准具体动作。不要先删文件、重装或清日志；紧急授权也须记录范围。
3. **留证**：保存受限访问的副本、文件路径/哈希、必要日志、篡改页面截图、异常账号与时间线；仅收集任务所需数据，隐藏秘密及无关个人信息，保持原始证据可追溯。
4. **整改**：在隔离副本与可信基线比较，定位入口，更新受影响组件、移除获批恶意对象、轮换暴露凭据、收紧权限并修复根因。只清明确归属的对象，不批量删除未知文件；每步保留恢复路径。
5. **恢复与复核**：完成副本验证后按获批计划恢复服务，复测页面、后台、表单、外链和监控记录。记录观察窗口与仍未验证部分，不以单次正常证明已完全清除。

## 数据、沟通与边界

- 数据恢复先副本演练，不承诺必然找回；覆盖恢复前确认新增数据取舍。
- 对外报告写实际技术事实、证据、措施与限制；必要的外部通知和法律责任由用户咨询适当专业人士确认，不代签或伪造证明。
- 不出具超出资质的测评、安全保证或解封承诺，不隐瞒事实，不提供规避审查或追踪的技术。
- 无法确认根因或反复感染时暂停扩大清理，提交重建/专业响应方案及成本范围，经批准后执行。
- 工具与记录目录从当前项目确定，先审查工具行为，不假定固定生成脚本。凭据不进仓库、聊天和录屏。

## 输出

资产与授权范围、时间线、证据索引、止损决定、根因与置信度、整改清单、备份恢复结果、复测、残留风险、权限撤销、后续责任人。费用/抵扣/后续维护按当前合同，不内置商业政策。
