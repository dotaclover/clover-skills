# 发布与文案

## 抖音发布规格

| 项 | 限制 | 做法 |
|---|---|---|
| 短标题 | 30 字 | 用满，带 EP 编号 |
| 描述 | 1000 字 | 控制在 100 字左右 |
| 话题 | 最多 5 个 | 选有搜索量的，不自造长尾词 |
| 合集 | 单独功能 | 三集挂同一合集，自动连播 |

标题模板：`用TRAE做小程序EP0x：<母题>`

- 例：`用TRAE做小程序EP01：一句话到可演示原型`（22 字）
- 「可演示原型」比「能点的原型」准确，比「可交互原型」好懂

描述结构（100 字内）：

```
钩子问句（一行，制造信息缺口）
↓
一段事实（做了什么、几步、卡在哪）
↓
一句判断 or 数据（为什么值得看）
↓
下一集指路（连更时）
```

要点：

- 折叠后只看前两行，钩子必须在第一行。
- 不要堆步骤清单，像文档的描述会被划走。
- 详细版丢到置顶评论或图文，不进描述。

话题选择：`#AI编程 #TRAE #微信小程序 #AI做小程序 #独立开发`。
`#用TRAE开发微信小程序` 这类自造词没有搜索量，删掉——合集名去承载「系列」这件事。

**链接一律放置顶评论**，描述里放链接不跳转。推广集（EP03）用真实截图 + 绿框圈出 Star / Fork，比口播描述转化高。

## 三集连发的节奏

- 间隔 ≥30 分钟，别同一分钟发完：同质内容集中发布容易被压量。
- 转化最好的那条（开源 / 引流）放在流量最高的时段。
- 每条发出后立刻自己置顶评论放仓库地址。

## 多平台分发

| 平台 | 做法 | 原因 |
|---|---|---|
| 抖音 | 3 条竖屏 + 合集 | 主阵地 |
| 视频号 | 3 条分开 | 单条完播率权重高，80 秒远好于 5 分钟 |
| 小红书 | 3 条 + 一篇图文 | 3:4 封面可直接复用 |
| B站 | 3 条 + 合集，另出 16:9 封面 | 竖屏有独立推荐流量，但封面必须 16:9 |
| 掘金 / CSDN / 知乎 | 图文 + 内嵌视频 | 唯一能放外链、直接转化 star 的渠道 |
| 公众号 | 一篇合订文章 | 长期落地的「主页」 |

**不要**把三条合成一条 5 分钟竖屏：竖屏长视频在 B站 和视频号都不占优。横屏合订版是另一条产品线，需要重新排版（左录屏 + 右讲解栏），等单集过千播放再考虑。

## 开源项目配套

- 仓库 README 写：一句话介绍、页面结构、技术选型、导入四步、教程索引、star / fork 引导。
- 视频里给地址，不给可点链接；口播不念 URL。
- 首页截图就是最好的推广素材，比自制海报有效。
