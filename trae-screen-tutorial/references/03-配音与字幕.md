# 配音与字幕

## 音色

| 场景 | 音色 | rate |
|---|---|---|
| 普通话教程（默认） | `zh-TW-YunJheNeural`（雲哲） | `+18%` |
| 普通话备选 | `zh-CN-YunJianNeural`（雲健） | `+18%` |
| 粤语 | `zh-HK-WanLungNeural`（雲龍） | `+0%` |
| 早期版本 | `zh-CN-YunxiNeural`（雲希） | 声音偏年轻，不像讲师，别用 |

- `+18%` 是这批视频定下来的语速：`+8%` 明显拖，`+28%` 开始赶。
- 粤语版：TTS 文本用繁体书面，字幕用简体口语；两套文本分开维护，别指望一套打天下。
- 配音按 `sha1(voice + rate + text)` 缓存到 `build/audio/`，改文案只重跑变的那一拍。

## 念不出来的字，改文案而不是改拼写

`行` 在「改动一百一十行」里会被读成 xíng。加空格、全角、破折号、改大小写**都无效**（实测时长差异 < 0.06 秒，发音不变）。

处理方式：**把这句话从旁白里删掉**，信息留在画面字幕上。不要试图用拼音、谐音或注音骗过 TTS，口音会更怪。

同理：URL、英文命令、代码片段不要念，全部走画面 + 字幕，旁白只用「地址在屏幕上」。

## 两层字幕

1. **大字结论**（每拍 2 行，粗体 56px）：写判断，不写旁白原文。位置 `CAP_TOP=1580`，行距 84。
2. **底部烧录口播字幕**（40px，白字黑描边）：旁白全文，按字数比例切句，跟配音逐句切换，去掉句尾逗号。

两层同时存在是这个系列的标准形态：大字给「刷到就走」的人看，底部字幕给「静音看」的人看。

## 中英混排

字幕统一过一遍归一化：汉字与字母、数字之间不留空格。

```
我让 TRAE 改了三遍   →  我让TRAE改了三遍
点个 star，fork 下来  →  点个star，fork下来
```

纯英文之间（URL、命令）的空格保留。

## 口播字幕的实现

- 用 PIL 渲染成透明 PNG（白字 + 2px 黑描边），按 `enable='between(t,a,b)'` overlay 到成片上。
- 句子切分按字符数比例分配时间，不引入 ASR，避免错字。
- 单行不超过 22 字，超过就换行成两行，字号不变。

## 音频合成

```
[mp3] adelay=<start_ms>|<start_ms>, apad → amix=inputs=N:normalize=0 → loudnorm=I=-16:TP=-1.5:LRA=11
```

- 必须 `normalize=0`，否则 N 路混音会把音量除以 N。
- 最终响度 `-16 LUFS`，抖音 / 视频号听感一致。
