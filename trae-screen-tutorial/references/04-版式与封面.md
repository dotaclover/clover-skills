# 版式与封面

## 固定版式（所有集共用，改一次全体变）

```
1080×1920 @30fps
├─ y=58    系列行：● 顺哥TRAE教程系列          右上：小程序开发·EP0x
├─ y=116   步骤号（60px 绿）+ 章节（36px 白）
├─ y=200   标题（58px 粗体白）
├─ y=312   分隔线
├─ y=316   画面框 960×1200，圆角 8，描边 2px，带阴影
├─ y=1534  进度点：当前拍绿色，其余灰 (56,70,88)，间距 25
├─ y=1580  大字结论：第一行白、第二行灰，56px，行距 84
└─ y=1700+ 底部口播字幕（40px，白字黑描边）
```

配色：

```
背景渐变 (8,11,16) → (15,21,29)
强调色   (18,227,155)
正文     (243,246,250)
次要     (138,152,168)
描边     (46,60,78)
```

字体：`C:\Windows\Fonts\msyhbd.ttc`（粗）/ `msyh.ttc`（常规）。

三条硬规则：

1. **画面框尺寸不变**。变的是框里框外的内容，观众第二集才有熟悉感。
2. **进度点数量 = 拍数**。连更时它是「还剩多久」的锚点。
3. 大字结论不得超过两行；底部口播字幕不得压到进度点（`DOT_Y - 10` 之外就截断）。

## 纯文字收尾卡

`kind="text"`，画面框内居中排 2–3 行：前两行 80px 粗体白，第三行 46px 绿色。

结构固定：

- 第 1–2 行：这一集的观点（「界面改了三遍 / 代码只写一遍」）
- 第 3 行：署名 + 下一集（「顺哥 · 下个视频见」）

## 封面（1080×1440，3:4）

抖音竖版封面按 3:4 展示，单独出图，不要用视频首帧。

统一模板：

```
y=86     ● 顺哥TRAE教程系列                     右：小程序开发
y=170    超大集数 150px 强调色（01 / 02 / 03）
y=350    短强调条 120×6
y=420    主标题第一行 112px
y=556    主标题第二行 112px
y=740    关键词行 44px 灰（砍字段·拆职责·换话术）
y=940+   右侧集数导轨：01 / 02 / 03 竖排，当前集高亮
y=1180   分隔线
y=1226   一句结论 38px
y=1330   左：第 x 集 · 共 3 集      右：全程录屏 / 仓库地址
```

- 主标题就是这一集的母题，两行、每行 2–6 字；三集连看时能一眼看出递进。
- 集数导轨是「这是系列」的视觉信号，比写「合集」两个字有效。
- 生成脚本 `scripts/make_covers.py`，改 `EPS` 列表即可。

## 横版讲解台（1920×1080，5–10 分钟长片）

竖屏是「一集一个动作」，横屏是「一节一个论点」，所以版式从「左上角信息 + 大画面框」改成左右分栏，右侧始终有字，观众不会只盯着截图看。

```
1920×1080 @30fps
├─ y=44     ● 顺哥 · TRAE 实战              右上：AI 编程 · 横屏长片
├─ y=128    分隔线
├─ 左：画面框 (80,164) 1136×639，圆角 8，描边 2，带阴影
├─ 右：讲解区 x=1264 宽 576
│   ├─ 章节号 86px 绿 + 章节名 34px（y≈150–230）
│   ├─ 标题 54px 粗体，最多 3 行，行距 70
│   ├─ 标题下短强调条 96×4
│   └─ 要点 30px：绿色小方块 + 文字，最多 3 条，每条可折 2 行
├─ y=846    口播字幕：左侧 6px 绿条 + 46px 白字黑描边，最长 1600px
└─ y=1006   章节条：10 个章节名 24px，当前项绿色 + 下划线
```

规则：

1. **右侧永远有字**。哪怕画面已经把事说清，右侧也放标题和 3 条要点，横屏观众需要文字锚点。
2. **截图按 1:1 放大裁切**，不做整窗缩小。3072 宽的窗口截图缩到 1136 会看不清字，必须裁到 1240×698 再贴，近似原尺寸。
3. **长截图用 1119×629 静态窗口**，按段落起点取帧，不做滚动动画（同竖屏的第 2 条铁律）。
4. **纯文字卡**用 `panel` 多行：首行 70px 白，其余 46px 绿，底下一行 32px 灰做补充；超宽自动缩字号。
5. 章节条就是进度指示，不另做进度条。

## 横版封面（1920×1080，16:9）

不用视频首帧，单独出图。三段式，左边是固定的虚拟形象（AI 生成，戴眼镜的技术博主），每条同一个人，建立视觉识别：

```
左侧 0–620     虚拟形象（同一张 AI 生成素材，裁到腰以上）
右侧 660–1860  主标题：两行，110px，第二行可以是强调色
底栏 y=1000+   价值点：40px 灰字，「AI 编程实战 · 持续更新」
```

- 标题不超过 14 字，两行；不放集数、不放小字。
- 底部价值点每期不变，形成固定签名。
