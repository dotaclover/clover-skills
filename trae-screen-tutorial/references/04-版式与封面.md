# 版式与封面

## 固定版式（所有集共用，改一次全体变）

```
1080×1920 @30fps
├─ y=58    系列行：● 顺哥TRAE教程系列          右上：小程序开发·EP0x
├─ y=116   步骤号（60px 绿）+ 章节（36px 白）
├─ y=200   标题（58px 粗体白）
├─ y=312   分隔线
├─ y=316   画面框 960×1200，圆角 8，描边 2px，带阴影
├─ y=1534  进度点：当前拍绿色，其余灰 (56,70,88)，间距 25
├─ y=1580  大字结论：第一行白、第二行灰，56px，行距 84
└─ y=1700+ 底部口播字幕（40px，白字黑描边）
```

配色：

```
背景渐变 (8,11,16) → (15,21,29)
强调色   (18,227,155)
正文     (243,246,250)
次要     (138,152,168)
描边     (46,60,78)
```

字体：`C:\Windows\Fonts\msyhbd.ttc`（粗）/ `msyh.ttc`（常规）。

三条硬规则：

1. **画面框尺寸不变**。变的是框里框外的内容，观众第二集才有熟悉感。
2. **进度点数量 = 拍数**。连更时它是「还剩多久」的锚点。
3. 大字结论不得超过两行；底部口播字幕不得压到进度点（`DOT_Y - 10` 之外就截断）。

## 纯文字收尾卡

`kind="text"`，画面框内居中排 2–3 行：前两行 80px 粗体白，第三行 46px 绿色。

结构固定：

- 第 1–2 行：这一集的观点（「界面改了三遍 / 代码只写一遍」）
- 第 3 行：署名 + 下一集（「顺哥 · 下个视频见」）

## 封面（1080×1440，3:4）

抖音竖版封面按 3:4 展示，单独出图，不要用视频首帧。

统一模板：

```
y=86     ● 顺哥TRAE教程系列                     右：小程序开发
y=170    超大集数 150px 强调色（01 / 02 / 03）
y=350    短强调条 120×6
y=420    主标题第一行 112px
y=556    主标题第二行 112px
y=740    关键词行 44px 灰（砍字段·拆职责·换话术）
y=940+   右侧集数导轨：01 / 02 / 03 竖排，当前集高亮
y=1180   分隔线
y=1226   一句结论 38px
y=1330   左：第 x 集 · 共 3 集      右：全程录屏 / 仓库地址
```

- 主标题就是这一集的母题，两行、每行 2–6 字；三集连看时能一眼看出递进。
- 集数导轨是「这是系列」的视觉信号，比写「合集」两个字有效。
- 生成脚本 `scripts/make_covers.py`，改 `EPS` 列表即可。
