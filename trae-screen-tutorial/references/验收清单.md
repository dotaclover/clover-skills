# 验收清单

出片后逐项过，**没抽帧看过成片不算完成**。

## 规格

```bash
ffprobe -v error -show_entries stream=codec_name,profile,level,width,height,r_frame_rate,pix_fmt,sample_rate,channels \
  -show_entries format=duration,size -of default=nw=1 成片/xxx.mp4
ffprobe -v error -show_entries format=duration -of csv=p=0 成片/xxx.mp4
```

- [ ] 1080×1920、30fps、`yuv420p`、H.264、AAC 48kHz 立体声
- [ ] 时长与规划误差 ≤0.25s（脚本已自动卡这一条）
- [ ] `ffmpeg -v error -i xxx.mp4 -f null -` 无输出（无解码错误）
- [ ] 文件带 `+faststart`（`-movflags`），首帧可秒开

## 画面

```bash
ffmpeg -y -v error -ss <每拍中点> -i 成片/xxx.mp4 -frames:v 1 chk-<拍>.jpg
```

- [ ] 每拍至少抽 1 帧：无黑帧、无错帧、无上一拍残留
- [ ] 字幕不溢出、不被底部安全区（y>1620）压到
- [ ] 裁切里没有混入文件树、滚动条、调试高亮
- [ ] 画面里的文字在手机上能读（≈18px 以上等效字号）
- [ ] 片头标题不顶到右边缘（中文+英文混排最容易溢出）

## 声音

```bash
ffmpeg -hide_banner -i 成片/xxx.mp4 -af volumedetect -f null NUL 2>&1 | findstr volume
```

- [ ] mean_volume 在 −26 ~ −18 dB，max_volume ≤ −1 dB
- [ ] 每拍配音起点对得上画面（听前 10 秒和中间任意一拍的接头）
- [ ] 无爆音、无半句截断

## 交付

- [ ] `beats.json`、`build_tutorial.py`、`audio/` 一并留在项目目录（可复现）
- [ ] 中文路径打不开时，另给 `output/` 下 ASCII 文件名副本
- [ ] 报告里写清：拍数、总时长、素材来源、配音方式、已知限制
