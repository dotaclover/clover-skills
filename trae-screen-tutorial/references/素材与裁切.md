# 素材与裁切

## 1. 先看素材，再选窗口

```bash
ffprobe -v error -show_entries format=duration,bit_rate \
  -show_entries stream=width,height,r_frame_rate -of json 01.mp4
```

按 5–10 秒抽帧看画面变化。**不要用 `fps` 滤镜配 `drawtext %{pts}` 打时间码**——`fps` 会把时间戳归零，标出来的全是 00:00:00。要带时间码就用 `select` + 帧号换算，或者干脆按固定间隔拼接触表，用「第几格 × 间隔」推时间。

判断标准：只有出现**信息变化**的窗口才值得剪——输入框里出现完整需求、文件树多出文件、聊天总结落到屏幕、页面切换、弹层打开。录屏里 80% 是等待。

## 2. 量裁切框

裁切框用**原始像素**，不是缩放后的坐标。做法：

1. 在预览图里目测比例，乘以原始宽度换算；
2. 再按候选框抽一帧确认文字有没有被切断；
3. 拿不准就用 PIL 扫一行像素找文字最右列，别靠眼睛估。

常用经验（素材 2432×1440）：

| 内容 | 典型裁切 | 缩放后 |
|---|---|---|
| 聊天面板（含用户气泡） | 1200–1400 宽 | 0.7–0.8× |
| 文档预览（占屏 60%） | 900–1200 宽 | 0.8–1.0× |
| 手机原型面板（天然 9:16） | 830×920 | ≈1.0× |
| 欢迎页 + 输入框 | 1300×620 | 0.7× |

原则：**裁切宽度 800–1400**。太宽文字小到手机上读不清；太窄会把整句切断。宁可少放内容，也不要放读不清的内容。

## 3. 常见坑

- **右侧被切**：文档/表格常贴着编辑器右边缘，先确认表格最右列在不在画面里；不在就换一个时间点或换一片内容。
- **左侧混入别的面板**：IDE 分栏位置每段录屏可能不同（聊天栏占 205–370 还是 205–600），按**这一段**的布局量，不要复用别的段落的值。
- **同一屏两段时间看起来一样**：文档长时间不滚动时，两拍会几乎一致，观众会以为卡住。换内容或换页面，不要硬凑拍数。
- **调试态**：浏览器被元素检查高亮、出现绿框截图时不能用作正式镜头。
- **中文路径**：部分 IDE 内嵌预览器打不开中文路径的 mp4（报 5104 / Format error）。交付时另存一份 ASCII 文件名的副本到 `output/`。

## 4. 抽帧自查

```bash
# 单帧
ffmpeg -y -v error -ss 12.5 -i 01.mp4 -frames:v 1 -vf "crop=1200:900:900:200" check.png
```

成片后也要抽：`--ss` 取每拍中点，确认没有黑帧、错帧、字幕溢出。
