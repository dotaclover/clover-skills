# 后期与验收

## 关键 ffmpeg 配方

**图片拍（定格）**

```bash
ffmpeg -y -loop 1 -framerate 30 -i bg.png -t 12.3 -r 30 -an \
  -c:v libx264 -preset medium -crf 16 -pix_fmt yuv420p out.mp4
```

**截图铺进画面框**：先 `crop` 量好的区域，再 `scale` 到 960×1200，`overlay` 到背景卡上。
**禁止对截图加 zoompan / scale 动画**：亚像素重采样会让文字轻微抖动，这是最容易被观众察觉的瑕疵。静止 = 专业。

**视频拍（加速 + 补尾帧）**

```bash
ffmpeg -ss <t_in> -t <mat> -i src.mp4 -loop 1 -framerate 30 -i bg.png \
  -filter_complex "[0:v]crop=w:h:x:y,scale=960:1200,setsar=1,fps=30,\
setpts=(PTS-STARTPTS)/<speed>,tpad=stop_mode=clone:stop_duration=<pad>[fg];\
[1:v][fg]overlay=60:316:shortest=1,drawbox=x=60:y=316:w=960:h=1200:color=0x2E3C4E@0.9:t=2[o]" \
  -map "[o]" -t <dur> -r 30 -an -c:v libx264 -preset medium -crf 16 -pix_fmt yuv420p out.mp4
```

**拼接**：`-f concat -safe 0 -i list.txt -c copy`（各分段编码参数必须完全一致）。

**混音**

```bash
ffmpeg -i v.mp4 -i a.m4a -c:v copy -c:a copy -movflags +faststart -t <dur> final.mp4
```

## 验收清单

出片后**必须**跑完，逐项过：

- [ ] `ffprobe` 分辨率 1080×1920、30fps、时长与预期一致（误差 <0.3s）
- [ ] `ffmpeg -v error -i final.mp4 -f null -` 解码无报错
- [ ] 抽 3–4 帧（开头 / 中段 / 收尾）看：取景有没有切字、字幕有没有重叠、进度点数量对不对
- [ ] 字幕与配音对齐：随机挑两拍听一遍
- [ ] 响度 `-16 LUFS`
- [ ] 交付一份 ASCII 文件名副本（中文路径在某些播放器 / IDE 预览里打不开）

## 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 画面里文字被左右切掉 | 4:5 框套了三栏布局 | 用 `measure_crop.py` 重测，一拍只对准一栏 |
| 截图有轻微抖动 | 加了 zoompan / 缩放动画 | 去掉动画，静止 |
| 配音音量为 1/N | amix 没设 `normalize=0` | 补上参数 |
| 「行」念成 xíng | TTS 多音字 | 删掉这句旁白，信息留给字幕 |
| IDE 预览报 5104 | 播放器 / 路径问题，与编码无关 | 换系统播放器，或给 ASCII 路径副本 |
| 时长对不上 | 素材比配音短，tpad 没配 | 检查 `pad` 计算 |

## 环境

- Windows + PowerShell，`ffmpeg` / `ffprobe` 在 PATH
- `pip install -r requirements.txt`（Pillow、edge-tts、numpy）
- 中文字体：`C:\Windows\Fonts\msyhbd.ttc`、`msyh.ttc`
- edge-tts 需要联网；不可联网时改用已有 mp3 缓存或纯字幕版
