# 配置字段

`beats.json` 是唯一输入。除 `beats` 外都可省略。

```json
{
  "out_name": "tutorial",
  "brand": "AI 从零开始",
  "episode": "Part04",
  "min_dur": 4.3,
  "max_speed": 2.6,
  "fonts": {"bold": "C:/Windows/Fonts/msyhbd.ttc", "regular": "C:/Windows/Fonts/msyh.ttc"},
  "theme": {"bg_top": "#090D12", "bg_bottom": "#111821", "accent": "#12E39B",
            "text": "#F2F6FA", "dim": "#8B9AAB", "line": "#1E2836", "border": "#2E3C4E"},
  "voice": {"enabled": true, "name": "zh-CN-XiaoxiaoNeural", "rate": "+8%"},
  "intro": {"kicker": "Part04 · 项目名", "lines": ["一个人，一句话", "一个晚上", "做出一个能点的 App"],
            "sub": "从需求到原型的全过程", "voice": "一个人，一句话，做出一个能点的 App。", "min_dur": 3.6},
  "outro": {"title": ["一个晚上", "三个文件"],
            "cards": [["PRO.md", "需求分析 · 功能清单"], ["MOCKUP.html", "可点的手机原型"]],
            "footer": "全部本地 · 不联网", "voice": "三个文件，全部本地跑通。", "min_dur": 3.6},
  "beats": [
    {"name": "b01", "src": "C:/Users/xxx/Videos/录制/01.mp4",
     "t_in": 0.8, "t_out": 4.9, "crop": [1290, 620, 800, 380],
     "step": "01", "title": "提需求",
     "cap": ["先当甲方：说清要什么", "原生小程序 · 不联网"],
     "voice": "先把它当甲方：建个目录，做一个决策记录器。"}
  ]
}
```

| 字段 | 说明 |
|---|---|
| `out_name` | 成片名前缀，最终文件 `<out_name>-<时长>s-1080x1920.mp4` |
| `brand` / `episode` | 左上角品牌行与右上角集数 |
| `min_dur` | 单拍最短时长，默认 4.3s |
| `max_speed` | 素材快进上限，默认 2.6× |
| `fonts` | 必须是本机存在的字体文件；Windows 用 `C:/Windows/Fonts/msyhbd.ttc` |
| `voice.enabled` | `false` 时不调用在线 TTS，按 `dur` 或 `min_dur` 定长 |
| `beats[].name` | 唯一；同时是分段文件名 |
| `beats[].src` | 录屏绝对路径；正斜杠或双反斜杠 |
| `beats[].t_in` / `t_out` | 素材时间窗，秒；`t_out > t_in` |
| `beats[].crop` | `[宽, 高, x, y]`，**原分辨率**坐标系，脚本会校验越界 |
| `beats[].step` / `title` | 顶部大号步骤号 + 标题 |
| `beats[].cap` | 字幕，1–2 行，每行 ≤17 字（超了会警告） |
| `beats[].voice` | 配音词，可比字幕长；启用配音时据此定时长 |
| `beats[].dur` | 可选：关掉配音时手动指定时长 |

时长规则：`dur = max(min_dur, 配音时长 + 0.55)`；素材窗口比 `dur` 长就加速（不超过 `max_speed`），短了自动挂尾帧补齐。
