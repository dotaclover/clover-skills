# 中文首选音色

以下四个实际voice名称作为中文音色候选，按语言、口音与用户试听偏好选择，可被用户指定音色覆盖，不代表任何用户的固定偏好或客观最优。配置必须使用完整voice名称，不使用试听页临时编号。

|语言|性别|voice|
|---|---|---|
|粤语，中国香港|女|zh-HK-HiuMaanNeural|
|粤语，中国香港|男|zh-HK-WanLungNeural|
|普通话，中国台湾口音|女|zh-TW-HsiaoChenNeural|
|普通话，中国台湾口音|男|zh-TW-YunJheNeural|

## 选择规则

- 仅在用户要求在线配音且完成网络授权后应用，不改变默认original原音模式。
- 明确指定音色时遵循用户选择；明确语言和性别时可从表格候选中试听确认。
- 未指定性别时先确认偏好；脚本缺省为zh-TW-HsiaoChenNeural，可用voice覆盖，不把实现默认当作用户已选择。
- 需要粤语配音时确认口音与候选并显式写入voice；脚本不会根据文本自动检测语言。
- 需要大陆普通话口音时另选并试听，不能把zh-TW-HsiaoChenNeural或zh-TW-YunJheNeural标成大陆口音。
- 粤语使用自然口语文案，例如“撳、揀、搵、唔使、嘅”；仅换音色而保留书面普通话措辞可能不自然。字幕是否使用口语或书面语另行确认，不自动篡改原意。
- 默认rate为+0%，按用户要求调整。在线voice为全局选项；不同片段多角色先分别生成录音，再使用voice_file。
- 声音可能随服务变化失效，报错时实时查询并征求替代选择，不静默切换。

## 配置片段

只将voice/rate合并到完整配置，不添加脚本不支持的language或gender字段。

```json
{"voice":"zh-HK-HiuMaanNeural","rate":"+0%"}
```

```json
{"voice":"zh-HK-WanLungNeural","rate":"+0%"}
```

```json

```

