# 发布前违禁词体检

词表仅为语义风险线索，不是官方判罚表。核对上下文、事实、资质及官方现行规则；未联网标“未核实”，不得标已核实。替换必须有真实证据，不能用个人体验包装无证功效，也不能保证过审。Logo、肖像、作品须判断权利依据和授权范围，不因出现就一律侵权。

> ⚠️ 自检清单里的"无功效承诺、无极限词"是**软自审**，不能代替这一步。
> 一条视频拍得再好，卡在审核就是零。

## 八类高危

| 类别 | 典型命中 |
|---|---|
| **功效承诺** | 根治、治愈、7 天见效、瘦 X 斤、包过、一次搞定 |
| **医疗用语** | 消炎、杀菌、治疗、处方、症状、疗效 |
| **极限词** | 最、第一、100%、永久、唯一、顶级、全网最低 |
| **诱导互动**（抖音高频） | 点赞过 X 更新、评论区扣 1、关注才发、不关注看不到 |
| **收益承诺** | 稳赚、保本、月入 X 万、躺赚、零风险 |
| **导流信息** | 微信号、加 V、站外二维码、其他平台水印 |
| **擦边引流**（**涉未成年零容忍**） | 小孩别看、未成年别看、不适合小孩、太刺激了、别在公共场合看、把"年龄门槛"当卖点 |
| **标签与内容不符** | 画面是豆包却挂即梦/可灵；挂 #教程 全片没步骤；挂 #免费 实际要付费 |

> 诱导互动、误导性标签与不适当引流均须检查语义和场景。处置由现行规则与具体审核决定，不给出命中即下架、禁言或降权的断言，也不对违规频率排名。

## 替换对照表

表中第一人称仅可用于用户确实提供的亲历；无亲历改用有来源的客观描述或删掉。清单“已置顶／已发布／已放收藏夹”等仅在实际完成且可核对时使用，否则写“可制作清单（待完成）”。不得为替词编造体验或发布状态。

| 违禁 | 安全改法 |
|---|---|
| 根治 / 治愈 | 缓解 / 我自己的情况改善了 |
| 7 天见效 | 我自己试到第【X】天开始有感觉 |
| 最 / 第一 | 我个人用下来最顺手的 / 少见的 |
| 100% 有效 | 大部分情况 / 我遇到的几次都 |
| 月入 X 万 | 收入结构我是这么搭的（不给具体数） |
| 点赞过 X 更新 | 想看下一期的话评论区告诉我 |
| 关注才发 / 不关注看不到 | 下一条讲 {X}，想看可以关注一下 |
| 加微信 / 私信领取 | 完整清单我放评论区置顶了 |
| 永久 / 终身 | 很长一段时间 / 至今 |
| 小孩别看 / 未成年别看 / 太刺激了 | 直接说清教会你什么：**只需要六步，你也能做出…**（数字要与画面节点数一致） |
| 评论区扣 1 发你 | 完整清单我放评论区置顶了（不要求任何交换动作） |

> 替换的原则是**改成体验描述**，不是换个同义词继续吹。
> 擦边钩子的替换方向是**把卖点从"禁忌感"换回"能力感"**：不暗示"你不能看"，直接说"你也能做"。敢说清步骤，比藏着掖着更抓人。

## 中性演示：语义检查不止词库

以下为虚构的剪辑教学演示，不是实际账号处罚案例：

| 问题 | 检查方向 | 改法 |
|---|---|---|
| 标题只写“你绝对想不到” | 是否隐瞒内容主题 | 写清“演示三步剪辑方法”，步骤数与正文一致 |
| 标签写工具A，画面实际演示工具B | 标签是否误导 | 仅使用实际相关标签 |
| 评论后才发基础步骤 | 是否用利益换互动 | 直接公开基础步骤，讨论不附交换条件 |

不得推测这类文案必然受到何种处罚。检查标题承诺、标签与画面是否相符，并依据现行规则核实疑点。

## 体检范围：五个地方全查

| 位置 | 常见遗漏 |
|---|---|
| **标题** | 极限词、夸张前缀、擦边钩子 |
| **口播稿** | 功效承诺、收益承诺、诱导互动 |
| **字幕** | **最容易漏**——字幕里的极限词同样会被判定 |
| **封面文案** | 主文案里的极限词与功效词 |
| **标签 / 结尾钩子 / 置顶评论** | 挂竞品标签、扣 1 换资料、关注才发 |

只查口播稿是最大的漏：**字幕和封面文案一样会被判定。**
标签与结尾同样需要审核：核对标签和内容相关、互动不附不当交换条件，不推断算法分发对象。

---

## 体检流程

1. 上面五个位置各过一遍八类高危。
2. 命中就**给替换建议**，并输出**按事实与语义修订的建议稿（不保证过审）**（不要让用户在原文里自己找）。
3. 标出命中位置：`标题` / `口播第 X 段` / `字幕镜 N` / `封面主文案`。
4. 没命中就明说"未命中八类高危"，不要含糊带过。

---

## 两条提醒

- **词库会更新。** 不确定某个词当前是否敏感 → 联网核实，不凭记忆判断。宁可改掉也不赌。
- **变体规避无效。** 不得以谐音、拆字或符号替代规避规则；是否识别与处置不作预测。

## 画面合规（视频特有）

除了文字，画面本身也会触发审核：

- 品牌 Logo、明星脸、他人作品入镜。
- 可识别的车牌、门牌、他人肖像。
- 血腥、密集恐惧、猎奇恶心、惊悚画面。
- 未获授权的音乐与素材。
- 诱导性质的二维码与联系方式露出。

展开分镜时一并检查。
