# beats.json 字段

一个文件描述一整条片。`scripts/build_video.py --beats beats.json`。

```json
{
  "tag": "小程序开发·EP02",
  "ep": "02",
  "hold": {"b01": 1.6},
  "beats": [ ... ]
}
```

- `tag`：右上角角标
- `ep`：集号，决定输出 `build/ep02.mp4`
- `hold`：拍名 → 额外停留秒数，也可以写在单拍的 `hold` 里

## 单拍公共字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 唯一标识，也用于缓存与中间文件命名 |
| `kind` | 是 | `video` / `img` / `text` / `promo` |
| `step` | 是 | 步骤号，如 `01`；可为空串 |
| `chapter` | 是 | 章节名，如 `改界面` |
| `title` | 是 | 这一拍的观点，58px 大字 |
| `cap` | 是 | 两行结论字幕，每行 ≤14 字 |
| `voice` | 是 | 旁白全文，也是底部口播字幕的来源 |
| `hold` | 否 | 本拍额外停留秒数 |

## kind=video

```json
{
  "kind": "video",
  "src": "assets/realdevice.mp4",
  "t_in": 0.0,
  "t_out": 11.0,
  "vcrop": [120, 60, 360, 450]
}
```

- `t_in` / `t_out`：素材窗口，秒
- `vcrop`：`[x, y, w, h]`，**宽高比必须 0.8**（4:5 铺满）；不给则整帧等比缩进 + 黑边

## kind=img

```json
{
  "kind": "img",
  "crop": ["assets/chat.png", 0, 1700, 1119, 1050]
}
```

- `crop`：`[图片路径, x, y, w, h]`，任意比例，等比缩进 960×1200 后黑底居中
- 同一张长图切成多拍时，只改 `y`，拍与拍首尾相接

## kind=text

```json
{
  "kind": "text",
  "panel": ["界面改了三遍", "代码只写一遍", "顺哥 · 下个视频见"]
}
```

前两行 80px 粗体白，第三行 46px 绿色，居中。

## kind=promo

```json
{
  "kind": "promo",
  "promo_kind": "gitee",
  "promo_url": "gitee.com/clover/trae-decision-recorder",
  "promo_shot": "assets/repo.png",
  "promo_box": [1490, 120, 380, 90]
}
```

推广卡：合成一张 960×1200 的图（标题 + 截图 + 高亮框 + 一句话），再按 `img` 播放。
`promo_box` 是要用绿框圈出来的区域，给 Star / Fork 这类按钮用。

## 素材路径

相对 `beats.json` 所在目录解析；绝对路径照用。
