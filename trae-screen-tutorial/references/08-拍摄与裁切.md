# 真机演示：录制规范与裁切配方

短教程的说服力全在「真机演示」。这一页只讲两件事：**怎么录干净**、**怎么裁掉不该出现的栏**。

## 一、录前把环境弄干净

- **目标窗口先置前**，再开始操作，否则点击会落到别的窗口（尤其 IDE 同时开着「聊天窗」和「项目窗」时）。
  PowerShell 置前（windowId 即 HWND）：
  ```powershell
  Add-Type @"
  using System; using System.Runtime.InteropServices;
  public class Win {
    [DllImport("user32.dll")] public static extern IntPtr GetForegroundWindow();
    [DllImport("user32.dll")] public static extern uint GetWindowThreadProcessId(IntPtr h, out uint p);
    [DllImport("user32.dll")] public static extern bool AttachThreadInput(uint a, uint b, bool f);
    [DllImport("user32.dll")] public static extern bool SetForegroundWindow(IntPtr h);
    [DllImport("user32.dll")] public static extern bool ShowWindow(IntPtr h, int n);
    [DllImport("kernel32.dll")] public static extern uint GetCurrentThreadId();
  }
  "@
  $h=[IntPtr]窗口句柄
  $fg=[Win]::GetForegroundWindow(); $tf=[Win]::GetWindowThreadProcessId($fg,[ref]$null); $tm=[Win]::GetCurrentThreadId()
  [Win]::AttachThreadInput($tm,$tf,$true)|Out-Null; [Win]::ShowWindow($h,3)|Out-Null; [Win]::SetForegroundWindow($h)|Out-Null
  [Win]::AttachThreadInput($tm,$tf,$false)|Out-Null
  ```

- **网页预览用 app 模式**，天然没有标签栏/地址栏：
  ```powershell
  Start-Process "C:\Program Files\Google\Chrome\Application\chrome.exe" `
    -ArgumentList '--app=file:///C:/Users/clove/Desktop/codextemp/traecourses/hello.html'
  ```
- **不要右键**：右键菜单会一直挂在文件树上，整段作废。要选文件就单击/双击。
- **别用带私人标签的浏览器窗口**（会露 OpenAI/chatgpt/API 等隐私），一律用 app 模式新窗口。
- **别悬停出路径气泡**：鼠标移开文件树即可。

## 二、裁掉状态栏 / 浏览器标准栏

录屏常见尺寸 1840×1152（含底部 Windows 任务栏）。目标：去掉**底部任务栏**、**顶部浏览器标题栏**。

```bash
ffmpeg -y -ss 290 -t 10 -i 录屏.mp4 \
  -vf "crop=1840:1020:0:66,scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,setsar=1" \
  -r 30 -c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p build/demo_ep01.mp4
```

参数含义：
- `crop=1840:1020:0:66`：从 y=66 开始（跳过顶部标题栏），高度 1020（底部到 1086，避开 1094 起的任务栏）。
- `scale=1920:1080:...,crop=1920:1080`：等比铺满 16:9，四边多余裁掉。
- `setsar=1`：统一像素比，否则多段 `concat` 会报 SAR mismatch。

多段拼接时每段都要 `setsar=1`，且尺寸一致：
```bash
ffmpeg -y -ss 170 -t 6 -i 录屏.mp4 -ss 292 -t 6 -i 录屏.mp4 -filter_complex \
"[0:v]crop=1840:1086:0:0,scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,setsar=1,setpts=PTS-STARTPTS[a];\
 [1:v]crop=1840:1020:0:66,scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,setsar=1,setpts=PTS-STARTPTS[b];\
 [a][b]concat=n=2:v=1:a=0[v]" -map "[v]" -r 30 -c:v libx264 -crf 18 -pix_fmt yuv420p build/demo_ep01.mp4
```

## 三、自查

- 抽首帧/中帧/尾帧，确认：无任务栏、无浏览器标签/地址栏、无右键菜单、无私人标签。
- 演示里能看到鼠标操作与画面变化，而不是一张静止结果页。
- 若整段被污染（菜单/隐私），宁可重录，不要硬剪。
