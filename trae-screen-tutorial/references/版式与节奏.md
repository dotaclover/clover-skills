# 版式与节奏

画布固定 1080×1920（9:16），30fps。所有坐标写死在 `scripts/build_tutorial.py`，改版式改那一处。

## 版面

| 区域 | 位置 | 内容 |
|---|---|---|
| 品牌行 | y=58 | 左侧绿点 + 品牌名；右侧集数 |
| 步骤号 | y=108，112px 粗体，强调色 | `01`–`09` |
| 步骤标题 | y=148，58px 粗体 | 提需求 / 拆任务 / 出原型 |
| 分隔线 | y=292 | 2px |
| 画面面板 | x=60 y=326 960×980 | 2px 描边；不足比例时同片段模糊铺底 |
| 进度点 | y=1342 | 每拍一个，当前高亮 |
| 字幕 | y=1396 起 | 54px 粗体主行 + 灰色副行，行高 78 |
| 底部留白 | y=1620–1920 | 留给平台 UI（点赞/评论/文案） |

字幕最多两行；每行 ≤17 字。第三行开始会压到底部安全区。主行写结论，副行写细节或数字。

## 节奏

- 总长 **45–70 秒**，**9–11 拍**；单拍 4.3–6.5 秒。
- 拍与拍之间硬切，不加转场；竖屏教程转场只会拖慢节奏。
- 静态画面用 `setpts` 2–2.6× 快进制造「在动」的观感，末尾挂尾帧等配音说完。
- 片头 3.6–5.6 秒（3 行大字 + 一行副标），片尾 3.6–5.6 秒（结论 + 2–3 张文件卡）。
- 拍数宁少勿多：一个画面撑不到 4 秒就合并或删掉，别用 2 秒的闪屏凑节奏。

## 视觉

- 背景 `#090D12 → #111821` 竖向渐变 + 48px 点阵（透明度 6%）。
- 强调色 `#12E39B`（只用在步骤号、进度点、字幕竖条、高亮标题）。
- 面板外有 18px 高斯阴影；画面与面板之间留 4px 内边距。
- 模糊铺底：同片段放大铺满 → 30px 模糊 → 乘 0.26/0.28/0.34 压暗（白底文档也能压成中性底），避免黑边割裂。

## 文案

- 标题 2–4 字动宾结构（提需求 / 砍范围 / 出原型），不要写「第一步」「Part 2」。
- 字幕是给"不戴耳机的人"看的：每条独立成句，能只看字幕串起整条逻辑。
- 旁白可以比字幕长，但不要念标题。
