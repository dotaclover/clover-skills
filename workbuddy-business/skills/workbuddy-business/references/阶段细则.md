# 阶段细则（阶段 1–6：找项目）

> 本文件只覆盖**阶段 1–6**。阶段 7 起在另外三个文件：
> `市场分析.md`（7）、`开办与运营.md`（8–10）、`创业计划书.md`（11）。
> 前置的判断标准在 `理论层.md`，跑之前先读它。

流程顺序：定位扫描 → 生成 10 个方向 → 筛出 3 个 → 六维对比选出 1 个 → SWOT 体检 → 业务画布 → 客户细分。

---

## 阶段 1｜定位扫描与候选生成

### 输入获取（图片可选）

**若用户提供图片**：从图片中提取以下字段，提取后向用户复述确认。

**若用户未提供图片**：直接提问补齐，每次最多问两个。

必填字段：

```
□ 硬技能（能教别人、能收费的那种）
□ 从业经历（做过什么、做过多久）
□ 兴趣（愿意长期做不腻的）
□ 可调用资源（场地 / 人脉 / 货源 / 设备 / 家人能帮忙 / 资金）
□ 所在城市与具体区域（关系到本地需求，必须问）
□ 可投入启动资金
□ 每周可投入时间
```

> ⚠️ **城市这一项不能省。** 不做本地需求分析，后面所有"周边有多少人"都是空的。

### 定位四象限表

| 象限 | 含义 | 填写内容 |
|---|---|---|
| **我会做** | 具备的技能能力 | |
| **我能做** | 有资源支撑的（即使不擅长） | |
| **我想做** | 有兴趣有热情的 | |
| **我做不了** | 明确排除的（资金/资质/体力/意愿） | |

> 第四象限很重要——**提前排除能显著减少后面生成无效方向。**

### 生成 10 个方向

分「服务类」「产品类」两栏，**每类至少 4 个**。

每个方向必须包含：

1. 方向名称（一句话说清卖什么、卖给谁）
2. **结合用户实际情况的理由**（引用上文字段，不能写"市场前景好"这种通用话）
3. 起步所需的资源（用用户已有的打勾，缺的列出来）

❌ 反例："可以做自媒体，因为现在自媒体很火。"
✅ 正例："可以做本地装修避坑短视频——你有 8 年装修工长经验，手上有真实施工对比图，
且不需要额外设备和进货。"

## 阶段 2｜筛出三个

### 评估权重（按顺序，不是平均）

```
1. 资源可及性    能否用上已有资源        ← 权重最高
2. 个人匹配度    兴趣和能力是否契合      ← 权重次高
3. 市场需求度    是否真有人需要
4. 起步门槛      能否低成本少设备启动
```

> 权重顺序不要平均打分。资源可及性权重最高是对的——
> 创业者最常见的失败不是方向错，是启动资源跟不上。

### 输出要求

**入选 3 个**：每个 1–2 句理由，必须同时扣到「资源 + 个人 + 需求」三点。

**淘汰 7 个**：归类总结即可，不要逐条长篇。按淘汰原因分组，例如：

```
淘汰原因归类：
· 资源不匹配（3个）：XX / XX / XX —— 都需要 XX 资源，当前不具备
· 个人匹配低（2个）：XX / XX —— 与用户技能经验无交集
· 起步门槛过高（2个）：XX / XX —— 需资质许可 / 需压货资金
```

### ★ 落选项目存档（差异点）

被淘汰的 7 个必须逐条写入落选存档，字段：

```
方向名称 | 淘汰原因 | 淘汰时的假设 | 什么条件下可以重启
```

最后一项是关键：**写下"什么条件下可以重启"**。
三个月后情况变了（拿到某个资质、多了合伙人、资金到位），这个存档立刻变回候选池。

## 阶段 3｜六维对比与算账，选出优胜项目

### 六维对比表（逐列填写，不允许空着说"不详"就算完）

| 维度 | 要回答的问题 |
|---|---|
| **1 需求真实性** | 解决谁的什么问题？**是痛点还是痒点**？这类人规模多少（**需检索，查不到标【未核实】**） |
| **2 竞争/替代** | 已经有人在做吗？他们的优劣势？如果没有，是没人想到还是需求不存在 |
| **3 我的独特优势** | 为什么由我来做更有优势？货源 / 技能 / 人缘 / 位置，写明来源 |
| **4 情绪价值潜力** | 能让客户感觉更好吗？可以设计哪些有人情味的细节？ |
| **5 资产价值积累** | 做完一单算一单，还是能积累回头客？能不能做成招牌后衍生别的业务？ |
| **6 风险与瓶颈** | 最大困难是什么（资质 / 压货 / 守店 / 体力）？现有资源能否克服？ |

> **维度 1 的"痛点 vs 痒点"判断是本阶段核心。**
> 不解决很难受 = 痛点；有了更好 = 痒点。痒点生意不是不能做，但获客成本高、复购低，
> 必须在结论里明确说出来。

> **维度 5 是最有价值的一维**（教材里没有）。
> 能积累的生意和不能积累的生意，三年后是两个世界。

### ★ 成本粗算（三选一的依据，不是实施内容）

```
售价
 − 进货成本
 − 平台佣金        （经验参考区间 2%–5%，需自行核实实际类目费率）
 − 推广预留        （经验参考区间 20%–30%）
 − 物流包装
 − 退货损耗        （经验参考区间 5%–10%）
 = 毛利
```

**毛利率低于 40% 必须明确提示风险**，并算出盈亏平衡所需月销量。

> 所有百分比写成"行业经验参考值，需自行核实"，不要写成平台事实。

**这组算式可以手算，但必须把过程写在档案里**（每步基数、单位、口径）。多档情景或反复调整参数时，跑脚本更省事：

```bash
python scripts/calc_unit_economics.py --price 199 --cogs 70 --commission 5 \
  --payment 0.6 --shipping 8 --return-rate 8 --ads-pct 20 \
  --fixed 12000 --volume 200 --level L3
```

脚本输出成本结构表、毛利率、盈亏平衡销量、安全边际、三档情景，并生成可粘贴进
`03_六维对比与测算.md` 与 `98_证据台账.md` 的片段。**它是加速器，不是必需品**——
判断权在用户手上，所以不管手算还是脚本，都要给出能复核的输入与中间值。

脚本里几个口径要记住（和上面的公式一一对应）：

| 参数 | 含义 | 说明 |
|---|---|---|
| `--cogs` | 进货/生产成本 | 变动成本，不含运费 |
| `--commission` | 平台佣金率 % | 按售价计，不是按成本 |
| `--payment` | 支付手续费率 % | 默认 0.6 |
| `--shipping` | 物流 + 包装 | 每单固定；退货损耗按 2 倍计往返 |
| `--return-rate` | 退货率 % | 损失 = 退货率 × (2×运费 + 10% 货损) |
| `--ads-pct` | 推广费占售价比 % | 与 `--ads-fixed` 相加 |
| `--fixed` | 月固定成本 | 房租、人工、软件等 |
| `--volume` | 预计月销量 | 用来算净利与安全边际 |
| `--level` | 输入取证级别 | L1→9 分、L2→8、L3→6、L4→5、L5→3 |

> **`--level L5` 就不要跑了。** 输入全是拍脑袋的话，算得再精确也只是把假设乘了一遍。

### ★ 情景测算

| 情景 | 结果 |
|---|---|
| 基准 | |
| 客流 −30% | |
| 成本 +20% | |
| 两者同时发生 | |

**这一块是市面上所有 AI 商业工具的公认空白**——
它们都帮你把想法写漂亮，没有一个帮你算"客流掉三成还活不活得下去"。

### 结论（本阶段必须收口）

给出明确建议：**选定哪一个**，判断依据是什么。
**必须写明这个结论的脆弱点在哪**（依赖哪个假设，假设不成立时排序会怎样变化）。

> 不能停在"各有优劣，请你自行判断"。必须给结论，同时说清结论的脆弱点——
> 这两件事不矛盾。

**附带输出四问一句话**（因为用户可能在此停下）：
销售什么 / 向谁销售 / 如何销售 / 满足什么需要，各一句。
作用是让选出的项目成为"成型的想法"而非"行业名词"。展开细节是阶段 5 的事。

## 阶段 4｜优胜项目 SWOT 体检 ★

### 为什么单独设这一步

**六维对比是横向比较三个候选（选哪个）；SWOT 是纵向审视当选的那个（它行不行）。**

老师流程里没有 SWOT，但它是教材「分析你的企业想法」一节的经典工具。
补在**选出项目之后、做画布之前**最合理——先确认这个当选者站得住，再投入精力细化它。

> 如果放在阶段 3 之前，就会变成"对三个候选各做一次 SWOT"，
> 输出量翻三倍且必然退化成四个框各写两句废话。**顺序错了，这一步就白做。**

### 四个象限

| 象限 | 问什么 |
|---|---|
| **S 优势** | 为什么由我来做更有利？（内部、正面） |
| **W 劣势** | 我缺什么？（内部、负面） |
| **O 机会** | 外部环境有什么可以借的？（外部、正面） |
| **T 威胁** | 外部环境有什么会打击我？（外部、负面） |

### ★ 四条防退化规则（这一步的全部价值所在）

**规则 1：禁止写放之四海皆准的话**

```
❌ "市场竞争激烈"      ❌ "需要不断学习"
❌ "服务质量要抓好"    ❌ "要重视营销"
✅ 必须具体到这个项目、这个人、这个地方
```

判断方法：**把这句话换到另一个完全不同的项目上，如果照样成立，就是废话，删掉重写。**

**规则 2：优势必须写明来源（四选一）**

```
技能优势 / 资源优势 / 位置优势 / 人缘优势

❌ "我比较懂行"
✅ "8 年装修工长经验，能看懂施工报价里的水分（技能优势）"
```

**规则 3：劣势和威胁必须配缓解动作**

```
只有劣势没有应对办法的条目，不算完成。

格式：劣势/威胁 → 缓解动作 → 缓解不了则触发什么后果

示例：
W 没有现成客户 → 缓解：先免费给 3 家做，换案例和转介绍
              → 缓解不了：三个月零复购则停止投入
T 旺季被大店挤压 → 缓解：避开旺季，主打淡季和急单
                → 缓解不了：客源集中在大店时退出
```

> 这条是本阶段的核心。**没有缓解动作的 SWOT 只是自我安慰。**

**规则 4：机会必须写明触发条件**

```
❌ "可以拓展线上渠道"
✅ "若三个月内复购率超过 30%，可启动线上渠道（复购验证了口碑，此时获客成本才扛得住）"
```

### 体检结论（三选一，必须明确）

| 结论 | 后续动作 |
|---|---|
| **通过** | 进入阶段 5 业务画布 |
| **有条件通过** | 写明必须先解决什么，解决后再进入阶段 5 |
| **不通过** | **回到阶段 3，从三强里换一个重新体检**（此时落选存档派上用场） |

> ⚠️ **"不通过"是合法结论，不要为了流程顺畅而放水。**
> 一个在 SWOT 阶段就被否掉的项目，代价远小于做三个月后发现不行。

## 阶段 5｜业务画布

四问表格，**每格必须绑定用户前面提供的实际信息**：

| 问题 | 填写要求 |
|---|---|
| **销售什么** | 具体产品/服务名称、品类、卖点特点；结合个人技能与本地资源能设计什么独特组合 |
| **向谁销售** | 最可能买单的人群（年龄/身份/特征）；消费习惯（图便宜 / 看重品质 / 图方便 / 认熟人） |
| **如何销售** | 在哪里卖（平台/线下点位）；怎么让人知道（内容形式）；交易如何完成 |
| **满足什么需要** | 解决什么问题；省时间 / 省钱 / 省麻烦 / 安心 / 开心 / 被关心；情绪价值在哪 |

❌ 反例："目标客户：25–45 岁女性。"
✅ 正例："目标客户：本小区及周边两个小区里，孩子在上小学、双职工、平时由老人接送的妈妈——
她们晚上 8 点后才有时间刷手机，认熟人不认品牌。"

> 阶段 3 已经写过四问一句话，本阶段是**把它展开成可执行的业务描述**，不是重复。

## 阶段 6｜客户细分

### 四维度推荐

从基本属性、地理位置、购买心理、使用场景各推荐 1–2 个指标。
**与项目关系不大的维度直接说明不适用**，不要硬凑。

输出表格：

```
维度 | 建议的细分指标 | 具体可以怎么分 | 为什么值得这样分
```

### 三条选择原则

1. **不机械套用年龄性别收入**——除非它们确实影响购买选择
2. **客户范围已明确就继续向内细分**（如已定"卖给大学生"，就分大学生的学习动机差异）
3. **优先选能体现需求差异、影响购买选择的指标**

### 收尾

推荐最有用的 2–3 个指标，并说明：
- 主要按哪个指标划分客户
- 其他指标怎样辅助描述这些客户

> 本阶段**先只给指标建议**，等用户选定后再生成具体客户分类。

```
存在 → 读 _进度.md → 询问"上次做到第 X 阶段，要继续吗？"
不存在 → 从阶段 1 开始
```

```
当前阶段：4 / 11
已完成：阶段1 ✓  阶段2 ✓  阶段3 ✓
下一步：优胜项目 SWOT 体检
最后更新：YYYY-MM-DD
```

> 旧档案里写成 "X / 6" 的，按原编号继续，新阶段接在 6 之后，不要重置进度。
