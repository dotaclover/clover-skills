# 手动挡：不用任何工具，自己复核

没有浏览器扩展、没有 Python，或者用户说「我自己查」时用这套。它不会过时，换个 AI 产品、换十年照样适用。

## 五步法

1. **点评搜「品类 + 商圈」**，按评分或评论数排序。**只看最近 3 个月**的评价，重点读差评——差评暴露的是稳定性，好评只能证明它不差。

2. **进商户页抄四项**：门牌地址、人均、营业时间、招牌菜列表。四项齐全才值得跑一趟；缺一项就标「未确认」，别用猜测补。

3. **地图二次确认**：搜店名看是否标「营业中」、有没有「暂停营业」、有没有电话。直接打过去问「现在开吗、目标菜还有吗」最省事。

4. **到店三看**：有没有明档现炒、菜单上目标菜是否在前几页、店里本地中老年客比例。三条都中，基本不踩雷。

5. **避开饭点验证**：14:00–17:00 去，能看出真实人流，也能问出师傅休息时间（很多店午市后不炒锅）。

## 判断「这家是不是真的」

| 可疑信号 | 说明 |
|---|---|
| 地址只有「XX 大街一带」 | 没有门牌，可能是记错或编的 |
| 搜到的店在其他区/其他城市 | 同名异地，最常见的幻觉 |
| 招牌菜是另一道菜 | 店是真的，但被硬安上「XX 首选」 |
| 点评日期超过 2 年 | 价格和营业时间基本失效 |
| 标题带「N 个维度拆解 + FAQ」 | AI 批量生成的 SEO 稿，不是探店实测 |

## 三句可以直接问店员的话

- 「你们家 XX 是招牌吗？」——验证招牌归属，比看点评快
- 「师傅几点休息？」——避开门没关但炒锅已停的时段
- 「现在还要排队吗？」——电话里能问出来，省一趟跑空
