# 成品上线执行

读取当前project brief、合同政策与验收清单；价格、范围、窗口和售后由本项目提供，缺项询问。定位是部署已就绪产物，不默认包含代码修复、构建工程改造或搜索优化。

## 定项与准入

| 类型 | 核实内容 |
|---|---|
| 静态站 | HTML/CSS/JS产物、入口、资源路径、子目录兼容 |
| 动态站 | 运行时、数据库、迁移方式、配置与秘密管理、后台和写入目录 |
| 新环境 | 是否另授权建站、数据库、服务、DNS与证书，成本由用户确认 |
| 需先修复 | 说明缺文件、构建失败、应用报错等阻塞，另确认修复范围 |

只有截图或预览链接时先索取产物。报价/工作量评估前先看产物与目标，不以内置档位推定能力或费用。

## 执行七步

1. 收产物并记录版本/校验值、文件清单与授权；确认目标环境和域名。
2. 本地或隔离环境预演，逐页查看资源、导航、控制台；移动端与其他指定浏览器按本单清单验证，不擅自排除体验缺陷。
3. 明确实际命令、作用范围、变更窗口及禁止事项，取得发布授权。
4. 备份目标文件、配置和数据库并验证恢复；新位置记录初始状态。
5. 更新已有站点走 `ops-deploy` 流程A/B；新建面板站点走 `ops-btpanel` 的支持界面/API，不直接写内部数据库。属主由现场运行用户和权限模型确定，不覆盖现有密钥配置。
6. 按面板/证书工具当前支持流程申请与部署，核对域名、完整链、到期日和续期执行证据，不假定任务已存在。真实重签另确认。
7. 正式域名验证状态码、内容、导航、资源、HTTPS和授权交互；记录新增问题与原有问题，按 `references/launch-record.md` 交付。

## 停手条件

- 缺文件、白屏、构建失败或需改源码：先给出诊断，不顺手修。
- 新增数据库、支付回调、迁移、设计或文案：核对是否在授权范围，超范围另确认。
- 明文密钥、数据库密码或可疑后门：停止发布，告知并保护证据；整改另授权，不将不安全产物照常上线。
- 无可用备份、目标不明、生产写入冲突：暂停，不冒险覆盖。

## 账号、验收与售后

用户持有主机、域名与平台账号，最小临时协作者权限；付费单独批准。正式域名可达、页面与资源无新增错误、证书正确、回滚可执行才可按清单验收；未验证项注明原因，不用本地结果顶替。

售后期限、响应时效和原站缺陷处理按合同，不内置天数或SLA。不承诺DNS生效时间、收录、排名或业务效果。输出部署前后差异、备份/恢复证据、证书与续期状态、待办及权限撤销结果。
