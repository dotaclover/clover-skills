# 性能、本地化与安全加固检查

为每项记录当前实现、是否适用、副作用、验证和恢复方式。`opc-slim`/`opc-harden`仅为可选实现名称；工具与文件路径从当前工作区核实，不依赖固定仓库。所有写入测试优先隔离副本，生产测试另行授权。

## 性能

| 项 | 核对与副作用 | 验证 |
|---|---|---|
| head标签/emoji/oEmbed | 先确认业务依赖，不为精简盲删功能 | 源码及嵌入/评论回归 |
| 心跳 | 调整影响锁定与自动保存 | 多编辑器场景核对保存和请求 |
| 缓存 | 匿名公开页与会话/表单/后台分开，不固化TTL | 响应头、实际内容刷新和用户数据隔离 |
| 维护模式 | 上线策略与访问权限按项目约定 | 匿名、管理员分别访问 |
| 调试输出 | 生产不得暴露路径、SQL或秘密 | 页面、响应头和日志权限 |
| 资源加载 | 不破坏业务插件依赖，不盲目合并/延迟 | 表单、导航、控制台、首屏 |

## 本地化

按实际服务区域、语言和网络需求选择字体、头像、时区、文件名与slug策略；外部镜像需许可、隐私和可用性核实，不默认接入。适用的站点声明由用户提供真实内容与要求，核对主体、显示和链接，不编造资质或将示例政策视为普遍法律结论。

## 安全

| 项 | 副作用/条件 | 验证 |
|---|---|---|
| XML-RPC | 可能影响移动端与第三方发布 | 核对实际集成再限制 |
| REST和作者信息 | 区块编辑器需要授权端点 | 匿名与授权用户分别检查 |
| 安全头/CSP | 可能影响资源、嵌入、统计 | 按浏览器与功能清单回归 |
| 后台文件编辑 | 不替代文件权限和账号授权 | 菜单、能力与直接入口 |
| 登录限速 | 共享IP、可信代理、恢复通道 | 授权副本按实际阈值验证，不在生产默认连续输错密码 |
| 登录错误信息 | 避免账号枚举同时保留恢复路径 | 用户名/密码错误提示与找回流程 |
| 更新策略 | 不应锁死安全更新 | 兼容测试、窗口、手动/自动策略及恢复 |
| 日志/临时数据 | 保留期关系排障与隐私 | 按项目政策核对，删除需批准 |

不要在`map_meta_cap`里调用`current_user_can()`造成递归；不要无差别移除REST端点。nonce不代替权限检查；输出转义、输入校验、SQL预处理和对象归属分别验证。

## 验证顺序

1. 对本次修改文件运行PHP语法检查。
2. 运行当前项目行为测试；如有WordPress替身测试，确认其覆盖钩子、权限、限速与恢复路径，而非仅看退出码。
3. 在隔离副本验证前后台业务、角色与配置，按`wp-admin`记录测试对象ID及清理结果。
4. 获准正式域名只读复核；生产写入或删除另授权。记录本次实际通过/失败/未验证，不将本地测试等同线上完成。

第三方安全/性能插件可评估，不默认禁用或安装；检查与现有规则冲突、维护状态、许可及性能。所有加固规则先副本验证，未授权不改文件权限、数据库前缀或生产安全策略。
