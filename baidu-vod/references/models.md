# 模型与验证

以下是 2026-10-12 的历史直连聊天记录，仅用于选择首次验证目标。模型可用性、名称和账号权限随时可能变化；每次接入都应使用当前 Key 做一次最小请求。

| VOD 类型 | 当时返回 HTTP 200 的候选模型 |
| --- | --- |
| 旧 VOD | `deepseek-v4-flash`、`deepseek-v4-pro`、`glm-5.2`、`glm-5.3`、`glm-5.3-flash`、`kimi-k3` |
| 新 VOD | 先从 `glm-5.3` 或当前供应商控制台所列模型开始验证 |

建议顺序：

1. 以短的非流式请求验证单个模型；记录模型、HTTP 状态和脱敏错误摘要。
2. 成功后再测试需要的 `stream: true`、工具调用或多模态字段。
3. 发生失败时，先确认地址、版本和 Key 是否匹配，再核对模型是否对当前账号开放。
