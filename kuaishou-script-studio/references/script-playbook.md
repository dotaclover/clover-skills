# 时间轴脚本与口播稿

## 通用硬规则

| 项 | 规则 |
|---|---|
| 时间轴 | 至少 **4 段**：钩子 → 展开 → 主体 → 结尾 |
| 语速 | 约 **4.5–5.5 字/秒**（比抖音慢，留说话的呼吸感） |
| 口播稿 | 可直接念，短句，全是口语 |
| 真实感 | A / B 型**不要过度剪辑**，保留过程的粗糙感 |
| 对话感 | 全篇至少 **2 处**直接对观众说话 |
| 人设 | 与既有设定一致，不跳风格 |

> 快手是信任经济：观众关注**这个人**。复看与关注转化比单条完播更值钱。

## 五套时间轴骨架

### A 实用技能（30–60s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 抛结果，或直接开始操作 |
| ② 说清用途 | 3–10s | 这个技能解决什么问题 |
| ③ 步骤主体 | 10–{N-15}s | 每一步一段，编号说出来 |
| ④ 提醒 | {N-15}s–{N-8}s | 容易出错的地方 |
| ⑤ CTA | 最后 8s | 引导关注或复看 |

### B 真实记录（30–90s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 进现场，不解释 |
| ② 背景 | 3–15s | 交代时间地点在干什么 |
| ③ 过程 | 15–{N-15}s | 真实推进，保留细节 |
| ④ 感受 | {N-15}s–{N-8}s | 说一句真心话（**信任来源**） |
| ⑤ CTA | 最后 8s | 引导评论 |

### C 人设故事（40–90s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 抛一句有个性的话 |
| ② 起因 | 3–20s | 为什么讲这个 |
| ③ 经历 | 20–{N-20}s | 按过程推进 |
| ④ 观点 | {N-20}s–{N-8}s | 我的看法是什么 |
| ⑤ 对话 + CTA | 最后 8s | 问老铁怎么看 |

### D 反转剧情（20–40s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 进冲突现场 |
| ② 铺垫 | 3–{N-8}s | 观众以为会怎样 |
| ③ **反转** | {N-8}s–{N-5}s | 结果相反 |
| ④ CTA | 最后 5s | 引导评论 |

### E 同城本地（20–45s）

| 段 | 时间 | 这一段干什么 |
|---|---|---|
| ① 钩子 | 0–3s | 抛本地元素（地名 / 方言 / 本地场景） |
| ② 本地信息 | 3–{N-15}s | 这件事跟本地人有什么关系 |
| ③ 你的角度 | {N-15}s–{N-8}s | 一个本地人才懂的点 |
| ④ CTA | 最后 8s | 引导同城评论 |

## 时间轴输出格式（默认交付就是这个）

| 时间段 | 这一段干什么 | 关键信息 |
|---|---|---|
| 0–3s | 钩子：抛结果 | {具体说什么} |
| 3–10s | 说清用途 | {…} |
| … | … | … |

**不要在这一步写分镜。** 时间轴是方向，分镜是第二遍。

## 口播稿规范

### 字数换算

`目标秒数 × 5 ≈ 口播字数`

| 时长 | 口播字数 |
|---|---|
| 20s | 约 100 字 |
| 30s | 约 150 字 |
| 45s | 约 225 字 |
| 60s | 约 300 字 |
| 90s | 约 450 字 |

### 写法

1. **短句**，一句不超过 20 字。
2. **口语 + 方言友好**：可以带地方说法，不要书面语。
3. 全篇至少 **2 处**直接对观众说话（"你们那儿是不是也这样"）。
4. 数字要说具体，但真实值留【】。
5. 整篇口播稿**可一次念完**，不写导演提示。

### 格式

```
【口播稿】约 XXX 字 / 预估 XX 秒

{正文}
```

---

## 真实感的三条写法

快手观众对"演"的容忍度最低。三条能显著提升信任感：

1. **保留不完美的过程**：失败一次、手忙脚乱、工具不顺手。
2. **说具体的数目和地名**：`【X】块钱，在【某地】买的`——比"很便宜"可信十倍。
3. **说一句真心话**：全篇至少一句不带目的的表达。

这三条都依赖真实值，**不要替用户编**。

---

## 字幕规范（展开分镜时才细写）

默认只给一句原则：**字幕上关键信息，不上全部口播**。
- 步骤编号、价格、地名、结果上字幕。
- 快手观众习惯听，字幕只是补充。

---

## 人设连续性检查

写完口播稿后自查：

1. 这条的口吻，跟账号过往内容是一个人吗？
2. 有没有哪句话不像他会说的？
3. 结尾的 CTA 是不是他一贯的方式？

任一为否 → 改到一致再交。**快手掉粉最快的方式就是人设跳变。**

---

## 自检细项（按形态查，不必每次全列）

- **A**：步骤编号说出来了？有易错提醒？
- **B**：保留了真实细节？有一句真心话？
- **C**：口吻与既有人员设定一致？有观点？结尾有对话？
- **D**：反转在最后 5 秒之前？铺垫够？
- **E**：本地元素够明确？跟本地人有关？
