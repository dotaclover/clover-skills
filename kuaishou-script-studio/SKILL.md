# 快手脚本工坊

四个模块：**选题 → 钩子（标题 + 前 3 秒）→ 时间轴脚本 + 口播稿 → 封面**，发布前过**违禁词体检**。

**三条底线**
- **零预设**：不含任何预设垂类、人群、话术，全部由当次输入或用户画像推断填充。
- **零编造**：数据、案例、时间地点、个人经历一律留【】占位。见 `references/truthfulness.md`。
- **零端着**：快手是信任经济，"端着说话"在这里没有观众。

> 本 Skill 自洽独立，不依赖任何外部技能或平台能力，可单独分发使用。

---

## 快手的三条平台铁律

| # | 规则 | 后果 |
|---|---|---|
| 1 | **信任经济，老铁关系** | 粉丝粘性与复看权重高，人设连续性比单条爆款更重要 |
| 2 | **普惠分发：关注页 + 发现页**，限制头部流量、扶持中小创作者 | 新号也能起来，但**内容不能断更、人设不能跳** |
| 3 | **同城权重高、复看权重高** | 本地内容与"值得再看一遍"的内容天然占优 |

**第 1 条决定了脚本的取向**：快手不是"一条视频定生死"，是"一个人值不值得长期关注"。脚本要服务于**人设连续性**，不能每条都换风格。

---

## 第 0 步：给预设场景卡，不问一串问题

**不要一次抛出 6 个问题。** 先拼出一段**完整的预设场景文本**给用户改。

推断来源，按优先级取：
1. **本次对话已给的信息**（最高优先级）
2. **用户画像与历史记忆**（赛道、人群、过往选题、**已建立的人设**）
3. **该垂类的常识值** —— 取用时必须标 `（推断，可改）`

**只有「本篇内容」是必填项**。其余全部预设好。

模板见 `references/input-brief.md`。

---

## 四条铁律

1. **先有人群，后有标题。** 快手 18–40 岁、下沉市场占比高——**用语和选题都要接地气**。
2. **形态决定时长与节奏。** 先定 A/B/C/D/E，再定秒数。
3. **标题出 3 条，三条三种机制。** 凑不齐 = 采集信息不够，回去补，不许硬凑。
4. **真实细节一律留占位。**

---

## 形态路由

| 形态 | 适用 | 主攻 | 时长 | 节奏 | 分镜密度 |
|---|---|---|---|---|---|
| **A 实用技能** | 手把手教、省钱技巧、维修种植、生活妙招 | 完播+复看 | 30–60s | 稳，步骤清楚 | 中 |
| **B 真实记录** | 生活日常、工作现场、真实过程 | 关注+粘性 | 30–90s | 慢，真实感优先 | 低 |
| **C 人设故事** | 个人经历、观点表达、老铁向对话 | 关注+评论 | 40–90s | 中 | 低 |
| **D 反转剧情** | 情景剧、意料之外的结果 | 完播+互动 | 20–40s | 快 | 高 |
| **E 同城本地** | 本地生活、同城信息、地方特色 | 同城流量 | 20–45s | 中 | 中 |

**判断**：教一个技能 → A｜记录一段真实过程 → B｜在表达自己 → C｜有情节有反转 → D｜跟本地有关 → E。

**三条硬例外**
- **A / B 型不要过度剪辑**——快手观众要"真实"，剪辑痕迹太重反而不讨好。
- **C 型必须延续既有人员设定**，不能这条一个风格、下条另一个风格。
- **E 型必须带本地元素**（地名、方言、本地场景），否则拿不到同城权重。

## 分支：旧片诊断

用户给的是**已发布视频 + 数据差** → 走诊断，**不重新采集**。

| 层 | 看什么 | 常见病灶 |
|---|---|---|
| 1 前 3 秒 | 有没有钩子 | 慢启动、自我介绍 |
| 2 真实感 | 是不是太"演" | 过度剪辑、端着说话、不像本人 |
| 3 人设连续性 | 与过往内容是否一致 | 风格跳变，老粉不认 |
| 4 互动设计 | 有没有跟老铁对话 | 单向输出，没有对话感 |
| 5 标题 / 封面 | 有没有看点 | 太平，信息流里抓不住 |
| 6 合规 | 是否被限流 | 功效承诺、极限词、诱导互动 |

输出：**先给诊断结论（哪 1–2 层是主因），再给改写版本**。

> 数据对应关系：完播低 → 改前 3 秒；关注转化低 → 改人设表达；互动低 → 改对话感与结尾。

## 交付规格（精简档）

| # | 项目 | 规格 |
|---|---|---|
| 1 | **标题 ×3** | 表格 `标题/机制/评分`，标 ⭐ 推荐 1 条 |
| 2 | **前 3 秒钩子 ×3** | 与标题配套的三种开场 |
| 3 | **时间轴脚本** | 分段表：`时间段 / 这一段干什么 / 关键信息` |
| 4 | **完整口播稿** | 可直接念的成稿，标注字数与预估时长 |
| 5 | **封面建议** | 主视觉 + 封面文案 + 关键镜头提示 |
| 6 | **违禁词体检** | 命中项 + 替换后的安全版本 |
| 7 | **自检** | 勾选结果 |

**分镜表不在默认交付里** —— 用户说「展开分镜 / 给分镜」才出。

不输出思路说明与过程分析。

## 填写策略：先简后拆（不要一次填满）

| 产物 | 第一遍：简版（必出） | 第二遍：拆解展开（确认后 / 用户要求时） |
|---|---|---|
| **预设场景卡** | 1 行本篇内容 + 其余预设值 | 补全关键词 |
| **标题评分** | 每条：总分 + 最低维度 | 推荐那条展开五维明细 |
| **时间轴** | 段名 + 秒数 + 一句内容 | — |
| **分镜** | **不给** | 展开每镜的景别 / 运镜 / 画面 / 字幕 / 音效 |
| **封面** | 主视觉 + 文案 | 展开构图与生图提示词 |
| **自检** | 必检 8 项 | 按形态展开细项 |

**规则**
- 第一遍出**方向性内容**，等用户确认方向。
- 用户说「展开 / 继续 / 细化」才出第二遍。
- **用户没确认方向前，不要把重型模板全部填满。**

## 标准流程

1. **预设场景卡** — 拼一段完整场景文本给用户改，只等「本篇内容」
2. **搜同类爆款** — 标题避让 + 结构借鉴（见 hook-playbook 第 -1 步）
3. **定形态** A/B/C/D/E，据此定时长
4. **标题 ×3** — 三种机制，各附评分
5. **前 3 秒钩子 ×3** — 与标题配套
6. **时间轴脚本** — 按形态骨架切段
7. **完整口播稿** — 真实细节留【】占位
8. **封面建议** + 结尾 CTA
9. **违禁词体检** — 标题 + 口播稿 + 字幕 + 封面文案全过一遍
10. **自检**附末尾

---

## 输出格式约定

- 标题与钩子用**表格**。
- 时间轴用**表格**：`时间段 | 这一段干什么 | 关键信息`。
- 口播稿单独成块，可直接念，不写"思路"。
- 占位符统一【】，口播稿上方声明"需要你填的 N 处"。
- **语感**：接地气、像跟老铁说话，不端着、不喊麦。

---

## 自检清单（必检 8 项）

- [ ] **前 3 秒**：有钩子，无慢启动
- [ ] **标题**：三条三种机制，评分均 ≥ 70，接地气
- [ ] **真实感**：没有过度设计的痕迹，像本人说话
- [ ] **人设一致性**：与既有人员设定一致，没有风格跳变
- [ ] **对话感**：有跟老铁对话的表达，不是单向输出
- [ ] **口播稿**：字数与时长匹配（约 4.5–5.5 字/秒），口语可念
- [ ] **真实性**：【】占位全部列出，没有一处是我替他填的
- [ ] **合规**：标题 + 口播稿 + 字幕 + 封面文案全部过违禁词

> ⚠️ 自检是**软自审**，不能代替违禁词体检。详见 `references/compliance.md`。

---

## 禁止事项

- **端着说话**：书面语、官方腔、端着的表达——快手观众不吃这套。
- **过度剪辑**（A / B 型）：真实感优先，剪辑痕迹太重反效果。
- **人设跳变**：这条一个风格、下条另一个风格，粉丝粘性会崩。
- **功效承诺**：根治、7 天见效、瘦 X 斤。
- **极限词与绝对化**：最、第一、100%、永久、唯一。
- **诱导互动**：点赞过 X 更新、评论区扣 1、关注才发。
- **变体规避**：谐音、拆字、符号替代——同样会被识别。
- **编造细节**：把【】当真实内容发出，或替用户填"看起来合理"的值。
- **凑数分镜**（展开分镜时）。
