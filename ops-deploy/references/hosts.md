# 目标配置与只读探测指南

本文件是字段模板，不保存个人主机、域名、站点库存、密钥位置或历史运行状态。每次从用户授权的项目配置取得目标，缺信息先询问。

## 配置字段

| 字段 | 要求 |
|---|---|
| 项目与授权 | 项目ID、负责人、授权证明、允许动作与禁止事项 |
| 环境 | 测试/生产、云厂商或自建、地域与实例ID |
| 连接 | 用户提供的SSH目标别名、端口、最小权限用户、凭据管理引用 |
| 站点 | 正式域名、规范URL、远程绝对路径、站点类型 |
| 本地产物 | 当前工作区内已确认的产物目录、版本与校验值 |
| 服务 | 操作系统、Web/FPM服务、运行用户、部署用户、版本、日志路径 |
| 备份 | 受限目录、异地副本、保留策略、恢复验证、数据一致性方案 |
| 发布 | 变更窗口、批准清单、回滚触发条件、验收URL |
| 证书 | 域名集合、签发机构、实际到期日、续期入口、最近执行结果 |
| 站点验证 | 平台、所有者、验证文件清单及保护策略；不存账号密码/token |

## 只读探测顺序

1. 用用户确认的实例ID、网络地址和主机指纹核对目标；指纹冲突停止并通过可信渠道核实，不直接删除known_hosts记录。
2. 查询`/etc/os-release`、负载、磁盘空间与inode、监听端口和实际服务管理器；不默认Ubuntu、腾讯云或宝塔。
3. 核对站点目录、Web/FPM进程及配置的运行用户；目录属主不一定等于运行用户，不默认`www:www`或`www-data`。
4. 查看站点入口和配置位置，避免输出数据库密码与密钥。盘点信息仅存授权的私有项目记录，不加入专家包。
5. 如使用宝塔，先确认版本与当前支持的界面/API。建站登记优先支持接口；内部SQLite库仅在明确授权诊断时只读检查，不直接插表修复。
6. 读取证书有效期、实际加载路径、续期任务和最近日志；不假定已存在任务或已续期成功。

## 搜索验证文件与缓存

- 验证文件使用本次平台提供的文件名和原始内容，不复用其他站点token。保留已授权平台的有效验证资产。
- 先实测验证URL及重定向链；仅当平台确需HTTP直出且用户确认时，为精确文件路径配置例外，不放宽整个目录或所有验证前缀。改前备份，配置测试通过才重载，复测普通页面HTTPS跳转仍有效。
- HTML、带内容hash资源、会话页和后台应分别设计缓存；HTML需及时更新时考虑重新验证策略，动态敏感页面不得共享缓存。
- 核对Nginx实际版本的响应头继承规则，避免子location新增`add_header`后丢失安全头。验收同时检查缓存头、HSTS（如项目启用）与真实内容版本。

## 连接异常

核对本地凭据引用、实例状态、路由、安全组/主机防火墙、端口与来源限制；不要为排障默认开放所有来源。重置密码、调整规则、启动实例及付费操作另行确认。
